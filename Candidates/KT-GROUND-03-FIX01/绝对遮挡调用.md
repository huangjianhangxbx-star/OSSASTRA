# 独立绝对深度／遮挡对照

`SurfaceDepthOcclusionContracts.cs.txt`，类 `KT03Fix01DepthOcclusionContracts`；轮询 `PollKT03Fix01DepthOcclusion`。仅调用时读取共用 `GroundSurface.Fix01.ShaderOverrideId` 与精确 `ShaderOverrideName`，不硬编码 Native 实例。引用的候选 Shader 不由本合同销毁。

新的键前缀为 `GroundSurface.Fix01.Occlusion.`，与层序 trial 分开：

| 键后缀 | 类型／默认 |
| --- | --- |
| `DepthFormat` | string `D32_SFloat_S8_UInt`，或精确 `D24_UNorm_S8_UInt` |
| `MSAA` | int `1` 或 `4`；支持查询与创建后读回均须符合请求 |
| `MatrixPreset` | string `Core` 或 `Expanded` |
| `Near` / `Far` | float `0.05` / `180` |
| `PlaneY` | float `3` |
| `Gap` | float `0.3`，upright 到地面的最小间隔；随试样尺度同比缩放 |
| `SaveImages` | bool `true` |

Core 为 perspective＋orthographic × pitch12/35/70 × distance5/25/32，18 pose，yaw315。Expanded 再加入 pitch12/35 × 八角 × 两投影，去重后46 pose。near/far 可独立配置复跑；不扩成无限笛卡尔矩阵。

每 pose 都有独立标准蓝色平面、完全在其上方的红 upright、完全在其下方的绿 upright。标准 opaque shader 由 Native 在内存创建，不写 persistent shader asset。候选只替换蓝色平面，白纹理、蓝 tint、view-depth offset0；其余几何与相机完全相同。

GroundOnly／CardsOnly／Standard Full／Candidate Full 四帧给出绝对遮挡证据：前景和后方被挡区域各至少64个5×5内缩样本，缺任一区域则 UNRESOLVED。比较所有标准纯色内缩 RGB，要求 mismatch0；全图严格差及被排除边缘差另列。MSAA4 使用显式原生 resolve 到同尺寸、同颜色 graphicsFormat 的单样本颜色目标后 ReadPixels，不直接读取多采样目标。

报告针对实际创建 target 的 depthStencilFormat/MSAA；无法直接签署 URP 内部额外 attachment 的格式。它证明的是标准 native 不透明几何与候选在该条件下的遮挡结果一致，不以候选自己互比证明自身绝对深度正确。
