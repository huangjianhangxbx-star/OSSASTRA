# 多层前缀 oracle

源文件 `SurfaceMultiLayerOrderContracts.cs.txt`，类 `KT03Fix01MultiLayerOrderContracts`；轮询类 `PollKT03Fix01MultiLayerOrder`。原两层红样本类不变。只读复制当前 A 或 B 全部实际活跃 cache 层，保留原 local TRS 祖先链、真实 Mesh/Material 副本与完整 MPB；不改或保存 R08 原场。

先分别在 A/B 执行默认 TwoViews，再决定是否扩矩阵。设置全部原实验键后加以下键：

| `GroundSurface.Fix01.` 后缀 | 类型／默认 | 作用 |
| --- | --- | --- |
| `Surface` | string `A` | 只允许 A/B，分别取两个精确登记 ID |
| `MatrixPreset` | string `TwoViews` | 默认两视角及各自 ±1mm，6 pose／平台 |
| `SaveImages` | bool `true` | 每 pose 保存 Full、ErrorMask、代表单层、对应 Prefix、移除高层结果、应出现的混合低层 oracle |
| `DepthFormat` | string `Default24` | 原24构造；或明确 `D24_UNorm_S8_UInt`／`D32_SFloat_S8_UInt`。设备不支持、实际创建不同格式均 `UNSUPPORTED`，不静默替换 |

`RenderHeightStep` 在多层类中按**实际 layerIndex × step**施加到每层自有 Mesh 的 local vertices.y。因此 0.0005 为相邻层半毫米间隔，仍不改变 Collider 或原场。

| MatrixPreset | 有界视角 |
| --- | --- |
| `TwoViews` | 35°／315°／25m，12°／315°／32m，各 -1/0/+1mm |
| `Octants` | pitch12/35 × 八个45°yaw，distance25，16 pose |
| `Neighborhood` | pitch12/35 × yaw314.9/315/315.1 × -1/0/+1mm，distance25，18 pose |
| `PitchDistance` | pitch12/35 × distance5/25/32 × -1/0/+1mm，yaw315，18 pose |
| `Bounded` | 按轴合并上述距离、八角、邻角，并仅在315°/25m补微移；去重后28 pose，避免全笛卡尔组合 |

每 pose 都重新渲染独立透明空帧、每层 Single、每层 Prefix[0..k]。Single[k] 与最高仍覆盖的低层 Single[j] 必须都有5×5不透明内缩且差色足够；Prefix[k] 应为 Single[k]；移除高层后 Prefix[k-1] 应为 Single[j]。确定匹配错误低层颜色才为 RED；其他色差或样本不足保留 UNRESOLVED。每 pose 及每层覆盖统计明确列出，最终 GREEN 还要求所有活跃高层至少有一次有效覆盖。

RT 报告为实际创建目标的 `depthStencilFormat`、颜色 `graphicsFormat` 与 depth bits；未直接捕获 URP 内部另建的 attachment，不把该元数据冒称 GPU 全管线证明。阈值仍保持原样，输出也不把微动前后整图差当闪烁。
