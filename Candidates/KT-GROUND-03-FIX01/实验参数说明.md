# 层序 Native 试验参数

调用类仍为 `KT03Fix01LayerOrderRedContracts`，轮询类仍为 `PollKT03Fix01LayerOrder`。输出目录仍由 `GroundSurface.Fix01Output` 指定。

每轮开始前显式设置以下全部键，避免上一轮 SessionState 参数残留。所有修改只进入独立 PreviewScene 自有 Mesh、Material、MaterialPropertyBlock 和 RenderTexture；原 Scene 不保存、不重开、不回滚。

| SessionState 键（前缀 `GroundSurface.Fix01.`） | 类型 | 原始默认值 | 含义 |
| --- | --- | --- | --- |
| `DepthUnitsScale` | float | `1` | 各层原 `_DepthUnits` 乘此值；默认不写属性 |
| `DepthSign` | int | `1` | 只允许 `1` 或 `-1`，与 scale 相乘 |
| `MaterialOnly` | bool | `false` | 深度变更仅写自有材质，原 block 深度覆盖保持原样 |
| `ClearDepthMpb` | bool | `false` | 私有 block 仅去除 `_DepthUnits`、`_DepthFactor`，保留 shader 其他属性与 texture ST；最终深度取材质 |
| `RenderHeightStep` | float | `0` | 只给高层自有 Mesh 的每个 `vertices.y` 加此值；不建或更改 Collider；报告实际 world Y 增量 |
| `Layer0DepthAnchorZero` | bool | `false` | 可选把低层自有材质及允许写入的 block Units 归零 |
| `Depth32FloatStencil` | bool | `false` | 默认沿用原 24-bit 构造；true 请求 `D32_SFloat_S8_UInt`，不支持或实际创建格式不符时明确 `UNSUPPORTED` |
| `ShaderOverrideName` | string | 空 | 只给私有 Material 换 Shader；Find 失败／ShaderHasError 明确 ERROR，不判为层序 RED |
| `ShaderOverrideId` | int | `0` | 非零时仅用 `EditorUtility.InstanceIDToObject(id) as Shader`，并验证名字严格等于 `ShaderOverrideName`；零才走 `Shader.Find`。适配未登记到 Find 的 transient shader，不由 harness 销毁该共享 Shader |
| `PrototypeLayerStep` | float | `0` | override 若暴露 `_ViewDepthOffsetMeters`，同时给 Mat 与 MPB 写入 `actualLayerIndex × step`；原共面几何保持不动 |

`ClearDepthMpb=true` 时不会再往 block 写深度值，因此可观察材质的实际效果。`MaterialOnly=true` 且 `ClearDepthMpb=false` 可观察旧 block 是否覆盖了材质变化。

可按单变量分别记录：原始默认；同方向 Units 16/64 倍；反方向 Units 1/16/64 倍；仅材质变化；只清 block 深度；高层物理分离 0.0005；只改 RT 深度格式。这里是实验控制表，不代表修复选择。

反馈始终使用原来的同 pose 单层参照、不透明 5×5 内缩、差色阈值 20、每通道容差 2、每 pose 至少 128 个样本。参数不会放宽 oracle。JSON 记录每 chunk 原始/最终材质和 block 的存在位、Units/Factor、请求参数、实际 `depthStencilFormat`、实际颜色 `graphicsFormat` 和 depth bits。

`mpbOrMaterialUnits` 只是按 block 存在位读到的值，不声称这是 GPU 光栅深度状态最终采用的值。是否影响 Offset 必须由本轮像素反馈区分；报告明确保留 `gpuRasterDepthStateMeasured=false`。

私有统一平面 shader 名为 `Hidden/Ossastra/GroundSurfaces/FIX01/UnifiedPlaneDepth`。override 会保留原所有同名材质属性、MPB 与队列；`PrototypeLayerStep=0` 可验证精确同深度与既有队列／LEqual 的行为，0.0005 可验证片元深度间隔。二者均不修改源几何、Collider 或生产 shader。
