# Native contracts

These owned IFunplayCommand fixtures run through the project's guarded native execute_code interface in stable Edit. Read each precondition and keep a durable execution receipt; a transport timeout is not permission to replay a mutation. They exercise production Settings, MRT MSAA1/4, style GPU math, lifecycle/renderScale rejection, window-only difference and finite main-light Toon math. They do not replace visual review or Player cost measurement. No test is imported into Assets or executed automatically.

Actual green counts: Settings11, Registry10, MRT62, composite11, lifecycle13, window70, Toon5angles. Final copied-scene/source configuration and measured limits are documented under docs/ossastra/LOOKDEV-01/StyleComposite.
