# SV-RENDER-ACE-01 横版 ACELight 与角色材质对照

用户明确授权执行附件 v1.0。指定规划对话已读，C 在同一个正式横版场内，原有/苍翼两套角色材质共用一张场景画面及同一组灯。

SV-ACTION-01-FIX01 仍持有 Unity 及正式场。当前仅登记本记录和独占外部研究目录。研究、源码候选和离线验证并行进行，正式导入以动作任务释放登记为准。

1. 从本机证据确认光源、四目标写入、组、场景及角色接收。研究成果与原作者参数不混写。
2. 工程外实现世界锚定的灯片、同相机屏幕图、分组接收、两级切换与材质所有权接缝。保存用于验证事务、属性同步和光图因果的探针。
3. 交接后在正式场登记 Renderer19 和原 UI；依次核对 A、B、C 原材质和苍翼材质，保存重开。
4. 采集三个位置、灯强度消融、动态实录和成本，再按 R11 定向发布。

## 工程外验证与接入准备

- 本机原版 2273430/build 26263712 的实际四路 MRT Writer、分组清色、踏板和角色接收已独立核实。两场样本所有灯 UseShadow=0；特殊阴影生产、原版动态图、原 LightLayer 高位映射仍无完整证据。
- `研究/SV-RENDER-ACE-01/候选/VerifyAce.ps1` 用本机 Tuanjie 运行库联合编译。`StageAceImport.ps1` 只读预检 17 文件及 7 个共享基线指纹通过。Native Scene/Renderer 入口和同机位取证探针已在工程外就绪。
- D3D11 WARP 实际编译运行 Writer 与场景/角色接收，确认灯强/遮罩改变像素，World-only 不改变角色，Alpha over 顺序有效；固定投影不同接收深度得到同样响应。此证据尚非 Unity 正式场帧。
- C1 复用原角色 Profile、环境底光、点光和轮廓路径，保留 C 本身的场景照明。C2 新 Shader 与原图集同用，当前适配了有证据的主色×环境光图；项目缺 BrightTex/Extra/Extra2，暂不冒充具备原版高亮和发光数据。
- 实机尚待动作任务交接。接入后检查四处灯、475 个响应画片、双角色 Shader 身份、两组各四张 RT、关闭灯时场景/角色响应、窗口尺寸改变、存盘重开和发布。

- 21 个候选、7 个共享指纹通过本机联合编译与预检。补齐独立 RT 生命周期和折叠灯图诊断，保留实际输入和 Gameplay Listener 采集的临时探针。ACE 未导入，正式场仍由动作修订独占。
- 交接顺序可分两步：动作修订完成正式场保存、实机和临时探针移出后即可释放 Unity；其定向 Git 若仍在进行，可继续独立完成。ACE 的 Git 在复核远端基准后另行发布。

## 正式横版场结果

- 动作任务发布并释放后，以 b2bda8aa247c07f9d8e80cd85b84e0b30b909514 为远端基准。正式场保存重开 17 个根、唯一相机、Renderer19 六个 Feature。默认 A，C 首次苍翼材质，两种角色材质可在 GameView 顶部即时切换。四个作者灯挂在 SideViewEnvironment，光图调试默认收起。
- 核对起始笼、东侧冷光、东侧暗区边缘。三处 C1/C2 同灯、同相机和姿态，场景取样 RGB 差为 0。C2 身体选区开关灯 RGB 差依次为 37.48、39.30、18.79。两角色的实际 SideViewSpine/SideViewSprite 与对应 ACE Shader 身份读回。A 恢复原材质设置和取样。
- C2 通过正式 A/D/J/左键移动、跳跃、扣 12 HP、一次命中特效和震屏，542 个 C 帧均有同帧光图记录。实录 7.69 秒含同次 Gameplay Listener 混音。暗区 C2 更融入，C1 人物更醒目。C2 当前用原图乘环境光图，缺对应 BrightTex/Extra/Extra2，原版特殊阴影未验证。
- 1600×900、4× MSAA、每档 360 个固定机位 Editor Play 帧，C1/C2 GPU 中位 1.838/2.525 ms，整帧间隔中位 5.747/5.619 ms。两组八张 800×450 RGBAHalf 约 22.0 MiB。改尺寸至 692×332 再还原，始终八张，退到 A 即为零。
- Unity 首次编译暴露共享采样器被裁剪后无法绑定，已改用 URP 线性夹取采样器。尺寸往返暴露暂时保留旧附件，已显式归还 backing texture 并复测。临时探针移出 Assets 后重新编译，原生持久按钮和两种 Shader 重新读回。全套武器、独立 Player 与原版动态片段不在已验证结论。
