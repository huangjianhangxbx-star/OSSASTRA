# 横版普通攻击原作特效接入

用户要求在正式横版场使用《空洞骑士：丝之歌》前期普通攻击原作特效，并把长白条做至接近参考画面的尺度。

- 本机同版本素材为两套释放刀弧、两套接触条带和一套接触爆点。刀弧各 4 帧／20 Hz，条带各 5 帧／30 Hz，爆点 3 帧／20 Hz。按原图帧矩形、定位和透明度绘制。普通连击按阶段交替选择刀弧，命中条带与爆点由真实命中回执触发。双条带的叠放和尺寸按项目机位校准。
- 正式场 `Assets/OSSASTRA/SideView/SC_SideViewAdventure.unity` 在 A Legacy、B Silksong 和 C2 ACELight 下，用正常键鼠与跟随同伴验证左右真击及空挥，共 9/9。各次真击木桩扣 12 HP、接触表现和震屏各一次。空挥有刀弧，未触发接触爆点或震屏。两侧主白条峰值帧中，Alpha ≥ 128 的原图水平投影约占画面 50.08% 和 49.96%，实际画面仍受前景遮挡。
- 保存后重开正式场，读取了三个配方、五张素材和主白条宽度，场景处于干净状态，临时探针已移出 Assets。正式场绑定、原作贴图、原始实测帧和带声视频均保存在本机。素材缺失时可走已有程序化特效回退。
- 证据在本地 `artifacts/SV-ACTION-ORIGINAL-FX`，包含实机带声录像、逐帧截图和可复核的正式输入结果。
