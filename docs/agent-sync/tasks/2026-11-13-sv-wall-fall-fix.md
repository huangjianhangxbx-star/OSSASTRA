# 横版贴墙下落修复

普通下落时持续按向高墙，旧版会进入墙滑。该状态先把下落速度置为 0，等待 0.15 秒后开始加速，最高 4.8 m/s。普通下落的上限为 30 m/s。旧版正式场的输入记录中，高墙上按住 D 时观察到了 0 m/s。

墙滑改为跳跃配置的独立选项 `allowWallSlide`，默认关闭。墙体仍阻挡横移，普通重力负责下落。抓边、持续输入翻越和独立的墙跳开关沿用原逻辑。

在 `artifacts/SV-WALL-FALL-FIX/contract` 运行 `dotnet run --project WallFallContract.csproj`。测试链接生产状态机、跳跃配置和持续输入代码，使用夹具提供墙面接触。旧版左右两项均失败，修复后 7 项通过，覆盖两侧速度一致、合法抓边翻越、禁用墙跳和墙滑显式启用。使用团结原工程响应文件编译项目运行时程序集通过。

正式场 `SC_SideViewAdventure` 的真实 A/D/J 输入验证在干净的 Play 会话执行，四项通过。东侧高墙的 D 保持与 D 释放各有 11 个空中下落步，速度均从 -1.162 到 -13.162 m/s，D 保持用例 11 步均有实际侧碰撞。低台保持 D 完成一次抓边和一次翻越。正式 JumpProfile 在 Play 读取为墙滑关闭、墙跳关闭、挂边系统开启。结果 `artifacts/SV-WALL-FALL-FIX/play-20261113-232713-585/result.json`。
