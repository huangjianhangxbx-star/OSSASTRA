# SV-RENDER-AB-01 横版整套渲染对照

用户授权执行附件 v1.0，并要求避免与另一个对话冲突。已从指定规划对话读到用户原始目标。两套画面使用同一个横版场、相机、角色和玩法世界。A 来自旧主场有效保存态。B 基于本机原作成像证据，并记录项目适配。

## 写入安排

动作任务 SV-ACTION-01 仍为唯一 Unity 写入者。本轮当前为资料与研究准备，独占本记录和星骸目录的 `研究/SV-RENDER-AB-01`。读取旧主场保存态、原作资源和横版现有渲染代码。待动作任务释放并交接后，核对现场与源码差异再登记正式写入范围。

动作轮已确认有其他任务仍运行时保留电脑开机。正式渲染接入和验证等待它完成 Play 和释放写入范围。

## 执行顺序

1. 记录旧主场实际启用的配方、各接收端和上下文依赖。记录横版基线的相机、材质分组、角色和局部灯入口。
2. 读取原作体色、光图、暗区、近远分层与最终合成的本机证据。
3. 取得 Unity 写入窗口后，先验证同相机的 A/B 配方应用与回退，再接完整 A、B，复用显示偏移、角色装备轮廓和现有动作链。
4. 正式场四个观察点同机位、同姿态采样。比较人物与场景、即时切换、动态动作、资源归还及帧耗。保存重开后发布经核对的自有文件。

## 正式场接入和实机结果

动作轮完成后以保存的 SideViewAdventure SHA 15A92304… 作本机备份。通过 Tuanjie 原生 API 登记 826 个现有画片和 Renderer19 五个 Feature，保存后重开。打开正式场按 Play，上方 A Legacy 与 B Silksong 两键可即时切换，默认 A。启动沿用横版 00:00；正午对照单独设 12:00。

B 的初版青屏由颜色链在 MSAA 解析后反复读写相机附件触发。实机对照关闭 MSAA 后恢复全部透明层。B 仅在该相机的渲染窗口借用原作单采样设置，A 和序列化相机保留原值。A 初版洞顶碎片来自横版透明画片沿用旧不透明阈值，本场改用实际 Alpha 平滑混合，光图、前景遮挡和角色仍写保护值。其他 Renderer 的 WorldLook 仍用原二值许可。

四个同机位分别为起始绿景、东侧暗区、局部光正午和西侧前景。每组 A/B/A 相机矩阵、投影、分辨率、主控 ID 和角色位置不变。B 三段 Pass 同帧提交，A 的角色 Coverage 在切回时恢复到 2。证据在 `artifacts/SV-RENDER-AB-01`。带声实录用同次 Unity GameView 与 Gameplay Listener DSP，显示模式切换、普通跳、挂边翻越、切人和命中震屏。临时动态用例 11/12；左击木桩输入发射但未新增命中，动作轮接入前记录 `probe-20261113-053215-137-120` 有相同结果，正式战斗逻辑未在此轮改动。

西侧机位，1600×900，暖机 90 帧、各 360 个 Editor Play 样本。A 帧间隔 P50 5.991 ms / P95 6.831 ms，CPU frame 5.982 ms，GPU 2.568 ms，Draw 594 / SetPass 419。B P50 5.674 ms / P95 7.217 ms，CPU frame 5.671 ms，GPU 1.810 ms，Draw 482 / SetPass 354。为固定机位实际数据，A 保留 4× MSAA，B 使用原作单采样；它不是同 AA 策略的优化归因。GPU 峰值占用和 RT 驱动开销未测。

A 的横版洞窟室内区域为作者近似，当前无显式露天雨区。B 保留已查证的静态场景边缘与 0/1/2 级暗区；动态黑边、Blackout 触发器、特殊受伤/灯笼分支仍未迁入。暗区样点 B 很暗，人物仅保留少量可见细节。局部的作者色与光图的 Gamma 数学已接入，项目透明叠加仍在线性 URP 完成。原作素材、源图和场景资源只留本机。未构建独立包。
