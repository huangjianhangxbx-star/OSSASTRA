# SV-RENDER-ACE-03 原作角色与方向内边光

## 正式场

在 `Assets/OSSASTRA/SideView/SC_SideViewAdventure.unity` 进入 Play，默认 C ACELight／融合材质。开场左侧显示 Es，顶部「苍翼角色参考」默认收起。面板可显示或隐藏样本、暂停和逐帧、选待机／跑动／攻击、切 02 默认色和 03／04 原配色、切完整／基础、分别关闭亮部／定向高亮／发光，并显式切换项目通道诊断灯。顶部「光图调试」仍可独立切换项目两角色的内边光和外柔光，并有克制／增强内边预设。

按最新要求，Es 的统一源网格缩放为 3.15，保持原网格脚底和动作比例。待机实测约 4.97 场景单位，约为两名现有角色的 1.60／1.78 倍。站位 (46, 3.035, 0) 在开场角色左侧。场景既有前景和台柱对剑身保留遮挡。

## 实现与原作依据

- Es 为独立视觉对象。参考根没有碰撞、战斗、主控或角色光照登记。沿用主体相机，ACE 图在同一相机读取，原两角色继续使用两个角色覆盖槽。基础／完整共用相同网格、主图、覆盖和附件页。
- Steam build 26263712 的 Es（Actor 103401）使用原生 `PaletteAnimation` 帧网格。待机 264 个 60 Hz 时间刻，跑动采用原动作配置中的 32 刻循环，攻击 52 刻。三段共 30 个不同原网格。每个帧同时切换三张相关图所在的页，保留源网格、UV.xyzw、三角索引与原始相对坐标。
- 换色替换已经上色的主图族，同时写入对应配色的发光参数。主图 RGB 给出底色，`Extra.a` 为真正覆盖，`Extra.r` 调亮部，`Extra.g` 为通用发光，`Extra2.rgba` 各自提供单独发光权重。方向高亮另外按光图方向偏移采样覆盖。所选片段的 Extra B 装饰分支关闭，配色覆盖共用。
- 20 张 1:1 裁切使用原 BC7 块，共 86,302,640 字节。采用 Bilinear、Clamp、单 Mip，保留原 Gamma 数值插值并在项目 Linear 输出时解码一次。既有项目场景深度使用 LEqual。D3D11 WARP 用三配色真实 BC7 图页和网格对照原作 PS152，Alpha 一致，样本线性 RGB 最大相对误差低于 0.21%。
- 原作大厅相应静态资源中 11 盏启用灯均为 `UseShadow=0`，包括 Es 专用灯。当前诊断灯使用项目自定通道参数，运行大厅光组路由和其他原作地图的特殊阴影仍未实测。原作比较图由发行资产和编译 Shader 离线重建，原作游戏界面、账号、存档留在原状态。
- 校准后的内边光宽度／柔度／强度／增益上限为 4.5／0.9／2.4／0.55，场景默认使用。ACE-02 克制配置 2.5／0.9／0.8／0.32 仍可选。肩部保护和外柔光沿用实际配置。

## 正式 Play 验证

- 团结 2022.3.62t18，D3D11，1600×900。暖光、东侧冷光和暗区共 26 个固定姿态状态，外柔光统一关闭后，内边变化仍可辨。小蓝局部显示亮度差超过 4 的像素，作者灯在暖／冷／暗区从 38／6／49 增至 174／134／425。侧灯切左右能换侧，关灯两种画面逐像素一致。保留黑线和既有 Alpha 修复。
- 15 个主场固定状态验证按钮、三配色同帧、辅助页跟随、亮部／高亮／发光消融、隐藏、退出和重回 C。人物与配色保持同一材质实例，隐藏或离开 C 时解除网格和 MPB 绑定、关闭诊断灯。样本图页由场景配置共享引用，隐藏不会重复创建或重新读盘，退出场景可由 Unity 释放。
- 同规格隐藏／显示／恢复隐藏各 360 帧。GPU P50 1.7080／1.7469／1.7019 ms，主线程 2.7624／2.6513／2.6848 ms，渲染线程 1.2485／1.2549／1.2597 ms。绘制 298／299／298。10 张 ACE 图身份稳定，三段的整帧 GC 计数中位数均为 99,565 B。公开计数包含编辑器和已存在开销。
- 正常左右探索、J、木桩实际命中与震屏、西侧同台连续两次回抓翻越和 Z 切控均通过。真实 Gameplay Listener 有声，实录 1600×900、48 kHz 双声道。动态探针中 2,683 个融合帧无当前光图缺失。探针和元数据移出 Assets 后，正式场冷重开、Play、默认配色、参考 Shader 无错误、2 个角色覆盖和 10 张光图已读回。Renderer19 序列化文件哈希与接手时一致。
- 升级后的日志还记录既有 T5/T6/体素实验 Shader 缺少 `APSKeywords.hlsl`。本轮未改这些于旧俯视场使用的资源。
