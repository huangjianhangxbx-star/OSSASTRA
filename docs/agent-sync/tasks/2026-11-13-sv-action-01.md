用户授权执行 2026-11-13 附件 v1.0，交付时其他对话仍在执行则保留开机。基线为 OSSASTRA main b5fc92f 和本机正式横版场。私有 ChatGPT 链接未返回正文，工程范围以用户授权和附件为准。

## 并行范围与顺序

- Root 为唯一 Unity 写入者，独占正式 SideView 场及其配置、横版相机、动画与音声接线、交付证据与发布。现有未提交工作保留。
- 战斗子任务独占 OSSASTRA Combat、CombatFeedbackView 和本任务战斗合同。命中网关发布时冻结空间事实，按结果播放，按发射聚合震动。
- 运动子任务独占 Characters Core、Runtime 的运动／动作资格与稳定瞄准接线，相机文件除外。挂边和翻越使用现有唯一 Move，动画与音效只读状态或实际事件。
- 原作研究只读取已安装游戏和相关文件，输出位于星骸研究目录。依据等级和项目候选参数单独记录。
- 先核对场景和真实输入，分别验证接触、相机、动作资格与墙边规则，再在同一正式场联调。保存重开后定向发布源码。

## 正式场试玩

打开 `Assets/OSSASTRA/SideView/SC_SideViewAdventure.unity` 后按 Play。A/D 移动，J 跳跃，Z 切换角色。用鼠标瞄准并点击左键攻击开场左侧的练习木桩。右侧两个苔边平台用于墙滑、墙跳和抓边。

- 朝墙按住 A 或 D 并短跳。靠近顶沿且差一点上台时会自动抓住。原来一直按住的方向会被消耗，角色可以停在挂边位置。
- 松开再按朝平台方向翻越。按远离平台的方向放手。走下低台后，可在手仍够到顶缘时反向贴墙回抓。
- 低于抓边范围时，贴着墙下落可墙滑，再按 J 蹬离。挂边和翻越期间攻击在原仲裁器提前拒绝。
- 相机震屏开关和强度在 Hierarchy 的 Main Camera → Side View Camera Follow → 命中震屏。练习木桩、墙体、音画设置和所有现有角色仍在同一个正式场景。

## 研究与项目映射

本机《丝之歌》Steam build 22479045、1.0.30000 的代码和配置核对记录在星骸研究目录 `研究/SV-ACTION-01/丝之歌命中震屏与墙边取证.md`。实际取证覆盖挥击和接触爆点的顺序、分配给不同配方的方向、下击粒子的特殊规则、震屏事件与曲线、贴墙减速和蹬离约束、原作自动翻越 FSM。墙边缺少同版本原作动态录制。

项目候选用冻结的释放方向、实际到达方向或表面法线驱动不同反馈。近战重叠点标记为估计值。命中、格挡、闪避、环境接触使用不同形状及配方，相机按发射身份合并冲击。项目使用有界衰减的方向震动和单一最终相机输出，保留稳定的基础镜头与瞄准射线。0.20 秒来自原作弱命中资产时长，方向权重、幅度、波形及墙边数值为项目候选。

墙滑、挂边和翻越归原运动状态机，碰撞位移归 CharacterMovement。挂边按新方向输入完成翻越和放手，和原作自动翻越不同。当前两角色的墙边动作走独立 SO，采用现有姿态临时映射。抓边、蹬墙、翻越和放手音效走原 GameAudioRoot，用现有本机短音配置变体。

## 实机与合同证据

- 正式场真实时钟，虚拟键鼠驱动实际 InputAction。两档各 12/12，通过普通跳、左右命中、挥空、击墙、抓边停住、挂边主手拦截、翻越、放手、走下后回抓、墙滑蹬离、Z 切换及第二名角色攀越和低顶拒绝。60 档记录 589 帧，中位 59.84 FPS。120 档记录 1133 帧，中位 119.86 FPS，P95 帧间隔 9.89 ms。夹具用传送设置各用例起点，动作本身由正式输入和真实碰撞推进。测试时暂移开同伴以隔离左右命中，原有角色遮挡规则继续有效。
- 渲染镜头实际震动最大约 0.1212 世界单位。基础镜头最大漂移 0.000008，稳定瞄准射线误差小于 0.000008，冲击结束偏移为零。同次发射的重复请求输出与单次一致，下一发射可合成且受上限约束。强度 0 清除队列，恢复强度后无旧冲击。
- 实机网关诊断分别得到 Guarded 和 Evaded，两目标均保持 100 HP。冰柱生成它自身的释放被原接触过滤拒绝，维持 4 HP。一次发射对两个目标各扣 9 HP，重复传入同一对象只结算一次，两个真实接触共一条震动请求。方向几何合同 8/8，墙边输入和跳跃合同 13/13。
- 有声短片 `artifacts/SV-ACTION-01/横版动作实录.mp4`，960×540，实际编码 548 个画面帧，约 10.4 秒。声音为唯一 Gameplay Listener 的真实 PCM，峰值约 0.523。四类墙边短音均有 PLAY_ISSUED，证据目录同时保存原始录音、声音事件和逐帧记录。录像采样和运行帧率分别记录。
- 本轮实机证据覆盖上述场景、默认角色和原游戏相机。尚未逐一回放所有副手与技能组合、动态平台、每种强制位移及实体手柄。墙边临时映射、表现强度与手感仍待用户试玩审查。

本轮自有 C# 文件按职责维护中文文件头，关键注释覆盖唯一位移、墙边输入重武装、释放快照、稳定瞄准、实际接触回执与声源去重。正式场、原作素材、引用本机音源的 SO、诊断记录和录像保留在本机，GitHub 发布自有源码、必要脚本 meta 和本记录。
