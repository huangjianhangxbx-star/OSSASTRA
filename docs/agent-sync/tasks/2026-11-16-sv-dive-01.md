# SV-DIVE-01 定向俯冲下击与命中腾起

本机基准为 Project_ANKALUTE 的正式横版场，远端基线 OSSASTRA main f77abbb。当前任务完成原作研究、可拆卸动作候选与定向实机测试。正式费用与动画事件等待统一架势接口。项目本机主场已保存芙蕾茜娅候选配置，每次进入正式横版场的编辑器 Play 自动开启预览。

- 同设备主手按下和下方向在普通连段之前唯一认领。键鼠连续 XY 投影，手柄沿同设备模拟摇杆。主角保持无挂载。
- 动作沿现有仲裁、能力 Run、固定步移动器和真实战斗网关推进。快速接触沿已裁剪轨迹扫掠，命中或击杀后自动腾起一次。落空时实际落地后收招；碰到侧墙继续下冲，卸下能力时撤销。
- 侧重保护现有横版抓边与跳跃。本机证据在 `artifacts/SV-DIVE-01`，原作材料在星骸研究目录，正式场、研究媒体和原作素材只保留本机。
- 用法及资源、动画缺口见 `docs/ossastra/SV-DIVE-01/接入说明.md`。

正式场自然 InputAction 流程正常帧率 4/4、30 FPS 5/5，实际木桩命中一次并上冲。原生运动 4/4、虚拟设备 5/5、原翻越和点按 8/8 与 9/9。详 docs/ossastra/SV-DIVE-01/验证与交付.md。

试玩入口修复。Play 重进自动启动当前正式横版场的已挂载候选。沿用当前初始猎人设置、Z 切人和当前 Play 菜单开关。用真实 InputAction 红 5 例、绿 5/5 核对；给用户交还当前芙蕾茜娅可操作的 Unity Play。

俯冲持续与腾起高度修复。俯冲阶段等首次有效命中或实际落地后转换；碰侧墙持续下落。腾起使用普通跳完整上升过程，不读取持续跳跃键。正式横版场 10/10，超旧时限 0.90 秒仍可命中，开阔处普通跳和腾起同为 5.484 m。证据与用法见 SV-DIVE-01 专项说明。
