# 横版角色手感调试台

入口在 Unity 的 **OSSASTRA → 战斗 → 横版角色手感调试台**。原「横版攻击调试台」菜单仍打开同一个窗口。

## 调一次实际命中

1. 打开「命中与受击」，选角色、动作和段位。指定格挡、命中、闪避或环境接触，可按真实材质创建覆盖。材质留空时匹配通用条件。
2. 设置命中声、接触特效、震屏和两个实体的卡肉。声音延迟从实际接触开始，素材起播点用来跳过片段开头。有效修改自动保存，下次出招读取。角色资产的共用范围在面板显示。
3. 选空挥、固定受击、格挡、致死靶或双目标并复位。在 Game 中按正式输入出招。在「实战对照」查看配方、提交结果和实测暂停。对照快照在本次同一角色进入试验时留存。
4. 「动画与事件」仍调出手标记和随动画触发的声画。命中声和接触特效跟随实际结算。

## 调跑跳和墙边动作

1. 在普通横版场景或独立测试场打开「移动与翻越」，选要调校的角色。同一行显示正式来源、候选和当前生效值。同一次 Unity 编辑器会话里，引用同一角色定义的场景共用这份候选。
2. 在独立测试场选择平地、低台沿、侧墙、低顶、落区或高台沿。改好候选后可直接点「应用候选并复位」，用正式输入试玩。恢复基线会撤销本次运行覆盖，保留候选。
3. 同一区先跑一条正式轨迹，再重复输入跑候选。横坐标可选相对物理位移或时间，跳高与腾空时间来自实际物理步。
4. 点「保存为角色默认（所有横版场景）」，把这份候选写进角色专用配置。以后引用这份角色定义的横版场景都会使用它。「写回共享来源」同时影响引用该共享配置的其他角色。墙滑和墙跳随正式能力开关显示。
5. 「运动接触」独立配置起跳、落地、抓边、墙跳、翻越完成和主动放手。按下跳跃键未形成成功起跳时，成功反馈不会触发。

## 重新执行测试

Unity 菜单 **OSSASTRA → 战斗 → 验证横版攻击调试台** 会打开原有独立场并自动运行定向回归。日志写在 `Reports/SideViewAttackLab/边界验收.txt`，完成后恢复原编辑场景。

验收日志中的声音提交、预算决定和实际播放调用分别表示不同的观察点。主观听感和打击感以作者现场试玩为准。

## 本机验收

2026-11-20，Unity 重新导入并编译通过。独立场 Play 回归 0 项失败，退出后返回原接墙样板，保留当时的未保存内容。

| 实测 | 结果 |
| --- | --- |
| 空挥、格挡、命中、致死 | 空挥无接触反馈。格挡保留靶 HP。固定靶 10000 → 9988。致死靶 1 → 0，延迟声提交到统一声音根。 |
| 局部卡肉 | 0 配置不冻结。45 ms 攻受双方均可恢复。人为插入 78 ms 长更新后仍出现 1 帧局部冻结。双靶各有一个回执与暂停，120 ms 配置实测约 122 ms。 |
| 跑速与跳跃 | 实际跑速 6.60 → 9.24 U/s，另一角色仍使用自己的来源。短按 1.25 U、长按 5.48 U。低顶实际碰撞中断，自然离台后有一次真实落地。 |
| 墙边和运动音 | 实测命中高台挂点、翻越落地和主动放手。石地起跳配置 180 ms，观察到 181 ms 后提交一次。复位清掉未到期声音。 |
| 配置持久性 | 隔离的角色定义重导入后，正常 CharacterMovement 读取专用 Profile，材质配方和双方卡肉读回正确。芙蕾 ATK1 及走、跑脚步回归通过。 |

首批证据覆盖两位现有角色的普通动作及上述定向用例。复杂技能的持续多段反馈、各敌人独立配方、墙跳开启后的实战组合及最终主观听感仍按各自素材和角色验收。表现页的震屏强度沿既有相机接口，衰减和时长由原相机配方控制。
