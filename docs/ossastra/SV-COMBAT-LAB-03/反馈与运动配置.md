# 反馈与运动配置

## 实际接触

已接受的动作保存角色、动作组、段位和配方快照。同一释放到达目标时使用实际投递和材质条件，原空间查询及战斗网关继续决定扣血、格挡和闪避。声画、震屏和卡肉读取同一回执，闪避和空挥不会产生伤害命中。

角色覆盖保存在 `SideViewFeedbackProfileSO`。音频优先级沿用共用 `CombatSoundProfileSO` 条件，具体材质优先于同招式的通用段位。声音引用原 `SfxEventDefinitionSO`、声音根和预算，真正提交之前允许延迟。致死音效可利用短租约完成，复位和退出会清理未消费事实。接触效果根据实际位置和方向请求原渲染链。震屏使用既有相机强度和方向。

## 命中停顿

`ActionDefinitionSO.hitStop` 保存攻击者和受击者各自的时长，零为关闭，0–120 ms。格挡有独立开关。合法释放先冻结配置，收到实命中后才向相应实体发请求。暂停从首次可消费的更新开始，用未缩放时钟计时。多目标对攻击者合并，合法受击者各自冻结。已有伤害、受击硬直、击退和震屏仍有各自的状态和日志。

身体、装备和现有敌人消费相同的局部状态。独立投射物、音频、特效和镜头继续运行。短暂停顿里的普攻按原提前输入规则缓存，控制权与 UI 捕获切换会使旧输入失效。

## 运动与接触

`CharacterJumpProfile` 仍是正式横版数据。角色可通过 `CharacterDefinitionSO.sideViewMovementOverride` 明确引用专用配置，其他场合继续读取原场景或 Prefab 配置。调试候选单独租用运行引用，应用和撤销都跟随当前试验，不回写正式资产。高度、速度、落地与轨迹来自原 `CharacterController` 的移动事实。

运动接触沿用原声音根。起跳保留离地前真实支撑，落地读取接触点和落地前的向下速度，抓边与翻越取得实际探测碰撞体。运动事实有物理步和接触代次，墙跳与翻越的同一步不会再播放普通起落反馈。素材起播补偿与接触后的延迟分别保存。制作帧、运动模拟步与反馈毫秒分别显示。
