# LOOKDEV-01 v1.2 实装与观察入口

本轮为独立材质/布光候选，不替换主场或 v1.1 的默认作者配置。

- 候选场景：`Assets/OSSASTRA/WorldRendering/Stylization/SurfaceLighting/SC_SurfaceLightingLab.unity`，Renderer 17，45°。
- 核心组件：`SurfaceLightingRecipe`，Play 后展开“卡通材质与光影”。A 是接手时完整 v1.1 蓝档；B 是真实材质和中性暖主光/冷填充；C 是蓝光、保色收尾、空气和正常窗灯 Bloom，默认 1px、无分档。
- 同光材质比较放在高级面板；切回 A/B/C 才是完整预设。诊断灯光、窗芯和 Bloom 不等于保存的新配方。
- 两个日光副本、三个风格副本和 C 的地表染色副本位于该场景的 `Profiles/`。原 `EnvironmentRoot` 是唯一照明提交者。
- 真实插件只覆盖 7 个物件的 17 槽，精确保留 5 个 Room wrapper 关键词组合；没有全场材质替换、Always Included 或新天气管理器。
- 木、石、屋顶、金属的实际插件字段映射见本机 `artifacts/LOOKDEV-01/SurfaceLighting/RealToon_semantic_mapping.json`，共 31 项语义，不把自主 Toon 的参数名冒充插件参数。

C 的地表染色先保留输入亮度，再混合有效环境色，发生在普通受光之前。草和当前安装的 224 个体素地形块共用 `.35` 强度；木屋、水和角色不在这份 Ground 登记中。只在 C 启用显式标签，A/B 保留原分类。室内不套室外颜色。新 helper 独立于通用 EnvironmentLighting include，旧配置新字段默认为零。

窗口世界位置 `(1.5,1.9,-13.535)`、窗芯 `.85×1.05m`。HDR 窗芯和真实暖色 point light 独立；灯位 `(1.5,1.7,-14.2)`、强度 3、范围 5。没有用整栋墙自发光代替照明。这个窗口属于新增观察样本；A 隐藏新增样本，B/C 显示，因此完整配方成本不是“只换材质”的单变量成本。

C 默认日光 sRGB `#84ACEB`、强度 `1.4`，原环境根太阳仰角 35°；镜头俯角 45°。B 的环境倍率 `.30`。18%作者灰面仅作诊断，不在最终画面显示；分项线性 HDR ROI 原始测量随证据保留，不能用截图 RGB 代替。

## 实现边界

LightingLed 只做可选的保亮度色度增益，默认继续走旧 palette。可见源 Bloom 对每个合法原像素先阈值提取，再固定分母降采样/卷积；非法源为零能量，最终仍需当前接收许可。旧 Bloom 与像素保护分支保留。没有清除黑幕、忽略遮挡、关闭阴影或降低输出分辨率。

资源/所有权：配方只在切档生成一个运行风格副本；禁用/退出按仍占有字段归还。材质只是有限引用切换，不每帧复制。相机、源 Profile、环境根或标签被其他作者改变时拒绝过期整档写回。

## 当前已知边界

角色作者材质没有改动。录像中可正常移动和切换主控；一次真实 New Input System 左键有按下/抬起，角色 ReleaseCount 仍为 0，画面显示既有 `missing-frozen-animation-plan`。因此本轮不宣称攻击验证通过，也没有为了视觉任务修改战斗或动画计划。

同机位静图、25 秒真实 PlayerLoop 录像、GPU 合同与构建采样保存在本机 `artifacts/LOOKDEV-01/SurfaceLighting/`。最终性能与发布结论见后续交付报告；任何尚未取得的 GPU/纯 CPU 数据均不能视为零。
