# ToonSurface01 独立卡通材质候选

本轮新增可以直接赋给3D物体的 `Ossastra/WorldRendering/ToonSurface01`，配套局部Room适配 `Ossastra/WorldRendering/SightToonSurface01`。两者共用同一套受光数学，不是两套材质风格，也没有新增全屏滤镜或天气管理器。原VoxelLit、RealToon包体、Spine和草Shader不替换。

**交付范围是独立Lab候选，主场默认不推广。** Release同版对照、性能采样、30秒录像、保存冷读和主场恢复已完成，详细数字与边界见《交付》。Git发布以publication.json为准。

## 查看入口

- Unity：`Assets/OSSASTRA/WorldRendering/Stylization/SurfaceLighting/ToonSurface01/SC_ToonSurface01Lab.unity`。独立Renderer18、45°，不修改Main默认Renderer。
- Play展开原「卡通材质与光影」→「开发分项对照」。先选择「材质比较：中性日光」或「材质比较：蓝夜暖窗」，然后切「原材质 / RealToon / ToonSurface01」。这条路径固定同一照明与几何，关闭强主题/空气/Bloom/亮度分档/像素化。
- ToonSurface01下可单独切Ramp、允许Specular、允许Rim。这是全局许可×各作者Material的默认开关，木材默认无高光，不因勾选全局高光许可就变成塑料。
- 原A/B/C完整外观配方继续保留；完整配方切换会改变照明与后处理，不能把它当作本轮单变量材质成本对比。
- Editor过程图在 `artifacts/LOOKDEV-01/ToonSurface01/Editor_Day_*.png`、`Editor_Night_*.png`。普通Mesh孤立诊断图为 `Editor_Ordinary_Toon01.png`，该过程临时关闭Room后已恢复，**不是最终绕开Room的交付档**。

## 技术链

源输入保留原BaseMap、BaseColor、UV变换与原顶点色开关；主光使用URP真实方向/颜色/阴影。`saturate(dot(N,L))`进入两处smoothstep，形成暗/中/亮系数。主光阴影单独衰减和染色，不以N·L亮面替代阴影图；GI/环境与额外灯仍沿项目既有单次受光链。

Specular使用半角方向的阈值形状，Rim由视角掠射权重×受光侧决定，两项都受实际主光遮阴影响。Rim不是黑Outline，黑描边继续归现有有限描边后端。

四模板为灰泥/木材/屋顶/石块。当前实际登记7物体17槽，按4模板与原材质身份建立有限运行副本：记录过的Toon档为13份副本；不是每帧复制，也不把四模板覆盖成没有原贴图差异的同一种材质。源材质/模板不作为运行功能开关写入目标。

Room仅精确识别新Shader家族，使用受审的SightToonSurface01入口；未知家族、透明或非登记素材继续拒绝。世界色、合法观察、揭顶、深度和ShadowCaster不借本候选扩权。实际Draw适配证据与图像/GPU数学相互印证，不能只看Inspector或缓存材料名字就宣称GPU路径已通过。

## 后续范围

本轮不做全地图替换、草系统新方案、角色强光重构、整体调色重做或旧60帧任务扩面。2022簇/143块草及其现有风动保持。本轮新增GPU预算通过，但全场稳定60仍未满足；不自动推广Main。
