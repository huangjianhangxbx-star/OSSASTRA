# 实机风格候选：接入与验证

当前主场保留原默认。独立实机候选使用当前主场的完整场景副本：

`Assets/OSSASTRA/WorldRendering/Stylization/SC_StyleCompositeLab.unity`

打开后按 Play，点击顶部中央“实机风格候选”。可切换原效果、蓝色沉浸、红色警戒；2/4输出像素块、6/4亮度档、空气及宽泛光均可独立切换。有限3D比较只改变已登记墙、屋顶、石、柜共14槽，原材质和主光三档支持Editor与Player；RealToon只用于本机已验证的Editor对照，Player入口与API关闭，不改变角色或草的材质体系。镜头45°，原角色切控、移动、攻击、房间门窗和草浪继续工作。

## 独立配置

- `Assets/OSSASTRA/WorldRendering/Stylization/BlueImmersion.asset`：完整蓝色，2输出像素、6亮度档。
- 同目录 `RedAlert.asset`：完整红色，2输出像素、4亮度档。
- 同目录 `BlueImmersionNonPixel.asset`：同算法无像素候选。
- 面板只编辑运行时副本；停止运行不会写入作者Profile。高级值在Profile Inspector，颜色为线性值。导入sRGB十六进制只转换一次。
- 原效果A会同时恢复后期旧链、已登记3D原材质与关闭有限轮廓；不以关闭所有CHAR效果冒充接手原效果。
- 两个独立亮源采用线性峰值4的自发光几何与普通URP局部灯；不提高太阳或人物亮度伪造泛光。

## 原渲染链的接缝

WorldLookController只把可选作者Profile转成不可变Settings；RendererFeature在原Room最终颜色之后消费**当前相机、本帧**的新合法深度与覆盖。新风格为空时走原分支。新Shader不读取旧相机OpaqueTexture/旧Depth，内建后处理保持关闭，没有增加天气根或全场取色相机。

StyleCoverage在已有许可生产时用可选MRT输出：R=合法环境或真实角色，G=真实角色，B=合法室外亲和，A=有效。信息与不支持表面写零并遮住后方贡献；G不由旧环境位取反推断。

旧标签许可刻意不含仅相机窗洞可见的外景，不能直接放宽旧Target0。对此，额外只绘制与相机窗域相交的有限表面之**风格许可**，裁切为Window && !Eye；不绑定标签颜色、不写真实深度，不重画世界颜色。限制128表面/256槽；信息最后写零，错误或超预算保守降级并给状态。

新阶段在RGBA16F中完成主题、解析高度空气和四级宽泛光，最后一次Neutral Tonemap。角色原外缘不进入Bloom源，只在最终合成加入一次。像素块内均色使用完整许可最小值；混合许可块不跨边界平均。分档只处理雾前亮度，雾与Bloom不分档，HUD保持原分辨率。像素尺寸仅认证renderScale=1；不满足时在写入前保守回到原链，不冒称最终输出像素一致。

## 版本与发布边界

场景、Profile、材质及参考素材按项目既有本地资产边界保留；源码和配置说明定向发布，不强行解除大范围Assets忽略规则。商业Shader展开只在已忽略的LocalMedia；生成器保留厂商原代码和本机许可，不上传展开内容。没有插件的环境默认原3D路线，不允许用标准Lit冒充插件比较。本轮Player只交付自主三档；商业wrapper必须在本机生成并完成Editor验证，不能把Editor通过当作Player认证。

原半幅草地的主场性能预算未通过事实继续保留。静态接口/GPU合同、画面正确性、Player帧耗是独立结论；本轮不自动宣布主场稳定60帧。

最终成本、保存重开与收口状态另见交付报告；构建及采样未完成前不把预算目标写成通过。
