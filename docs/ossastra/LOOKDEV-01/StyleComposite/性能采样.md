# LOOKDEV-01 StyleComposite 最终成本报告只读分析

分析日期：2026-11-10。本分析只读取两份已完成报告，不启动 Unity、不追加测试、不修改原始数据。

## 结论

Player 固定机位六态均完成 180 个相机帧和 180 个唯一 FrameTiming；整帧 GPU 实际取得 179–180 个正值样本。相对 originalA，本轮四个风格态的 GPU 中位增量为 **0.739–1.224 ms**，低于计划建议的 2 ms 增量目标。但完整 Toon／描边组合的 CPU 主线程 inclusive 中位增量为 **0.682／1.146 ms**，高于 0.3 ms 目标，不能宣称 CPU 预算已通过；这些数值包含等待及 Native 工作，不能称为纯 C# 有效工作。

**整场稳定 60 FPS 未通过。** 原版底座相机帧间隔中位约 25.3 ms，风格组合约 25.4–26.5 ms；底座本身已超过 16.67 ms。GPU 中位增量满足有限目标，不代表尾帧或整场预算满足。

Player 的五个 Style 分阶段 CPU／GPU／inline sampler **均未取得样本**，必须写 Unavailable，不能写 0 ms。Editor 对应执行阶段确实各取得 180 个样本，但不能将其冒充 Player 的逐阶段成本。

本次实际 Toon 模式是 **ThreeBand**，并非 RealToon。窗口补绘在所有状态端点的 `windowCandidates/windowDraws` 均为 0，不能将本成本表扩大为 RealToon 或室内窗口补绘成本认证。

## CPU／等待与逐阶段 GPU 是否实际取得

### Player

- FrameTiming 的 CPU frame／main／render／present wait／main-minus-present residual：各态各 180 样本。渲染线程的 FrameTiming 时间可用，虽然同名 ProfilerRecorder 的 `Render Thread` marker 未注册。
- Main Thread named scope：各态 180 样本，包含等待与 Native 工作。
- `mainPresentWait` P95 仅 0.0045–0.0049 ms；`WaitForTargetFPS` P95 0.0041–0.0044 ms；`Gfx.WaitForPresentOnGfxThread` P95 0.0008–0.0010 ms。可观察到的这些等待很小，不能解释全部约 25 ms 主线程时长。
- `Semaphore.WaitForSignal` 主线程 marker 未注册，Unavailable。其他等待尚无完整、不重叠的分解；`mainMinusPresentResidual` 仍包括其他等待与 Native 工作，不能称为纯有效工作。CPU、GPU、不同 named scopes 不能相加当作串行总帧时间。
- `Style.HDRSource/LogicalGrid/Bloom.Down/Bloom.Up/Composite`：所有态 CPU／GPU／inline 样本数及 block 数均为 0。原版态、无像素态的 LogicalGrid 为 NotExecuted；应执行的项为 **Unavailable**。字段文字“Recording enabled”不等于成功取得样本。非 Development Player 未产出这些 scope 数据，报告不能证明具体原因。

### Editor

- CPU FrameTiming 各项仍各 180；整帧 GPU 仅取得 159–164 个正值样本，每态缺 16–21 个，缺失不能填 0。
- 五个 Style sampler 在应执行态确实各有 CPU 180／GPU 180／inline 180 个样本；CPU blocks=360、GPU blocks=180、inline blocks=180，unexpectedSampleFrames=0。CPU scope 每相机帧有 2 blocks，不自行除以 2，也不将 CPU 与 inline 重叠相加。
- 原版态五项、无像素态的 LogicalGrid：NotExecuted，正确没有样本。
- `Render Thread` named marker 未注册；`WaitForTargetFPS` 虽 marker 来源有效但没有执行样本，仍为 Unavailable。其余 named scopes 取得 180，不能据此获得完整 CPU 等待分解。

## 可复用的只读 PowerShell 摘要

在工程根执行以下命令只读报告，保留 unavailable/null 与样本数。不要用 `0` 代替 null。

```powershell
$report = Get-Content -LiteralPath 'artifacts/LOOKDEV-01/StyleComposite/player-cost.json' -Raw | ConvertFrom-Json
$report.phases | Select-Object name,cameraFrames,uniqueFrameTiming,
    @{n='CPU_Main_P50_ms';e={$_.cpuMainInclusive.p50}},
    @{n='GPU_n';e={$_.gpuFrame.samples}},
    @{n='GPU_P50_ms';e={$_.gpuFrame.p50}},
    @{n='GPU_P95_ms';e={$_.gpuFrame.p95}},
    @{n='RT_delta_MiB';e={$_.estimatedPixelPayloadDeltaFromOriginalA / 1MB}} | Format-Table -AutoSize
$report.phases | ForEach-Object {
    $phaseName = $_.name
    $_.styleSamplers | Select-Object @{n='Phase';e={$phaseName}},name,expectedExecuted,
        @{n='GPU_n';e={$_.gpu.samples}},@{n='GPU_status';e={$_.gpu.status}},@{n='GPU_P95_ms';e={$_.gpu.p95}}
} | Format-Table -AutoSize
```
