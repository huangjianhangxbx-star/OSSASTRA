## 建议设计

沿现有根管理顺序，在有效输入/AI意图和动作事实形成后计算方向，仍由现 Router/Mapping/Override/Composer/Handle 播放。禁止另建一套直接调用 SetAnimation 的平行权威。

```text
连续逻辑方向 + 当前动作锁向政策
                ↓
模型方向Profile → faceId / mirror / revision
                ↓
结构性方向意图 ─┐
原状态机动作意图 ├→ 原Router / Mapping / Override
                └→ Composer → 唯一Handle
                                      ↓
                            骨姿态求解完成
                                      ↓
                        显隐 + 功能锚点 + 独立装备
```

1. **方向Profile**：坐标约定（世界XZ到相机投影/模型方向）、面集、基础朝向、边界/零输入、镜像、离散混合政策、显隐策略、各面功能锚点。单面翻转与五面Profile并存，不硬编码模型名或轨9。新语义枚举只能追加，保留原序列化ID。
2. **动作方向政策**：接受时锁定、释放时采样、允许持续转向/阶段转向、强制特定面明确配置。结构方向刷新不重新捕获攻击快照、不重受理、不再收费、不重复事件。移动朝向与攻击瞄准优先级保持用户要求。
3. **Composer职责区分**：增加明确的结构性轨道角色或保留条件，让方向与全身攻击共存；其他非兼容轨仍按原独占规则清理。不要全局豁免高轨，也不把所有方向偷偷塞到攻击owner来绕过边界。
4. **缓存与生命周期**：方向变化revision独立进入可观察缓存；静止时同一X符号内转瞄准也能换面。ClearAll/重建/池复用后重新建立结构表现，不能复用旧实例状态。身体动作身份与结构方向身份分开。
5. **显隐策略**：优先模型Profile配置。仅“源裁切＋方向动画”在小蓝默认姿态不足；原型清中文不等价于原作；原作AABB slot显隐可作为独立渲染适配候选。避免修改第三方Slot.get_A源码，先找当前4.3渲染扩展点，并验证不污染共享SkeletonData。不得改附件永久数据以伪装兼容。
6. **功能锚点与独立装备**：经真实动作/方向/镜像确认语义手点、武器/投射点；辅助分支接管不能误挂到场外中文手骨。装备仍为SO配置骨/槽跟随与语义动画，独立处理显隐/前后排序。玩法攻击向量、命中体与渲染面不绑定成同一概念。

## 三条表现路线

| 路线 | 优点 | 已知限制 | 本轮建议 |
|---|---|---|---|
| 只用源裁切＋方向动画 | 最接近纯Spine作者流程 | 小蓝起始mask位于后段，不会遮住所有场外分支 | 不能当小蓝生产完整方案 |
| 原型式清非当前中文附件 | 接入直观，现原型可参考 | 拼音仍可绘制；辅助接管和未来模型结构需实测 | 保留为研究对照，不全局强制 |
| Profile选择显隐与挂点适配 | 保持模型差异与SO作者入口 | 要落实4.3时序/共享数据安全/装备遮挡 | 推荐DIR02主线，先用小蓝副本做有界验证 |

## 实施顺序与完成条件

- G0：确认正式多面资产入口、4.3导出与合法素材；方向/锚点命名及坐标约定。未确认不覆盖rozeul正式绑定。
- G1：纯方向选择及锁向政策合同，含边界、零输入、镜像、同符号转向。UI/AI/有效玩家意图共用明确接口。
- G2：在原SO工作流实现结构意图/Composer职责与缓存；实际全身攻击、受击、闪避和同名重播不清方向，也不重触发动作。
- G3：唯一隔离候选内验证4.3骨姿态、显隐和双实例；不复制多套场景。
- G4：独立装备骨跟随/语义动画/遮挡，多面功能锚点与命中方向保持一致。
- G5：保存重开、域重载、池/生命周期、同X符号静止瞄准、开包控制权限回归；录少量真实画面后再切正式绑定。

小蓝原作全攻击碰撞配置、全部技能的转向锁、每个辅助分支的所有接管时点，以及完整独立装备多面遮挡仍不是已验收事实。把它们放在对应Gate内补证，不能宣称本研究已完成全角色生产支持。
