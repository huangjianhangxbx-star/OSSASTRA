# 外缘柔光 v1.1

当前主场已接入独立外缘柔光。打开“角色光感”，在“外缘柔光”分组调节。A只关外缘，B开启外缘，C只看新增能量；当前内侧亮边、染色与高亮保护参数保持。运行调节使用接收者副本，原SO不会被悄悄写入。

默认候选：开启，宽2个1080p等效最终像素，强度.22，预算.18，柔度1.5。实际内部半径=宽×渲染目标高度/1080；512覆盖槽不是最终像素。用户原默认1/.28/4/1.23/.35/1.2/2保留。主场Profile为CharacterLightingMeasuredSoftExterior。

完整覆盖缓存只负责自然形状。实际能量来自本帧有效主灯/合格点灯、自然轮廓和源alpha；灭灯、失权即消失。场景最近深度合并透明人物，源/目标/逐像素supercover路径同时限制扩散。没有旧面历史、没有全场Bloom依赖。

每角色先独立卷积，再把合规结果合入能量层。有环境Look时，环境先做Focus/Bloom，之后第一次加入柔光，再接受一次空气/调色；防止量化后减法残差或空间二次扩散。无Look走同一PositivePass直接追加。HUD不参与。

专项技术验证通过，审美仍待用户确认。原尺寸A/B与局部裁切、C诊断和16秒实景录像仅本机保留（包含受限素材）。详细结果与本机路径见 docs/agent-sync/tasks/2026-11-05-char-light-01-v11.md。

资源：当前1600×900，新增3RT/3Material/7Draw，约38.45MiB，原Coverage另2MiB；.75 RenderScale实际1200×675约21.63MiB。三轮开关释放到0并稳定恢复。整个PositivePass CPU命令构建off约4.99–6.22ms、on6.54–7.42ms，编辑器波动且非模块独占；GPU耗时未测，不宣称零开销。

范围限制：只认证当前四种Spine/DepthPlane MeshRenderer家族；活动Sprite、非Always stencil、超预算/无数据保守关闭柔光。当前实际DX11/主场MSAA与RenderScale1/.75已测，其他图形API/Player/任意Mesh LOS与多层楼未代签。天空或无合法表面附件的空洞边界保守不画；空气按目标合法深度近似，不宣称物理散射。
