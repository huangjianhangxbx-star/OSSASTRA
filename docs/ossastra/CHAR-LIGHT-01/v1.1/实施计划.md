# 受光外缘柔光增量实施计划
Goal：在原角色光感之上增加独立、薄淡、受方向光与可见性约束的外缘。
Spec：用户2026-11-05 CHAR-LIGHT-01 v1.1增量补丁。
Architecture：复用完整角色Coverage与原Positive世界帧；每角色独立发光源重绘和有界扩散；新像素同时检查真实新深度、源/目标当前许可与路径，不能采黑色当权限。没有历史柔光。保留原控制、原参数与本体alpha。
Tech Stack：现有Tuanjie/URP、Spine、CommandBuffer、现有uGUI运行副本。

- [x] P0：Native读取当前主场和参数、记录原dirty/HEAD，保存可恢复现场；隔离测试存档。
- [x] P1：先新增GPU和Settings失败合同；实现独立RGB能量+深度源、当前合法深度解析与合成。1080等效2px默认，换算renderHeight/1080，逐角色分离，不改内带预算。
- [x] P2：前墙截线/目标实体/黑幕与许可岛/双角色/冷暖及零强度合同；原尺寸A/B+局部裁切与短片；记录Draw/RT/资源释放。无法证明的家族保守关闭并报告。
- [x] P3：主场增加显式Shader与非零推荐Profile，原值不覆盖。面板独立A/B/C。保存重开、有限启停与原路由恢复；只提交本轮白名单并核远端SHA，完成待机。

文件责任：CharacterOuterGlowCache及专属Shader管理自有RT/Material；CharacterLightingSystem负责角色参数与原灯资格；RoomPositivePass在最新合法世界/标签完成后、WorldLook/HUD前调用；Settings/Panel只定义与调整运行副本。无每角色Camera/CPU回读/每帧材质创建/新场景/新管线。

验证只覆盖该模块，不跑音频/合成/库存历史回归；技术通过不代签用户审美。原WorldLook对角色排除，柔光先应用一次EnvironmentFog再按目标合法环境后处理边界处理；以真实插入点核查限制。
