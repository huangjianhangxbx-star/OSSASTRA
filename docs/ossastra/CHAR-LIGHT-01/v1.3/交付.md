# 强日光防泛白：A级定向校准

本轮采用既有保护的P1校准，不增加Shader算法、主光专用保护或新光照系统。两角色分别保存完整原A（K16/C32）与推荐B（K0.7/C1）；除K/C外，所有效果开关与参数和实际接手副本一致。轻档1/1.3仍泛白，强档0.4/0.8偏暗，故采用中档。全部候选保留原环境染色、内轮廓、外缘柔光及高亮保护。

## 已测原因

实际作者Profile与运行副本都是16/32，真实System.Bind后GPU也回读到16/32、保护量1。无遮挡样点的增益亮度Y=1.131873，没有超过16，故保护不启动；B同一样点压到Y=0.928892。源图/材质/透明约定未改。关内边、关外缘、同时关二者都没有消除Freycia内部大块近白，因此不以取消已认可特色效果处理主体问题。

正式HLSL的私有float探针中，Freycia统一世界样点采atlas的保护前RGB峰值约1.094，B降到普通显示范围内。**该探针无真实阴影重放，R=0、白顶点色、统一世界点，不是当前骨架全部片元，也不是屏幕白色面积。** 完整字段见`有限GPU采样.json`。

实际GameView RT为1600×900 `R8G8B8A8_SRGB`；已分配Opaque副本为800×450 `B10G11R11_UFloatPack32`，私有探针为32F。部分活动cameraColor RTHandle不可读取，故不宣称已锁定“首次截断的精确附件”。证据能确认主体受光输出已超普通显示范围、旧保护未启动、显示端大块近白；不能把许可mask的8bit当主体颜色格式。此次不改HDR或全局tonemapper。

## 同机位效果与保护范围

正午A1/A2的9处角色内部ROI逐像素一致。Freycia白发冠31×17内部样本，RGB均≥250的占比从99.62%降至0%，平均编码RGB加权Y从254.962到234.788；上/下浅肤的P90-P10从0.939/19.170到17.357/36.571。该统计描述8bit显示差异，不代表线性亮度、整个人物或美术审美阈值。深线仍可辨，B保留亮发而没有强档明显压灰。

暮色和深夜的6处内部ROI A/B完全一致。暖/冷室内受灯浅肤受到总保护压缩：暖室下身编码亮度约下降8%，阴影发冠不变；目视暖光、冷光各自颜色与可读性保留，没有足够理由增加P2。室内并非“完全不受影响”。名为eaves的摄影机位样本仍明显受光，不能将它冒充全阴影；真正阴影证据另有室内发冠。八个45°旋转步骤完成，未改相机俯角或转向策略。

正午角色包围之外的平均RGB差，A/A为0.077234，B/A为0.086870，动态像素属于同量级；不使用全图最大差虚报世界无变化。原始PNG与完整ROI统计保存在本机`artifacts/CHAR-LIGHT-01/v1.3/`和`Candidates/CHAR-LIGHT-01/V13/Analysis/`。原始图片没有重编码或修图。

## 使用与保存语义

运行原主场，展开“角色光感”，选择观察角色，在“强日光保护（完整效果对照）”中选择完整原A或推荐B。它只Clone该角色运行参数，不切主控、不写作者Profile、不改世界灯和场景。高级项明确：开始保护值越高，保护越晚；渐近上限越高，允许越亮，不是保护更强。

四个持久候选位于`Assets/OSSASTRA/CharacterLighting/Profiles/`，见`独立配置清单.json`。旧两个作者Profile保持；Main原dirty不隐式保存。**重进Play后可以再次一键恢复B；本轮没有把B暗中改成Main自动启动默认，也没有更改独立Player默认。** 编辑器开发面板的载入入口不伪装成Player的AssetDatabase功能。

A/B覆写期间拒绝将运行值经“保存当前默认”误写到原作者Profile，仍可独立另存候选。正常手动调参的旧保存功能保留。切回A仍是完整接手值，不是关闭所有角色光感。

## 最终读回

四候选Native创建、重新编译后冷读、再次进入Play全部一致，原两个Profile及Main磁盘SHA不变。实际面板两角色A/B按钮接线、Clone隔离、他人参数/主控保持、方法和按钮拒写原Profile、恢复及关闭/重新展开/disable后的保护均通过；普通手动调参的显式保存仍保留。该合同通过调用按钮事件验证，不冒称物理设备输入。只读源业务4文件SHA守恒，两轮隔离路由已归还，临时Shader已Native按SHA清理，摄影输入/动画/环境借用均归还。最终Main Edit/ready、原dirtytrue保留，最近900秒Console error缓存无条目。

只完成A级定向校准和已有面板接入，没有另打独立Player或代验全玩法/真实移动手感；原模型模糊和帧率不属于本轮修复。末段面板曾出现未归属的运行参数变化，已保存现场；稳定A/B采用此前冻结摄影系列和真实绑定采样，不将变动现场用作效果证据。
