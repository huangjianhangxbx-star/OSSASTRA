# 角色强日光保护：本机执行清单

执行用户v1.3批准方案，先P1校准已有保护。保留环境染色、内轮廓、外缘和高亮开关；不调全局曝光、太阳、底光、原图和透明混合。

现场完整A是两角色K16/C32，其他实际值见本轮baseline JSON。先比较K/C：轻1/1.3、中0.7/1、强0.4/0.8。中档正午内部细节恢复，强档偏灰，轻档仍有大块泛白。检查认可环境后再定稿。没有额外保护强度滑条或新光照系统。

验收限A级参数及必要UI接入：真实GPU绑定与浮点辅助采样、同机位A/A噪声和A/B、五环境、现有门窗许可与透明一致性、资产保存读回/Play重开。若更改Shader数学或共享绑定，升级B级；目前不需要。

候选单独保存于既有角色光感配置目录。原Main已有dirty，不隐式Save整个场景，不覆盖未归属作者Profile。完整A与已调好B应有可直接使用的入口；保存前登记准确资产路径和推广范围。

所有摄影/输入/动画/时钟改动只借用于隔离Play并归还；GPU临时Shader只用于有限采样后删除。运行截图是屏幕证据，浮点探针是受限数学证据，两者不互相冒充。
