## 1. 实际交付范围

在当前唯一主场增量接入两名原角色的环境染色、完整人物内侧受光轮廓和合计高亮保护，并提供中文角色光感面板。保持原EnvironmentRoot/Frame、角色控制与动画、装备状态、RoomSight许可、Upright深度和遮光权威。

主场：`Assets/OSSASTRA/GroundWorkshop/Samples/KT-VIS-04/SC_RoomVisibilityLab.unity`。本轮不新建平行主场；末次Native读回为35°俯角、yaw45°、距离25、FOV35。

入口与调参见[操作与参数](操作与参数.md)，源码组织与限制见[架构与接入](架构与接入.md)，实施顺序见[实施计划](实施计划.md)。

主要新增职责：

| 模块 | 交付行为 |
|---|---|
| `CharacterLightingSettings / ProfileSO` | 三效果独立参数、Clone运行副本、有限值校验；作者配置不保存灯列表/RT/动作 |
| `CharacterLightingReceiver` | 显式身体与既有装备表现端口登记；原Root在表现提交后推进，失活/脱手撤销 |
| `CharacterCoverageCache / Coverage Shader` | 两角色隔离的完整alpha覆盖，不用墙/黑幕截线充当自身外缘 |
| `CharacterLightingSurface / Rim / Color` | 有限内带、方向投影、有来源的轮廓预算及主体＋轮廓合计增益软肩 |
| `CharacterLightingSystem` | 当前合法相机/环境租约、逐对象参数、主灯阴影/云及登记点灯保守资格 |
| `Development/CharacterLighting` | 可折叠中文uGUI、常显滚动条/提示、观察选择、对照/恢复、环境时钟与显式另存候选 |
| 原Environment/RoomSight/CharacterRoot接缝 | 天空色桥、合法片元着色、可选接收者组织；不建立第二套角色框架 |

没有新建Bloom后端、每角色Camera、逐帧CPU图像读回、逐帧重打Spine图集或额外角色移动/动作提交。未改写原图和Spine源资源，参考图片只留本机。

## 5. 性能采样与资源预算

已只读核对`performance-main-performance-b.json`的完成摘要，并按Root确认口径记录：团结`2022.3.62t16`、RTX 4080 SUPER、DX11、1600×900、同相机与角色位置；每档8帧暖机后30帧测量。该轮`complete/restored/profilesUnchanged=true`，恢复冲突为空。原角色空闲动画继续，不删除敌人/装饰或降低分辨率制造对照。

| 模式 | RoomMask命令构建CPU中位/ms | Editor Draw中位 | 覆盖draw | 覆盖RT |
|---|---:|---:|---:|---:|
| 旧效果 | 3.7742 | 390 | 0 | 0 |
| 仅染色 | 3.8166 | 390 | 0 | 0 |
| 加轮廓 | 3.9054 | 395 | 5 | 2MiB |
| 全组合 | 4.1615 | 395 | 5 | 2MiB |

这里CPU采样的是RoomMask命令构建作用域，包含原工作量，不是新模块独占CPU时间。UnityStats是主相机结束时观察的Editor渲染计数，也不是逐Pass精确成本；本轮“加轮廓”个别采样Draw为398，表中列中位395，没有删去该波动。

可取得的GPU读数是带API延迟的latest-completed**整帧**计时：四档中位约9.735、8.103、8.770、8.420ms，每档29或30个有效读数，帧间波动明显。这些异步值不能直接相减为本模块GPU增量，不能据较低读数宣称加效果反而更快。模块独占GPU增量与低端硬件性能仍未测。

覆盖缓存为一张`1024×512 R8G8B8A8_UNorm`，两个独立512²槽，约2MiB颜色存储；无深度、MSAA或mipmap，另有一个覆盖材质。最多2个角色、每角色8个明确Renderer、每Renderer16个材质槽；超预算保守停该帧轮廓并诊断，不串角色槽位。主场当前回读5次覆盖draw是样本，不是成本上限。

受支持的是实际Spine MeshRenderer与受限Simple、无SpriteMask的SpriteRenderer家族。任意SkinnedMeshRenderer、SpriteMask/其他Sprite绘法、全部材质、更多角色、多层建筑和任意Mesh遮光均不据本轮样本签为兼容。

局部轮廓光采用同房/距离与三条登记OBB线段的保守资格，是整角色近似；主灯复用真实阴影/云。没有用玩家观察许可替代物理遮光，也未声称补齐所有附加灯逐像素阴影或GI。

正式库存换装、投掷及脱手流程未测。最后脱手fixture的`attached=false`，B角色已离开当前机位，受测前提不成立；没有把它填为通过，也没有把这个夹具结果伪装为正式玩法失败。本轮保留实际源ownership、装备同帧提交和GPU组合证据，不为这一项扩大到外部玩法改造。

SceneView实际渲染、真实销毁/跨场、保持Play内的真实热重载、完整强灯扫值、视频逐帧无闪烁、Player、其他图形API、实体硬件输入及全部角色/装备内容均未签。独立Camera无消费者检查和3轮资源启停不冒充这些未测场景。基础效果不依赖Bloom，当前Bloom控件不可用；不以Bloom关闭代替角色许可检查。

用户已批准本轮截图参数，不代表任意镜头、动作、角色原画或未来原创素材都已审美验收。换角色的接入方法与关闭回退见操作文档。
