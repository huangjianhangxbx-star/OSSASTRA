# 动态物质实验室

在现有 Tuanjie 工程打开 `OSSASTRA → 实验室 → 打开动态物质实验室`，或双击 `Assets/OSSASTRA/OSPhysics/Scenes/SC_DynamicMatterLab.unity` 后点 Play。实验场只有相机和独立实验室控制器。退出 Play 会释放模拟、纹理与临时碰撞体。

- 左键点按或拖动画笔。数字 1–8 依次是水、油、沙、草、木、加热、擦除和测试障碍。圆形笔刷只作用于世界画布。
- 中键拖动或 WASD 平移，滚轮以鼠标所指为缩放中心，Home 回到全览。
- 开场在闸门左侧蓄水。点「开闸」或按 G，可看水经槽底进入右边；闸口还有物质时合闸会等待通道腾空。
- 点「油水分层」或「燃烧灭火」立即重摆初始物质，也可用「空白」后自行布置。加热笔给有限热量；燃料耗尽后只留灰和逐渐消散的烟，水接触处可局部灭火。
- 空格暂停与继续，暂停时 N 或「单步」推进一格时间。「原始网格／自然画面／温度／碰撞」切换同一份模拟状态。画布上的探针显示格数据。
- `Config/MatterCatalog_SAMPLE.asset` 保存实验值。模拟从配置复制运行数据，画笔和反应不回写该资产。相对密度和填充量采用整数，液量满格为 255，热量上限 1023，流率、热量传播与燃耗按 30 Hz 的每步计。

## 技术来由与取舍

| 题目 | 可核对的公开资料 | 本实验 |
|---|---|---|
| 规则模拟 | Petri Purho 的 GDC 2019 场次说明大型连续世界中的落沙模拟，以及可破坏刚体与物质模拟并用。 | 有限 2D 网格，重力向下。颗粒原地步进，液体使用每格有限容量、方向交替以及按相对密度交换。 |
| 液面、热和气体 | 公开场次页没有给出逐项参数、数值容差或水油混合方程。 | 22 格封闭池同源离线对照，400 步后离散格法覆盖 7 格，保守通量覆盖 22 格且总量 2295，保守方案入选。水油每格只存一种液体；烟可与非阻挡物质同格并有上限；不同燃料共享热反应规则。 |
| 区块和并发 | 公共资料可以确认大世界缩放是题目。可见的视频描述没有公开完整的线程限制和状态契约。 | 32×32 活跃区块，变化唤醒本区和相邻区；渲染用独立区块修订号，和模拟活跃状态不绑定。先保持单线程。 |
| 碰撞 | 原作的可破坏刚体技术属于独立结构。 | 既有横版地编以地图格定义尺度，常用参考为角色高度推导的约 0.72U/格，64 绘制像素/格。实验场采用 0.1U 的自有格，用明确登记的 BoxCollider2D 和 PolygonCollider2D 栅格化。闸门与笔刷障碍同时更新网格及 Collider。 |
| 表现与光 | Unity 的 2D URP 光照需要 Renderer2D 与匹配的 Lit 材质。本机正式 D-New 用自己的相机与角色/世界灯图。 | 同一 URP 工程独立提交一张动态格纹理。自然视图的平滑着色、空气层和最多 4 组燃烧光都仅在实验画面；没有正式 OSLight 运行时接线。将来需要可独立调用的世界灯图消费端，再做兼容。 |

[Noita GDC 2019 场次说明](https://www.gdcvault.com/play/1025695/Exploring-the-Tech-and-Design) · [GDC 官方公开视频及描述](https://www.youtube.com/watch?v=prXuyMCgbTc) · [Unity 2D 光照材质说明](https://docs.unity.com/en-us/engine/6000.0/manual/unity2d/2d-urp/2d-index/prep-shader)。网页可读到视频描述，无法核对完整口述。项目会话链接的网页端没有可读正文，按用户提交的本地计划执行。

## 性能

本机 i7-14700KF、RTX 4080 SUPER。以下 CPU 核心用 .NET 9 Release 运行。同一装置每档各测 900 个固定步；局部列为持续补水，密集列定期补燃料，补料时间不计入步时间。

| 格数 | 空场 P95 ms | 稳态水池 P95 ms | 局部流动 P50 / P95 ms | 密集燃烧 P50 / P95 ms |
|---|---:|---:|---:|---:|
| 256×128 | 0.0003 | 0.0002 | 0.1690 / 0.2345 | 0.9650 / 2.6279 |
| 512×256 | 0.0002 | 0.0002 | 0.0824 / 0.1193 | 3.8956 / 4.1060 |
| 1024×512 | 0.0004 | 0.0004 | 0.1573 / 0.2325 | 28.2613 / 29.5096 |

核心测量区间线程分配均为 0 B。密集 1024×512 到达 30 Hz 的 33.3 ms 上限附近，给渲染和输入留下的余量有限。大图常见局部运动和全图同时燃烧应分别评估。Unity Editor 的 UI/纹理开销不在纯核心测量内。

## 验收结果

在 Tuanjie 1.11.1（2022.3.62t18，URP 14.2.0-t1）打开同一 Unity 工程的独立场景验收。逻辑小集 9 项通过。下表中的场内画笔使用实际 Game View 和 Input System 的合成输入。

| 规格 | 验收结果 |
|---|---|
| T01–T03，流动、守恒与分层 | 闭闸单步后右池为 0。开闸 70 步后右池收到 38,296 单位水，水总量仍为 148,410。纯核心通过水先、油先两种顺序。场内分层 240 步后，水和油的质量加权高度分别为 11.24 和 14.48 格。 |
| T04、T08，沙、开闸与跨区块 | 场内闸门真实 Collider 与模拟阻挡同时切换。专门加窄槽的场内测试中，510 单位沙先堆在关闭的闸门上，开闸后落下且账本不变。纯核心覆盖跨段水、热与颗粒唤醒。 |
| T05–T07、T13，燃烧、灭火和未预设组合 | 空白区用画笔布置草、木、油，再只点草。33 步后观察到 26 格燃烧，其中 17 格为木。预设的左、右着火格分别从 18／39 变为浇水后的 11／39，出现灰与烟。纯核心覆盖隔断、燃尽、烟上升与衰减。 |
| T09、T10，生命周期和操作 | 实际检查暂停、单步只进一格、重置恢复、离开再重进。空白世界逐个试用八种笔刷，按钮点击未送进画布。快速拖动检查的 13 个中心全部有油。相机缩放和平移后，投影点正确反查到同一格。 |
| T11，显示与碰撞 | 暂停在第 71 步切换 A/B，世界状态哈希保持 3159AE701986557C。四种视图都已检查，画笔障碍和闸门的模拟占格与 Collider 核对通过。正式 OSLight 接入受上文的耦合边界限制。 |
| T12，负载与隔离 | 同一 Unity 工程完成三档纯核心和 30 秒场内测量。新场景依赖检查没有发现实验目录外的项目资产。正式横版、既有岩洞样板、工程构建入口、图形／输入设置以及包清单的前后 SHA-256 一致。 |

在 1920×1080 Game View 下，实验场持续运行 31.00 秒，记录 930 步（30.00 Hz）。该样板模拟步耗时中位数 0.0004 ms、P95 0.1117 ms；活跃格平均 1,372、峰值 10,240。Tuanjie 编辑器帧耗时中位数 1.18 ms、P95 1.60 ms，平均 794.6 FPS。测量仅覆盖实验场，未打独立 Player，也未做全局 GC 归因。

本机的 `Reports/OSPHYSICS-01` 存有两张同帧 A/B 对照、碰撞截图、三段现象截图、自由绘制截图和 22 秒的 `08-lab-demo.mp4`。

验收所用 Unity 本地基线为 871bcbe1880c3c563e4a7b6562a229f1fa253734。实验模块包含可导入原工程的源码、场景和 SAMPLE 配置。运行依赖宿主工程已有的 URP 与 Unity Input System（本机使用 URP 14.2.0-t1）。独立 GitHub 源码检出需要先备好宿主工程及对应包。

## 已知边界

这是实验规则。当前液体均衡为受支撑水面的保守近似，只解重力方向与横向移动；高压倒灌、任意地形坍塌、同格液体混合及正式角色交互属于独立议题。自然画面是本次原创的程序材质。编辑器在 Play 中热重载这些脚本后，应退出重进以重新开始本场。普通退出再重进已经验证。
