# 持续圆锯的配置与验证

## 在正式横版里使用

从团结编辑器打开 `SC_SideViewTitle` 并点开始。切到芙蕾茜娅，在脱战空闲时点角色 HUD 的右手装备格，在 Q 或 R 列选择「圆锯」。选择 Q 时用键盘 Q 或 Xbox Y，按住进入持续段，松开后播放一次收招。需要卸下时在同一列选择原技能或「清空槽位」。E 仍由主手职业技能表的固定槽负责。

## 在 Inspector 中调整

- **技能与来源。** `FreyciaSaw_Ability` 的 `action` 指向 `FreyciaSaw_Start`，`executor` 指向 `FreyciaSaw_Executor`。技能列在芙蕾茜娅近战刀的 `FreyciaSaw_Loadout → experimentalChoices`，原职业默认选择仍可用。候选 SO 与本机 Spine 资源在 `Assets/OSSASTRA/LocalMedia/FreyciaPreview/SkillHold01`。
- **三段动画。** `FreyciaSaw_Executor` 的 `loopAction`、`endAction` 分别指向另外两个动作 SO。三个动作 SO 的 `animationLogicId` 分别在 `FreyciaPreview_Animation` 的 Skill 14、15、16 找到 Track 0 片段。只有 Skill 15 开启 Loop。当前按原片段时长播放，起手约 0.133 秒，单圈约 0.067 秒，收招约 0.400 秒。更换动画时同步对应动作的 `finishAt`，End 的 `attackReadyAt` 随 `finishAt`。如果新收招有真实架势恢复事件，可在 End 动作填写 `postureRecoveryEvent`。现有素材无该事件，由收招或取消清理。
- **节拍与命中。** 执行器的 `movementScale` 为 1，`pulseInterval` 为 0.20 秒。循环开始 0.20 秒后打出首击。技能 SO 的 `releases[0]` 是脉冲模板，当前每次 12 伤害、8 架势冲击。扇区距离 1.8、角度 100°，冷却 0.4 秒。正式横版由架势流程处理动作受理，只在第一次实际投递提交装备来源费用。
- **普通攻击。** 右手装备页的主手动作组仍指向一个有序的动作 SO 列表。替换想改的段位，调整该动作的 `animationLogicId` 和时间／伤害，按原连段规则验证。段位依旧决定连段语义及覆写上下文，显式动作动画会随所选动作 SO 生效。

## 验证

- 正式标题进入 Tut_01，使用隔离存档与虚拟输入设备。Q 和 Xbox Y 均完成三段，阶段共享执行 ID。早松和同次输入更新内按松都走收招，跳过循环伤害。
- 持续中角色正常移动并保留锯击循环，另一主攻击保持锁定。虚拟键盘和手柄各在练习目标结算两次，每次扣 12，目标叠加第二个碰撞体仍只结算一次。结束后脉冲停止，切人、设备拔出、暂停菜单捕获及能力禁用均清理了动作。零架势时仍可使用。一次执行的两次真实投递共扣一次装备耐久，禁用装备来源也会取消动作并清理。另用正式战斗结算给出致命命中，观察到取消、停止脉冲及队友接管，队友未继承按住的 Q。
- 持续时实际走门从 Tut_01 进入 Tut_02，旧动作取消。所选 Q 技能和装备实例随会话保留，过门前按住的 Q 不会触发新技能。由原路返回后重新按 Q 能正常开始。
- Blue 的普攻替换在原流程实际播放 a2 并使用替换动作的伤害。默认动作四段逐一核对，举盾移动、蓄力冲锋切相和俯冲命中腾起在正式场通过。
- 真实三段动画使用原始 Spine 工程副本导入。本机合并骨架保留原有 16 个片段并验证恢复与镜像。独立装备表现仍从各自的资产和手别取用，圆锯本体由角色 Spine 绘制。

试玩手感、实体手柄与独立 Player 留给对应环境验证。本次 GitHub 提交包含游戏逻辑和此指南，芙蕾茜娅本机媒体及其装配留在本机。
