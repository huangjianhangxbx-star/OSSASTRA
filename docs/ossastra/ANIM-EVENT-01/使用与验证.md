# ANIM-EVENT-01 动画事件与普攻连段

## 配置入口

1. 在 `SC_SideViewAdventure` 的芙蕾茜娅角色定位 `FreyciaShadow_Animation`。依次展开 **Melee → Attack 1 → Clips → 事件响应**。小蓝在正式场使用 `BlueFiveFace_Model_Override` 的对应规则。
2. 从该片段的源事件列表选响应。Hit 可配置释放、音效和刀光，动作结束标记用于完成当前动作并开放接招。架势恢复可勾在对应事件下。
3. 动画重新导出后，能唯一识别的事件采用新时间和原偏移。缺失或存在歧义的绑定保留原参数，可在原片段重新选择。
4. **横版攻击调试台 → 动画与事件**可定位同一 Mapping，播放中的临时候选在下一次出招生效。使用「保存此动画映射」写入目标资产。旧 EventCalibration 保留作兼容和恢复来源。
5. 角色定义和武器动作组都显示「普攻连段」。有已生效武器动作组时，看调试台列出的武器配置。没有动作组时看角色默认。预输入只记最近一次合法按下，实际结束事件仍决定何时接刀。
6. 在招式效果中选择 `SpineEvent` 或换相触发时，下拉从当前场景的相关 Mapping 列出事件与片段。旧同名匹配仍沿用原作用范围。没有 Spine 时序的圆锯继续用起手、维持、收招的原相位驱动。

## 迁移与验收

芙蕾四段源事件被旧的校准时间阻断。第一段校准仍吻合，第二刀的结束标记已由 0.200 s 移至 0.267 s，第三、四刀结束标记实际为 0.433 s、0.300 s。当前 Mapping 已写入四套响应，保留源校准的音画引用、帧偏移、锚点与恢复事件。导入预览共核对 35 个片段，包含小蓝基础 Mapping、实际模型覆写，以及芙蕾基本攻击、移动和相关旧校准技能。重复预览确认已有绑定，角色数值 .12 / .45 / 空挥可续。小蓝两组武器保留 .25 / .625 / 空挥可续。

- Core 定向 49 项通过，覆盖预输入期限、零值、命中要求、最后一段、空挥与主手序列。另以实际 Spine 事件模型定向检查同名身份、移时、删改和同帧逻辑／音画排序。
- Unity 编译成功。正式场通过 Input System 合成鼠标记录到四个动作 ID、四段实播与四次释放。用户也确认四段顺序可播。
- 小蓝模型覆写经正式输入复测，记录到 2 次已迁移脚步，普攻 Hit、Break、End 来自新配置。正式 Q 仍走原定时配置。
- 现有横版手感调试台 32 项通过。包含圆锯真实 Q 起手、移动维持和收招、换相词条一次激活、下冲命中反弹、架势清理与零架势承伤破防。该次下冲记录未观察到触地回执，角色恢复空闲。
- 同帧效果与输入逻辑经过定向检查。尚未逐项人工操作全部 Inspector 分支及所有同名源重排。Unity Game View 与正式发布构建各自使用相同的序列化字段，独立 Player 构建不在本轮验证中。
