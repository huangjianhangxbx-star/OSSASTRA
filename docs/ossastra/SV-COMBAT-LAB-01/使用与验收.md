# 横版 ACT 攻击调试台

## 进场打第一刀

1. 从团结编辑器菜单 **OSSASTRA → 战斗 → 横版攻击调试台** 打开窗口，点 **进入独立测试场并试玩**。退出 Play 后回到原先编辑的场景。
2. 在 **试玩与记录** 选择角色、固定靶、平地和面向右，把目标距离设为 1.20，点 **按此条件复位**。点回 Game 用当前正式按键普攻，或点窗口的 **请求普攻**。两种来源在记录中分别标明。**正式按键与当前状态** 显示本机绑定。
3. 在记录中选刚才这一刀，查看输入、状态、动画、判定、反馈五轨。查判定时看实际查询的球心、半径、朝向、目标和扣血回执。Spine 的 Hit 事件与正式释放是独立的时间点。调试窗口操作完要继续用键盘时，点回 Game。
4. 打开 **参数与预设**，把普攻第一段的释放时间推后 0.025 秒，点 **应用候选并复位**，再用同一方式打一次。**用基线复位** 可切回原参数。导出本次诊断可得 Markdown 和 JSON，保存在工程的 `Reports/SideViewAttackLab`。
5. 要保留下次继续试，用 **另存实验预设**。随附 `ACT_Rozeul_Basic1_第一段微调`，在 temporary-a 的初始主手配置上可重开读取。它包含第一段结束时间 +0.025 秒、基础伤害 +1、代表技能冷却 +0.1 秒。读取后再应用候选。写回正式来源有单独的字段勾选和冲突检查。

## 测哪些动作

训练场复用正式场的两个角色及主手装配。temporary-a 当前装备支持角色默认普攻、猎人原型Ⅰ（四段）、猎人原型Ⅱ（两段），Q 为 hunter-break。temporary-b 当前装备 FreyciaShadow_MainHand，使用角色默认普攻，Q 为 al-stab。「观察与试放技能」可切到已装配的 Q、E、R 槽，同时切换候选参数来源。角色移动、跳跃、架势费用、受理、动画和伤害都走项目原有运行链。测试场提供空挥、固定靶和普通受击体，平地、墙前和台边可独立选择。固定靶用来测时序与伤害，普通受击体用来观察受击位移。

## 参数改到哪里

| 参数 | 生效来源与单位 |
| --- | --- |
| 输入提前、缓冲与连段接续 | 当前实控角色配置和当前主手动作组，秒 |
| 各段释放、移动许可、再次攻击、结束、基础伤害 | 当前有效 ActionDefinitionSO，优先 eventTimeline，缺省读取对应时序字段。时序为秒。效果独立主导伤害的段仅开放适用字段 |
| 默认普攻前移、半径 | 实控角色 CombatMeleeHit，世界单位，影响实际 OverlapSphere |
| 主手段的持续接触、扇形、位移与末段收尾 | 当前有效 MainActionProfileSO，角度为度、长度为世界单位、时间为秒 |
| 代表技能费用与冷却 | 当前装配的 AbilityDefinitionSO，读取选中的 Q、E 或 R 槽，进入实验时默认第一个有效槽 |
| 震屏 | 实验场 SideViewCameraFollow 的震屏强度。反馈轨可观察震屏请求，相机实际位移需单独测量 |

窗口逐项列出来源、基线、本次生效值、候选和单位。候选绑定到当前角色并在新动作受理时冻结快照。仅对可追溯的正式资产字段开放写回，勾选共享资产字段会影响它的其他使用者。原文件已改、存在未保存编辑或版本有冲突时，窗口会保留候选并提示重新读取。

## 同条件实测

临时角色 A，平地向右，固定靶相距 1.20。以下两刀测试的是释放时间和查询半径，与随附的保存示例是两组独立试验。

| 来自同一动作的观测 | 基线 49ebb64322fc | 候选 a7cac32c347f |
| --- | ---: | ---: |
| 释放阈值 | 83.333 ms | 108.333 ms |
| 实际受理至释放，模拟时钟 | 85.901 ms | 109.527 ms |
| 实际查询半径／粗筛碰撞体数 | 0.65／2 | 1.15／3 |
| 球心 | (0.80, 0.82, 0) | (0.80, 0.82, 0) |
| 目标生命 | 10000 → 9988 | 10000 → 9988 |

另以虚拟手柄经正式 Input System 输入 24 次按下与 24 次释放，记录到 4 次入缓冲及消费，释放段序为 1、2、3、4、1、2、3。分开验证了向左打普通受击体、空挥、跑动、起跳至着地、打墙的表面反馈、台边高差、角色切换和释放前复位。按代次与动作身份核对了 11 份 Play 导出。战斗核心 13 项回归通过，同批次重复提交后两个目标各扣血一次。

## 可重复的 Play 验收

在 Edit 状态点 **OSSASTRA → 战斗 → 验证横版攻击调试台**。工具启动同一个独立场景，走正式动作链，最后退出 Play。结果在 Console 搜索 `[AttackLab验收]`，完整报告位于工程的 `Reports/SideViewAttackLab/边界验收.txt`。

| 检查 | 本机实测 |
| --- | --- |
| 主手与技能槽 | 猎人原型Ⅱ依次受理 A3、A4。E 槽盾冲受理，对应 hunter-native-E |
| 录制、冻结与关闭采集 | 同一刀三次均扣 20 架势、造成 12 伤害。冻结和关闭时各新增 0 条记录 |
| 真实震屏位移 | 强度 0.8、0、0.8 时，逐帧测得最大偏移依次为 0.099772、0、0.099772 世界单位 |
| 左右空挥 | 实际方向分别为 −X、+X，查球中心分别在 x = −0.80、+0.80。两次均无扣血 |
| 已释放后转身 | 向右释放后两渲染帧，正式手柄输入让角色转向左。该子发射随后 21 次查询均保持向右，挥击和命中视觉仍向右，目标只扣一次 20 生命 |
| 出手前复位 | 已受理、尚未释放的动作在新代次没有迟到的判定或扣血。目标 HP 10000 |
| 声音事件归属 | 捕获的 3 条正式音频提交带动作、父动作、子发射身份 |

## 使用边界

- 首版覆盖实际装配与已接入的代表动作。手感、物理手柄、扬声器听感及震屏舒适度留给作者试玩。台边已测高差出招，抓沿转入和翻越尚未验收。
- 记录冻结停止追加时间线。当前使用正常模拟速度，慢放、模拟暂停、严格单步、倒放和命中停顿未接入。
- 本机实验场位于 `Assets/OSSASTRA/SideView/Development/SC_SideViewAttackLab.unity`。有正式横版场和本地角色资源的完整工程可从菜单构建它。远端保留构建器、调试工具和数值预设，本机实战截图与诊断留在本机。
