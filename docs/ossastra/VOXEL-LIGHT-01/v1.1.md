# v1.1：C独立明暗调参

本轮接续 v1.0，仅扩展用户认可的 C。A/B 保留，原 C 保存为独立 C0；不修改全局太阳、曝光、二维角色或地图。

## 操作

当前主场 `SC_RoomVisibilityLab` 左侧“体素受光”展开后选择 C：

- **亮面增强 0–50%**：只增强有效主方向光的实际漫反射，1%步长，数字框回显实际值。
- **背光压暗 0–50%**：只降低背光侧的 GI 漫反射与显式登记方向补光漫反射。
- 单项 +1/+2 对应 10%/20%的绝对目标，保留另一项；重复点击不累计。
- **恢复原 C0**：两项归零且恢复原 C 基础参数，保持轻分面，不切 A。
- **均衡候选**：亮面15%、背光10%；只是候选。
- **读取已存候选**：恢复已保存参数；不更改启动默认。
- **保存为候选 Profile**：只保存明确独立目标，回执列出目标路径、来源 Profile、22个登记对象。
- **显式设为本对象集默认**：要求当前会话已保存。Play 中先排队，退出后按稳定场景身份固化；场景有其他未保存修改时保留请求并提示先保存，不抢写。

窗口使用现有协调者/地图的输入捕获及角色指针区域；世界继续运行。A/B 显示“C参数暂不应用”。Player 可调当前会话；作者资产保存仅在 Editor 可用。

## 贡献与路由

两参数沿 `VoxelSurfaceSettings → 独立会话 → 复用私有材质 → 普通/Sight共享HLSL` 进入实际渲染。滑动不写共享作者资产，变化最多每帧合并刷新一次。

亮面增益为 `1 + litFaceBoost × smoothstep(0,1,N·L)`，只乘已有主光漫反射。主光身份、原光照层、距离、真实投影、云影保持；没有直射不产生白色自发光。镜面、环境反射、Emission继续原路径，最后进入既有保色保护。

背光控制使用真实世界法线、主光强度平滑门、实际表面室内归属和局部灯保护。只减已有填充贡献，最多减半，不设置绝对RGB底光。强点/聚光能阻止填充压暗，局部直射本身不变；室内默认保持原C。真实投影不驱动额外分面硬切。

主灯/补光是比较组件中的显式 `Light` 引用。既有 RendererFeature 在本相机真实剔除结果中匹配实例，映射到当帧URP额外灯上传序号；不是固定GPU编号、名字或颜色猜测。未知方向灯保持原样。原方向补光编辑值0.65，当前午间实际运行值0.199，由原环境模块调度；本轮未改灯值。

每相机开始清空角色标识，当前 Feature 发布，结束清空/恢复外层上下文。普通、部分许可、环境全表面、屋顶及材质槽继续原路由。没有新增 Pass、相机、RT、全场扫描或逐体素脚本。

逐顶点额外灯已经聚合，无法可靠区分火把和方向补光，因此该变体的**背光控制整体回退原C**；主光增强仍可用。GI通道可能含烘焙直射，未宣称分离真实反弹。
