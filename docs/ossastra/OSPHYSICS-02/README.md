# OSPHYSICS-02 手绘物质实验室

从团结编辑器的「OSSASTRA → 实验室 → 打开动态物质实验室」进入原有 `SC_DynamicMatterLab`，再点 Play。实验场默认打开 C「雾蓝水渠」。按 1–8 选择物质或工具，G 开闸，空格暂停，N 单步，滚轮缩放，WASD 或中键平移，Home 回全览。右侧可切换显示、画风和图层，以及调整水体透明度、火烟、明暗和试灯。

| 显示 | 用途 |
| --- | --- |
| A 原始格 | 观察物质占格与渲染前的状态 |
| B 原自然画面 | 保留上一版程序材质作为对照 |
| C 手绘 | 「雾蓝水渠」和「苔光幽洞」共用当前物质世界 |
| 世界灯图 | 同一组手绘图层，读取正式 OSLight 世界灯图 |
| 温度、碰撞 | 查看原有热量和碰撞诊断 |

## 实现与素材

- 地形主体、轮廓饰边、实体装饰、视差背景和透明近景独立绘制。坡、台阶、薄墙、闸门使用上一版的碰撞。图层可单独切换；两套 `MatterPaintProfile` 位于 `Visual/Resources/OSPhysics/Profiles`。
- `MatterVisual` 按原有脏区块更新共享状态纹理。Shader 使用整数坐标取物质分类和阻挡，按含量与同类邻格重建液面，只在有限范围内圆滑接缝。油和水使用不同颜色和响应，接触的位置保留界面，水油之间不叠加空气水线。纸纹基于世界坐标。试验仍能看出 0.1U 网格带来的小台阶，放大时尤其明显。瀑布、折射、反射和基于速度的飞溅留到后续。
- 草、木和沙灰以真实占格绘制，按燃料和温度过渡到烧焦、消失和灰烬。火焰、烟雾取真实燃烧和烟数据，绘制在透明批次中。无逐格粒子或逐格灯。实验轮廓和预设标记仍可见。
- 公开资源包含两张原创背景、两张带透明度的原创近景和程序材质纹理回退。原作研究用于比较遗迹石沿、苔藓和分层遮挡。现有资料支持这些素材的外形与用途，原作具体水面着色、烟扩散和灯光算法没有从截图推定。
- 本机编辑器可用「本机研究图」加载 `Reports/OSPHYSICS-02/本机素材映射.json`。遗迹方案取后墙、柱景、前景剪影、石材、液体色纹、草、木、火、烟；苔光方案另有水边槽，可用丝之歌苔岩、苔丛、水边和烟。ENDER MAGNOLIA 的水图用于液体色纹，主体轮廓仍来自真实液体掩码。油和沙灰使用原创回退。查看本机报告可核对选用的文件、尺寸、透明方式和指纹。
- 研究图按槽位临时加载，缺图回退到原创。原作路径、图像、映射、截图和视频保存在本机。公开配置仅引用本轮原创资源。

## OSLight 接入范围

实验相机独立启用正式 Renderer 上的 `SideViewAceLightMapFeature`、`SideViewAceLighting` 和正式写入 Shader。世界灯投影参与地形、水、植物、烟和带受光配置的景物。试灯加最多四个由真实燃烧聚合的灯，切回 C 会撤回试照组件并恢复相机 Renderer。

完整 D-New 合成当前由 `SideViewRenderComparison` 驱动，初始化需要正式角色，分层合成依赖 `SideViewComparisonSilksongFeature` 与角色会话。现有世界 Feature 产出八张灯图，实验室只采世界组。正式 D-New 的成片、角色边光、Bloom 和调色维持生产链路原状。后续可提取一个相机级合成入口，显式传入世界灯、前后层与可选角色，先在实验场做完整链路对照。

GitHub 当前为定向源码交付。本机原工程持有已验的管线和 Renderer 配置，缺少这项绑定的检出会显示原因，并继续提供 C 手绘。

正式横版接入还需把现有 3D 碰撞或作者格按角色平面采样成物质阻挡，处理闸门、狭缝和局部变化的增量同步，再接正式相机分层。当前实验是 256 × 128 物质格、格宽 0.1U、Collider2D。实验场尺寸和碰撞仍由原规则控制。

### 样板连续运行

同机使用 1920 × 1080 Game View 对开闸 `Flow` 运行约 38 秒。每模式丢弃 1 秒暖机后统计。帧间隔和计数包含编辑器，Draw Calls 取可用峰值，GC 取可用中位值。专用 GPU 和渲染线程计时未采到。

| 显示 | 帧 P95 ms | Core P50 / P95 ms | 峰值脏区 / 单帧上传 | Draw Calls | GC B/帧 |
| --- | ---: | ---: | ---: | ---: | ---: |
| A Grid | 2.04 | 0.091 / 0.174 | 32 / 6 | 161 | 8465 |
| B Natural | 2.33 | 0.090 / 0.134 | 32 / 6 | 161 | 8465 |
| C Painted | 2.38 | 0.091 / 0.133 | 32 / 6 | 167 | 8465 |
| 世界灯图 | 2.19 | 0.090 / 0.150 | 32 / 6 | 170 | 8609 |

这次样板正常运行时最多 7 个可见手绘批次，未起火时有一盏试灯，场内无附加粒子。256 × 128 的 RGBA32 主状态图约 128 KiB，区域上传复用 4 KiB 缓冲纹理。按实际格式 RGBA16F 估算，八张灯图在两档分辨率约 17.8 MiB 和 31.6 MiB，未计 RT 开销及其他相机纹理。

75 步纯 Core 压力复测如下。密集工况每 20 步重补木和油，测量单步求解时间。1024 × 512 密集时 P95 已超过 30 Hz 的 33.3 ms 单步预算。

| 尺寸 | 局部 Core P95 ms | 密集燃烧 Core P95 ms |
| --- | ---: | ---: |
| 256 × 128 | 0.263 | 2.463 |
| 512 × 256 | 0.581 | 9.151 |
| 1024 × 512 | 1.248 | 36.562 |

本机实载读回遗迹 9 槽、苔光 10 槽，缺失数均为 0。1080p 和 QHD 均验证正式灯图。QHD 连切 C / 世界灯图 24 次后，按实验室命名前后比较，材质和网格计数维持 68 / 14，本地图源纹理与临时灯对象均已释放。

## 本机试看片

`Reports/OSPHYSICS-02` 有同帧 A/B/C、世界试灯对照、自由笔刷灭火和 44 秒 Game View 录屏。打开实验场先试「水流与闸门」。再切「空白」，并排画草、木和油，只加热草的一端，观察火经过材料后刷水。暂停后连切两套画风和世界试灯，可以对照同一时刻的水线和实际烟火。
