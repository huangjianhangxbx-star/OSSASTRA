# OSPHYSICS-02 R1 地图资产笔刷与动态水火

从「OSSASTRA → 实验室 → 打开动态物质实验室」进入原场景并 Play。右侧「资产交互样板」可直接检查水渠、草和长根。「空白资产区」保留地基、外侧界墙和闸口，可拖框画或擦黑砖，点草或木缩略图后在场中落笔。草簇会贴到附近顶面。数字 1–8 返回物质笔刷；G 开闸，空格暂停，N 单步。「仅看资产」关闭背景、前景和试灯。「燃料叠线」用淡蓝标实体格，用青色标图件交互范围和截至当前仍有效的燃料格。木构件以原锚点自由摆放。「旧 C」与「地图画面」可随时比较。

## 资产与状态

- 本机使用当前岩洞作者地图的遗迹岩洞套件。黑体、顶边、侧边、洞顶、内外角和端头都走地编 `TerrainAssembly.Solve`。样板采用作者格 0.7215358 U，按物质格中心落在哪个作者格来登记固定阻挡。0.1 U 物质格与 30 Hz 步进沿用原配置。当前刷子覆盖正交作者格，历史预设的斜坡和碰撞仍可试玩。
- 蓝叶草、台面小灌木和交错长根保留原裁片、尺寸、透明剪影及原锚点。两种草为 45×96 和 238×164 像素，长根为 197×217 像素。其正常地图世界尺寸约为 0.35×0.74、0.80×0.55 和 1.97×2.12 U。镜像服从本机图件标定。燃料登记采实际透明度和支撑宽度；长根中间透空不登记燃料。
- 落笔预检逐格确认边界、阻挡、材料、容量和属主，再一次性走原物质 API。原始草木笔刷遇到已属某图件的格会拒绝补料。燃料消耗由物质步后同步，哪怕当前画面隐藏也会记焦化。图件的 Alpha 来自原图，局部焦痕和淡出取决于本件有效燃料。彻底耗尽会释放画片与登记槽，独立灰烬仍由现有物质账本管理。删除草木时只清除本件有效燃料。
- 资产样板的运行时占格决定画片、Collider2D 和固定格，闸门使用独立的阻挡登记。新增或回填实体遇水、油、沙、燃料会拒绝。图件越出接边或叶尖伸出去只影响画面。切回原预设会还原原有实体和镜头背景。正式 3D 碰撞仍需要作者格或角色平面的增量投影适配。
- 作者地图 API 留在默认程序集，窄桥在场景启动前注册；实验 Runtime 仅将本程序集设为自动引用，交换图件、裁片、规则求解结果和尺度。Core 不参与地图或渲染。每次有效编辑对实验室范围重新求解，模拟每步不重建地形。
- 本机绑定从忽略的 `Reports/OSPHYSICS-02/R1/资产绑定.json` 读取。公开回退包括七张项目原有铜色边件和两张项目原创植物，复用同一套地编规则和笔刷。公开回退提示没有完整木构件。两套旧画风仍控制水色、火烟和可选背景；资产样板使用同一套岩洞草木与石边。第二套独立资产刷套件未搭建。
- 水油从整数分类快照重建同类自由边界，最多借邻格约 0.34 个格宽的空气带。相邻同类数据控制宽窄流、孤滴和水池，实体与油水分类仍硬裁。纹理使用固定世界坐标，水线与油水接触区各自处理。竖直流水在近景仍可见真实离散滴，极端初始方形水块和实际断流仍由格模拟决定。流向是局部形态近似。
- 火焰使用完整透明剪影而独立成批，位置取实际燃点、大小及相位稳定，随固定 Tick 动画。来源为实测单张完整火图，烟仍读真实浓度，石壁和低顶限制火烟。默认本机映射使用完整图，公开回退为原创火形。真实世界灯图可继续使用，完整 D-New 的角色和成片合成继续依赖正式链路。

### 性能取样

在同一台 Tuanjie 编辑器的 1920×1080 Game View，对同种子 256×128 资产交互样板、3 个原图件、同相机与关试灯状态，各暖机约 1 秒并采 30 秒。测的是编辑器 Game View 帧回调间隔。驱动这段样板的固定步频相同，实际步数受编辑器运行节奏影响。

| 表现 | 帧间隔 P50 / P95 | Core P50 / P95 | Draw Calls 峰值 | 整帧 GC 分配中位数 | 画片与动态批次峰值 | 实际步数 |
| --- | --- | --- | --- | --- | --- | --- |
| 旧 C | 1.41 / 1.88 ms | 0.120 / 0.149 ms | 176 | 8,505 B | 4 | 900 |
| 地图画面 | 1.44 / 1.92 ms | 0.121 / 0.150 ms | 192 | 8,505 B | 20 | 855 |

初次画片求解 2.68 ms。连续 30 次有效画格和重建的峰值为 3.45 ms。正常样板两模式都触及 32 个脏区块，取样段没有燃点与灯。火焰、灯的预算分别为 96 片、4 个火灯加试灯。焦化掩码纹理为 384×384 线性色，不随编辑次数扩大。单独的 GPU 时间、派生阶段计时及密集燃烧帧成本本轮未量化。此处帧间隔可用于本机两模式对照。

本机 `Reports/OSPHYSICS-02/R1` 包含真实素材截图、帧比较和约 59 秒的实际 Game View 录像。录像由脚本触发公用落笔、开闸与注水接口，在水流段与点火段之间清空并重种同三件图件。面板和画笔另有合成鼠标验证。真人手感、正式地图投影与独立 GPU 耗时仍待专门验证。
