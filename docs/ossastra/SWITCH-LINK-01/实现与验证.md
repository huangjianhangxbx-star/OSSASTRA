# 双角色切换连携的实现与验证

## 执行时序

1. 原主控照常提交攻击。普攻完成真实投递后，队伍记录该角色的生命代际、控制代际与当次动作 ID。一次出手只开一次机会。可选技能须显式启用并完成真实投递才参与。
2. 队伍处理下一次手动换人时，检查机会、共享冷却、双方动作状态、地面支撑、位置和切换技。条件不足就按原规则换人。原有脚本调用 `SwitchNext()` 也沿用普通换人。
3. `CharacterMovement` 提交入场，`CharacterActionCoordinator` 以一次性身份受理真实动作。受理后更新唯一 `Current`，退场角色结束原动作及其仍随身移动的命中窗口，在固定步中沿原动作反方向退开。已投递的命中和独立飞行物继续结算。
4. 相机继续由 `SideViewCameraFollow` 持有。特写的倍率与震动合成后参与最终投影边界与屏幕射线。短演出按真实时间计，连携机会、冷却、后撤与角色动作按战斗时间计。菜单夺输入、角色死亡、切图及组件生命周期会清理临时演出。换人声沿用原控制变化事件。

## 附件验证矩阵

团结 Editor `2022.3.62t18`，正式横版第一场 `SC_SideViewAdventure`。场景保存前后仅增加两处组件引用和两份组件数据，共 45 行。既有门、菜单、相机和音频引用均由同一场景保留。Play 的控件测试使用逐帧 Input System 虚拟设备，实测链路经过项目正常输入、动作、命中和镜头。

| 项 | 实测与覆盖 |
| --- | --- |
| V01 | 实机空按 Z 沿用普通切换，冷却内松键再按也正常切回。过期由窗口合同覆盖。 |
| V02 | 左键／Z 猎人→芙蕾茜娅，X／LB+RB 芙蕾茜娅→猎人，两人均验证空挥和真实命中。按最终试玩反馈将开阔处目标设为 27.5 个碰撞体宽度。正式场西侧分别朝左、朝右实测 `12.100` 单位，11 个观测固定步均接地，新角色留在原角色交接点，交接约 350 ms 后相距 `11.605–11.770`。 |
| V03 | 窗口合同覆盖同一执行 ID 重复、不同来源拒绝与下一次独立出手。实机检查自动切换技只受理、释放各一次。 |
| V04 | 实机匹配原攻击和切换技各自的不同执行 ID。命中探针检查原攻击与入场攻击各自从预期方向和位置发出。 |
| V05 | `None` 完成交接且无攻击。移除动作引用后按 Z 普通换人，保留两原位置且不开始连携冷却。 |
| V06 | 原接触网关将角色打到 0 HP 后自动由存活角色接手，再实际输入 Z 未产生自我连携。队友非可取消状态由正式准备门槛校验，本次实机未逐一复现各类控制状态。 |
| V07 | 原场出生练习区受两侧训练平台限制，西侧开阔地两向通过。以 27.5 身宽从实际左键／Z 驱动的物理夹具，背墙实走 `2.060`，崖边实走 `2.411`，11 个观测固定步均未失去原支撑。较高身形遇低顶，以及预备后删除落点支撑，另由定向探针验证拒绝。录像中的临时地形用于展示边界。 |
| V08 | 双方零架势时仍可在原输入路由连携。已有架势合同覆盖独立账本、同语义暴露与恢复等待。 |
| V09 | Z、鼠标左键、虚拟手柄 X／双肩组合、旧 Z 持续按住与新 Z 重新武装实测。实体手柄待试玩。 |
| V10 | 原练习目标收到两次独立伤害。已有震屏与推近减速实测重叠，峰值 `1.070`、最低时间倍率 `0.650`，自然回到 `1.000`。 |
| V11 | 演出中按 Esc 进入既有菜单，Z 被拦截，共享冷却保留。组件禁用与 Unity 失焦回调分别触发复位。另在 Play 临时延长退场包络，从真实 LMB／Z 开始的特写中发起 Single 加载 `SC_Tut02Entry`。旧场卸载，时间倍率从 `0.9376` 恢复 `1.0`，新相机保持 `24°` FOV。延长时长仅用于覆盖异步加载中的清理竞态。 |
| V12 | 实机按 D 行走、左键出手并保持 D 后再按 Z，镜头改跟新主控。记录中的最大单帧基准位移为 `0.004` 世界单位，收束偏差低于 `0.001`。 |
| V13 | 场景保存并重新开始 Play，可读回两项实际动作、27.5 身宽、0.20 秒退场、1 秒机会、2.5 秒共享冷却和演出设置。新会话连携计数为 0，时间与镜头无残留。 |

已通过工程外验证。机会窗口 11 项，运动几何 8 项，演出合同 4 组，现有移动免架势 4 项，横版跳跃合同通过。独立基线内已有的架势、输入组合和受击恢复合同也通过。合并源码用当前编辑器生成的 Bee 参数构建完整游戏程序集，退出码为 0。既有 M02C 跟随合同在改动安装之前就未能编译，其测试引用缺少 Abilities 相关来源。

## 本机与源码交付

正式横版场景及其资源链、约 73 秒的 1600×900 实机录像和临时探针按项目既有策略在本机保留。录像包括普通换人、双向长退距切换技、命中、仅交接、移动镜头和背墙／崖边，音轨来自同一运行的 Gameplay Listener。远端发布经核验的自有连携源码、必要 Unity `.meta`、定向合同与说明。
