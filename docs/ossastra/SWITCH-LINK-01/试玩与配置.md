# 双角色切换连携

打开正式横版场景 `Assets/OSSASTRA/SideView/SC_SideViewAdventure.unity`，按 Play。两名角色站稳后，用鼠标左键或 Xbox X 发出一次普攻，再在出手后约 1 秒内按 Z 或 LB+RB。连携可用时，主控角色卡会显示提示。新主控接替原角色当前位置，原角色向反方向短退，新主控播放自己的切换技。

没有连携机会、冷却中、伙伴正忙或位置无法交接时，同一个按键可以普通换人。两次连携间隔为 2.5 秒战斗时间。空挥也能开启机会。

要看完整的前后交替，从出生练习区向左越过练习平台，到西侧平地再试。靠近出生区障碍、墙壁或台沿时，实际后撤取决于身后还有多少安全地面。

| 角色 | 切换技默认动作 |
| --- | --- |
| 猎人 | 角色现有第一段普攻 `Rozeul_Basic1` |
| 芙蕾茜娅 | 角色现有第一段普攻 `FreyciaPreview_Basic1`，对应 `短刀-a1` |

## Inspector

选中当前正式场的 `CharacterControlCoordinator` 对象。其 `CharacterSwitchLink` 组件包含两名角色各自的 `Slots`，可将 Mode 设为 Action 并指定单段动作定义，或设为 None 仅交接。Action 的引用需要有效且能通过该角色的动画映射。

| 组件 | 试玩参数 | 起始值 |
| --- | --- | --- |
| CharacterSwitchLink | Opportunity Seconds | 1 秒战斗时间 |
| CharacterSwitchLink | Cooldown Seconds | 2.5 秒战斗时间 |
| CharacterSwitchLink | Retreat Body Widths | 27.5 个碰撞体宽度，正式场两人开阔平地实测 12.10 个世界单位，受实际支撑和阻挡限制 |
| CharacterSwitchLink | Retreat Seconds | 0.20 秒战斗时间 |
| SwitchLinkPresentation | Zoom Multiplier | 1.07 倍，设为 1 可关闭推近 |
| SwitchLinkPresentation | Time Multiplier | 0.65，设为 1 可关闭减速 |
| SwitchLinkPresentation | Enter / Hold / Leave Seconds | 0.06 / 0.15 / 0.24 秒真实时间 |

每人的架势由各自原账本推进。切换攻击作为一次真实主手动作结算，首段默认架势暴露目标为 20。切换和退场位移本身免架势费用。Show Diagnostics 用于查看机会、冷却、实际退距和上次分流原因。
