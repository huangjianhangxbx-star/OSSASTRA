# 横版地形工坊验收与范围

## 编辑和运行

- 团结 2022.3.62t18 已导入并编译。鼠标在 Scene 中画出矩形平台、擦出封闭洞、点击顶沿，面板显示选中的具体画片和匹配规则。用鼠标将顶面贴附线从 0.640 拖到 0.801，撤销读回 0.640，重做读回 0.801。保存重开仍有 431 格、两个封闭洞。
- 同一求解器检查深色填充与权威格面积相等，碰撞覆盖相同面积。单格改形后 82 个旧画片批次保留 75 个原对象。第二套件与 117 格标准形状测试页保存重开，初始样板和试拼页均无缺件诊断。
- 关闭工坊再进入 Editor Play。原有猎人、芙蕾茜娅均以原输入移动、跳跃、落地和切控，原 Esc 菜单、SFX 路由和 OSLight C 读回通过。芙蕾茜娅下冲挂载可用。挂边、攀越和下冲实际命中仍需场内专项走查。正式第一场和 Build Settings 的接手前后哈希一致。
- 128×64 格测试在团结编辑模式测量 24 次改变形状后的装配求解，中位数 8.92 ms，P95 9.77 ms。计时范围为解算，鼠标事件等待与提交后的实际绘制分开。
- 核心测试包含 512 个小网格穷举、内外轮廓朝向、拆分合并、材料交界、覆盖定位键与碰撞分区。接点和边带另有定向测试。

## 使用范围

- 支持直边、直角台阶、薄墙及套件最小跨度内的洞口、短平台。自由曲线、斜坡与单向平台留作后续。未知图件及不满足跨度的边会显示诊断。
- 画笔和程序共用作者数据，碰撞与显示分块从同一套数据产生。编辑预览目前对全图进行轮廓求解，提交重用内容相同的分块和碰撞盒。玩家运行时挖掘仍需接入物理更新和失去支撑后的角色处理。
- 当前库预装铜脉遗迹、月白灰岩两套原创图件。第三方游戏以公开画面作为分层研究参考。旋转的已打包图集和裁片保留锚点的跨图集迁移未验，建议使用源图或单独 Sprite 来校准。
- 鼠标操作已留编辑器读回与截图证据。连续录屏未覆盖完整流程，且最终布局修正没有再接管桌面重录。审美接受待用户确认。
