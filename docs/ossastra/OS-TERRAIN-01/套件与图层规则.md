# 套件与图层规则

## 原创示例怎么拼

「铜脉遗迹」用暖铜石面和近黑紫灰主体，「月白灰岩」用冷蓝灰石面和深蓝主体。「山隙远景」提供连续底景，「风蚀断碑」作为独立结构盖章摆放。两套套件使用同一组正交形状规则，可在示例东段查看材料过渡。

| 槽位 | 出现的位置与初始规则 |
|---|---|
| 内部填充 | 每一处实体内部使用套件主体色；封闭洞和通道保留空域 |
| 顶面、洞顶 | 顶面指实体上方的外露面，洞顶指实体下方的外露面。水平边带的初始有效跨度为 2 格 |
| 左墙、右墙 | 朝左、朝右的外露面各自用独立槽位，初始有效跨度为 1 格 |
| 凸角、凹角 | 外凸与内凹分别用独立图件，初始尺寸为 0.65×0.65 格 |
| 端头 | 为完整长件铺不下的短边提供替换 |
| 附着装饰 | 沿能支撑装饰的表面散布，初始间距为 3.5 格。手工附着物找不到原边段时会列为问题 |

重复边带按有效连接区间计算相邻位置。完整构件保留自己的尺寸并按可用跨度放置。附着装饰保留独立用途。用青、蓝两个点标出真正相接的像素区间，再用金色贴附线配合「碰撞」叠线检查角色实际站位。已有规则初始重叠为 0.075 格，最短适用边为 0.25 格。两种材料接在一起的内部仍是连通实体，只有外露边进入饰边规则。

工坊预览覆盖直边、台阶、短平台、薄墙、正交凹凸角和封闭洞。首版实体不可从底部穿过。任意曲线、斜坡、单向平台和玩家运行时破坏属于后续物理与玩法范围。套件状态由作者确认，可按未分类、候选、工具测试和已确认区分。

## 默认图层

| 图层 | 绘制顺序 | 初始视差 | 初始受光比例 | 用途 |
|---|---:|---:|---:|---|
| 远景底层 | -62 | 0.04 | 0.30 | 连续底景 |
| 中景结构 | -48 | 0.02 | 0.45 | 远墙、断碑等独立构件 |
| 近背景墙 | -35 | 0 | 0.55 | 角色身后的布景 |
| 地形主体 | -24 | 0 | 0 | 实体形状及其深色内部 |
| 轮廓饰边 | -22 | 0 | 1 | 顶面、侧墙、底面和角件 |
| 附着装饰 | -20 | 0 | 0.85 | 在表面自动或人工放置的装饰 |
| 前景遮挡 | 12 | 0 | 0.8 | 有意挡在前面的独立图件 |
| 气氛 | 14 | 0 | 0 | 雾或色片等独立表现 |

在「图层」可改名称、显隐、锁定、独显、画片排序、视差和受光比例。背景与前景可以指定一张底层图件，也可以挑素材盖章。独显只改变画面审查状态。实体碰撞根据占位格求解，挖洞后能看到独立的背层布景。
