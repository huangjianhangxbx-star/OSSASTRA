# 星骸·横版地形工坊

在 Project_ANKALUTE 的团结编辑器里打开 **OSSASTRA → 地形工坊 → 打开工坊**。第一次点 **打开示例** 可进入「高台遗址」并查看「铜脉遗迹」「月白灰岩」两套原创饰边。Scene 视图是画布，工坊窗口可以停靠。

## 从选材到试玩

1. 在「素材与校准」选择套件。点缩略图查看原页、裁片和来源，可以用过滤、搜索和收藏缩小范围。要试调自己的配方，先点 **复制套件**。
2. 把素材缩略图拖到「顶面」「左墙」「洞顶」等槽位，或先选槽位再点 **放入**。在放大图拖青色起点、蓝色终点和金色贴附线，观察下方的实时试拼。**保存套件**写入当前套件资产。
3. 回到 Scene，在工坊点 **正视**，启用 **Scene 画笔**。先用「矩形」拖一段实心平台，再用「擦」在里面挖洞。拖动时看到主体与饰边，松开才提交。用 **边界**、**碰撞**开关核对图件的连接线和实际支撑面。
4. 选 **检查**，点击需要处理的边段。工坊高亮画片并显示套件、素材来源、跨度、间距、偏移与选择原因。可打开对应规则、单独替换、锁定或返回自动。点 **复制问题描述**，将同一位置的信息贴给协作者。
5. 点 **保存**，再点 **试玩**。要试空白地图，先点 **新建地图**。可按提示接到当前工坊场，也可点 **新建试玩场**在另一个场景编辑这个资产。已有地形根的场景用 **连接当前地图**，随后从「作者地图」选择要接入的资产。

## 画笔与场景导航

| 操作 | 用法 |
|---|---|
| 画、擦、矩形、直线 | Scene 中左键拖动，Shift 临时擦除，Esc 取消当前笔 |
| 换材 | 选另一个套件，在已有实体上拖动 |
| 选区 | 左键框选实体，拖动选区内部可移动，Ctrl 拖动复制，Delete 删除。目标有其他实体时会提示 |
| 检查 | 左键点边段或角件，查看来源与规则 |
| 盖章 | 在「图层」为目标层点 **在此层盖章**，选择素材后在 Scene 点放。附着装饰需要靠近有效饰边 |
| 导航与撤销 | Alt 沿用 Scene 导航。用 Unity 撤销与重做操作，一次落笔对应一次地形编辑 |

在 Project 选中自己的 Sprite、图片或文件夹，再点素材库下方的 **添加 Project 中选中的原创 Sprite／图片／文件夹**。也可把一张素材从 Project 直接拖到校准槽。需要从图集选局部时，展开原页，开启 **从原页拖框建裁片**，拖出可见范围。

「帮助」里的 **冻结当前显示**会保留当前派生网格和碰撞。保存后可关闭工坊再试玩。要继续作画，点 **解冻并刷新**。

示例场、地图和两套套件位于 `Assets/OSSASTRA/SideView/PrivateValidation/OS-TERRAIN-01/`，场景为 `SC_TerrainWorkshop.unity`，示例地图为 `高台遗址.asset`，另有 `空白试拼.asset`。校准参数和图层约定见 [套件与图层规则](套件与图层规则.md)。
