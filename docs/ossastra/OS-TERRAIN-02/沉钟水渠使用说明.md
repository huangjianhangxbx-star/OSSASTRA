# 沉钟水渠 · 教程地形分层观察

从团结打开 `Assets/OSSASTRA/SideView/PrivateValidation/OS-TERRAIN-02/TutorialOrganization/SC_TutorialTerrainOrganization.unity`，点 Play。场景沿用星骸回廊原有角色、镜头和输入。观察面板在画面下方。

1. 保持「黑底格」并关掉「石边」和「布景」，可看到一个 8×8 白格染深后铺成的 391 格实体。地面、悬台和洞顶下面已预留了通路。
2. 打开「碰撞轮廓」。青色框为由占格生成的 13 个基础 3D 碰撞盒，橙色框为独立挡墙。隐藏「假墙遮挡」只关画片，橙色碰撞仍挡住角色。
3. 点击「打开假墙」。遮挡和橙色碰撞一起退出，之前已经画好的地面与洞顶石边露出来。关闭时，若缺口中有角色，样板会保持开启。

层级中的黑底、轮廓画片、附着装饰、前后景、基础碰撞和假墙都可以单独点选。底图 Tilemap 是此观察场的可视快照。基础碰撞与石边在作者态从同一份占格烘焙，观察场冻结该输出。上轮的「裂谷闸廊」样板则用运行时删格和生成断面，可与本场对照。

单测在正式团结 Editor Play 的原生组件上执行。391 格和 13 个基础碰撞盒的对象在开关测试中一致。角色控制器从同一点横移 4.6 单位，关门停在 X=9.760，开门到 X=13.450。遮挡可隐藏而碰撞仍存在，站入缺口时不能把假墙关闭。按钮画面和状态截图来自 Game View，验证通过原生组件调用执行。

此场借鉴 Never Grave 教程场可核实的分层和独立挡路对象，使用原创布局、项目素材和现有 3D 物理。假墙的画片显隐用于示意遮挡。原作使用独立 SpriteMask，原作触发顺序仍待录制核对。详见[序章地形研究与闸廊验证](序章地形研究与闸廊验证.md)。
