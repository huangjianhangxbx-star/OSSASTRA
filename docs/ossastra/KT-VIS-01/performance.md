# KT-VIS-01 性能与资源实测

最终四态采样：`d1f4eeca2d3a4ee7b6704e570b61f0e3`，回执 `final-route-perf-poll.json`。同一个真实小墙遮挡姿态、相机、1600×900 输出和画质；每态先稳定 1.5 秒，再取 90 个真实 Play 帧。世界与原动画继续运行。

探针 CPU 是最近一次约 20 Hz `Detect` 调用的耗时样本均值，不包含目标投影、支撑检查及装饰代理同步。捕获提交 CPU 包含该调用的主线程工作，不能当 GPU 时间或单独渲染线程时间。Draw／SetPass 来自 UnityEditor 统计，可能包含其它 Editor 视图。

同次 Main Thread 计数均值为 2.95／3.11／4.52／4.07 ms；整个 Editor 帧的 GC 计数约 65.1／77.5／78.2／78.2 kB，包含现有游戏、Editor 和测量脚本，不能归因为本模块的独立分配，也不签零 GC。Render Thread 计数器不可取得，GPU 时间未测；这些值不填成零，不由此推算发布版 FPS。

关闭态原先仍做检测，初轮回执保留为历史。最终生产旁路停止遮挡、装饰代理及支撑检测，重新开启首帧立即重测，不沿用陈旧需求。

三次完整 Play→Stop 均检查了本模块清理。第三轮另外追踪实际持有的 104 个原生对象引用，退出后存活 0、ID 复用 0；包含捕获材质、网格、RT、辅助对象和角色变体。独立查询场景、合成输入设备、输入捕获 Owner 均归还。全 Editor 的原生材质总数有增长，尚未归因，不能把局部所有权检查扩大为全引擎无泄漏。详细证据见 [validation.md](validation.md)。
