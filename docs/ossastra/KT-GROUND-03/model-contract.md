# 侧壁模型与顶盖约定

首版支持水平、连通、无自交的简单单外环。侧壁Mesh必须先保存为可读的静态资产，MeshFilter明确列在平台Binding中，且属于该平台层级。正缩放、平移和绕Y旋转可用；倾斜、负缩放、多环/洞、分叉或非流形会拒绝，不用凸包填平。

上沿高度由Boundary.localTopY明确指定。Reader从Mesh原生顶点/全部三角子网格取开放边，临时焊接UV/硬边缝，验证同高闭环。不会修改原Mesh、Importer或角色。默认局部焊接容差1e-4、平面容差5e-4；世界误差随平台正缩放换算，不为失败样本临时放宽。

顶盖由实际Sprite vertices/uv/triangles、Tilemap颜色与每格矩阵生成，再按作者格范围和真实模型域裁剪。边缘格保留Tile，不以格中心删除整块；凹口三角需要相交裁剪。Shader深度偏移用于层次，物理顶面与模型上沿共面。

每个平台拥有独立surfaceId、作者Map、Boundary和SurfaceCache文件夹。上沿指纹包括源资产身份/几何与有关变换。来源改变时先提示失效，旧正确缓存保留，用户明确重取。版本切换的作者Undo不录入随时会被替换的派生缓存指针。

顶面Collider由同一凹域生成，独立于显示缓存根；隐藏顶盖、裸缝或裁剪前对照不会关闭站立面。凹口不得用覆盖整个AABB的高处BoxCollider填满。样本侧壁Collider使用对应模型，缓坡是静态MeshCollider；外部侧壁模型须提供匹配的碰撞配置。

装饰Transform是唯一脚点作者位置。有效落点需要属于同一高度平台、位于边界内并满足配置的世界米退让。改轮廓不会自动移动/删除手摆、锁定或域外实例；诊断列表是即时只读结果，不增加第二份位置表。

本轮未承诺完整内洞、桥洞玩法、多层队伍寻路、跨层战斗、动态平台、任意曲面刷地或自动修复任意损坏模型。
