# KT-VIS-06 自然视野与柔和过渡 Implementation Plan

> **For agentic workers:** 在本轮已授权的并行子代理中逐项执行，Root 负责集成与复核；不再请求执行方式确认。

**Goal:** 在现有唯一实验场景完成无短距硬截断的自然视野、真实窗景与独立黑幕过渡。

**Architecture:** Core 分离人物观察策略与相机洞口几何。Runtime 生成当帧权限、静态环境名单和重置代号；Rendering 管理最多四个世界域历史及内部柔边，动态与标签只读当帧权限。

**Tech Stack:** Tuanjie 2022.3.62t16、URP 14.2.0-t1、C#、HLSL、现有 Native MCP、独立 .NET 合同测试。

**Spec:** [设计说明](设计说明.md)
