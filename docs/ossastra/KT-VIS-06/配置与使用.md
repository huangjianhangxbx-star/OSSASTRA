# KT-VIS-06 配置与使用

继续打开 `Assets/OSSASTRA/GroundWorkshop/Samples/KT-VIS-04/SC_RoomVisibilityLab.unity`。仍为同一个双角色、单敌人样板，相机默认 45°，局部物件透视默认关闭。06 使用独立验证档，未接管 05 档或原源场。

## Inspector 入口

选择 `RoomVisibilitySampleRoot` 上的 `RoomVisibilityModule`：

| 配置 | 默认值 | 用途 |
|---|---:|---|
| 玩家自然视野 | 开 | 前方 180°；不使用旧门窗 6/8 米限制 |
| 真实窗孔外景 | 开 | 按当前房间外窗的真实洞口显示相机看到的世界，不授予人物标签或邻室许可 |
| 稳定观察点高度 | 1.4 | 从原主控脚点上移，不使用相机位置作为人物感知来源 |
| 黑幕呈现 → 启用 | 开 | 静态环境过渡及合法侧柔边 |
| 初始可见度 | 0.3 | 新获许可时先出现一部分；显示器 RGB 读数不是线性透明度 |
| 显现 / 退场时间 | 0.5 / 0.3 秒 | 当前四份世界域历史的支持上限，不能直接调成数秒 |
| 扩散时间 / 参考半径 | 0.12 秒 / 8 | 距观察点较远处稍晚展开，总显现时间仍不超过 0.5 秒 |
| 内向柔边宽度 | 0.35 | 向合法区域内部变暗；不模糊开放未知区域 |
| 稳定世界点阵 | 关 | 可选颗粒边缘；尺寸 0.06、强度 0.12，不使用逐帧随机噪声 |
| 静态过渡环境名单 | 已配置 | 地板、固定墙体、高柜及地表；动态内容禁止加入 |
| 固定地表作者根 | 已配置两处高台 | 初始化登记作者生成的显示叶，不逐帧扫场 |
| 活动门窗遮挡盒 | 原实体门板、西窗板 | 不保留静态退场；开合仍由原门窗状态及真实几何决定 |

样板右侧面板可开关自然视野、真实窗景、静态过渡和点阵，方便对照。面板中的橙线仅表示方向，不表示视距上限。运行时调整的参数不会自动保存；需要保留时应在 Edit 状态配置组件并保存样板。

`ViewPortal` 中仍有“有限策略·观察距离 / 延伸距离”。它们供独立有限策略和旧行为对照，玩家自然视野及相机窗景忽略这两个数值。尚未接入敌人侦察或手电筒玩法；以后应使用独立策略，不能读取玩家渐隐亮度作为 AI 可见性。

## 美术及建筑登记

真实门窗应有与墙洞一致的可读凸多边形网格，仍支持 3—7 边。相机窗景直接显示原世界，不需要制作假窗景贴图，也不增加每窗相机。

屋顶与结构分类保持此前规则：入室后整栋登记屋顶揭开；根据相机方向剔除当前房间前墙；原屋顶 Caster、碰撞和业务继续。揭顶本身不授予未知房间内容权。本轮平滑的是黑幕和静态环境，屋顶/墙段剔除仍为原来的硬切。

静态名单应只放固定环境。角色、敌人、Spine、动画、粒子、可破坏物、掉落、信息叶及活动门窗都不应加入。显式名单中的物体被移动后会降为当帧表现；被禁用或销毁不会被历史复活。当前已登记的固定柜体属于当前完整房间时保留原投影。

门窗或实体遮板改变时立即清除历史；主控切换、重生、传送和观察失效也清除。普通走门、转头和相机旋转不会清除正常过渡。相机窗景始终受当帧洞口限制，历史不会将旧窗口画面拖到新的位置。

## 呈现与照明的区别

柔边是独立的可见性美术层，不是把全场灯调暗。当前合法区域继续使用原材质及 URP 光照；房顶遮光不因揭顶取消。已失权的静态环境只用原材质颜色短暂退场，避免持续泄露未知敌人的实时影子或光效。

硬实体阻挡边缘保持精确，不承诺任意遮挡轮廓都有柔边。世界域按约 1/6 秒有限采样，连续运动的跨界时间是插值近似；极快反复越界以最新四份快照为限。当前认证仍是此 Lab 的 URP/DX11/MSAA4、无后处理、Box/OBB、单层单跳；完整外部日光、GI、任意 Mesh、多层建筑及正式美术调优未在本轮扩展。
