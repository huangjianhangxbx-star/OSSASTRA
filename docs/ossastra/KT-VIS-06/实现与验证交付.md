# KT-VIS-06 实现与验证交付

2026-11-03。用户要求“出计划然后实现”，随后明确连续执行及常规问题采用推荐案。本轮为当前建筑可见性任务的增量，使用原 SC_RoomVisibilityLab，无清场或新建游戏场景。

## 已实现

- 玩家自然视野与旧有限视野分开；前方 180°宽容规则允许两个真实开口同时涉及，保留洞口及实体遮挡，取消普通玩家旧 6/8 米截断。
- 相机通过当前房间真正通向室外的孔洞显示真实世界。它与人物眼点分开，不解锁邻室，不给予标签、锁定或交互权。
- 显式静态环境具有 30%起始、0.5 秒内展开、约 0.3 秒退场及短距离扩散；世界域历史重投影，不存旧屏幕颜色。
- 柔边向合法域内收缩，提供中文 Inspector 参数和默认关闭的稳定世界点阵。房间体积硬许可仍为三维，地面柔边只沿水平足迹，避免贴地面整体变黑。
- 动态内容与信息权限当帧撤销；门板/窗板、主控身份、传送和观察失效清历史。普通走门与相机旋转保留过渡。
- 原主相机、Current、角色、敌人、物理、门窗、灯和业务根保留；相机仍 45°。固定高柜的原投影不会因使用过渡 adapter 而被误关。

## 限制

屋顶和前墙的权威显隐仍硬切，当前过渡优先处理黑幕与静态内容。硬实体遮挡边缘仍精确剪裁；点阵默认关闭。四份世界域历史是有界插值近似，快速反复越界以最新快照为限。

本轮真实颜色验证使用公开位置/朝向夹具；没有据此声称新做了实体键盘/手柄、完整 WASD 视频或 Player 认证。光照验证为现有局部灯和 Caster，不是完整室外日光/GI/烘焙/反射/SSAO。原敌人、正式特效、任意新美术和多层楼仍需各自内容验收。
