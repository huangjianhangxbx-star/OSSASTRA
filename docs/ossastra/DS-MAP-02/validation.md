## 有限图形、时序与资源证据

修复后17秒顺逆各8次步进，1082次正式mesh回调，empty=0、boundsFailures=0，覆盖五面及镜像、actual yaw 0–359.26°；有20秒30fps录像。它不证明全部高帧率GPU帧和独立装备均无闪烁。

正常DepthPlane材质的三个实际摆位截图已人工查看：A树后/B树前、交换、无树同轴；树后角色被树叶遮挡，前方角色保留正常前后关系，没有通过关闭深度或永久顶层绕过。图片仅本机 `Candidates/DS-MAP-02/Visual/pose0.png`、`pose1.png`、`pose2.png`；第三姿态的角色交叠有限，不能扩成全部交叉动作验收。连续移动/攻击由输入与实战故事覆盖。

Depth实时24/24：三身体各200自然LateUpdate帧，非法/越界bounds均0；正式mesh仍持续产生。disable恢复原间距、enable重绑、不同外来间距不被覆盖、最终还原均通过。采样期间新增自有Renderer/sharedMaterial ID均0；这不是全局内存泄漏证明。

该200帧的整Editor场景观测：median 2.508ms、p95 3.259ms、max 5.051ms，199真实间隔约383.76fps。包含夹具扫描和整场开销；未测独立组件/GPU耗时，没有同条件改前基线，也未认证30/60/120帧或玩家构建性能。修复增加每次正式mesh一次native O(vertexCapacity)的bounds重算。
