2026-10-28，本机 `work/OSSASTRA/VC01-20261021/prototype-c21/game`，Edge 无头模式，视口 **1440×900**，地址 `http://127.0.0.1:5173/?scene2d=1`。该快照的 `game/src` 245/245 个文件与固定提交 `bb969cc88591fd8e93e4c939cb52719dd652a948` 的 Git blob 相同；`game/package.json`、`playwright.config.ts`、`tests/merchant-ppt.spec.ts`、`tests/role-interaction.spec.ts`、`index.html` 也相同。此结论仅指这些文件字节，不证明依赖、资源或部署环境完全相同。

## 观察步骤和画面

1. 进入标题画面，按 Enter，再点击“开始游戏”；`window.prototype.state.phase` 变为 `battle`。点击 HUD 的“Tab 背包”按钮，显示背包画面（本地截图，未发布）：团队 5×2 格及“整理”按钮、双角色左右手槽、安全栏、重量和后备入口可见。此步用鼠标打开；键盘 Tab 的实际开启效果未由本次成功路径验证。
2. 仅为定向取景，在运行内存中把当前角色坐标移到商人坐标，并向安全栏加入 1000 枚 `trade-coin`。按 F 打开角色菜单，点击商店，选中“烤麦饼”，得到商人交易画面（本地截图，未发布）：左背包、中交易详情、右商人货架三列；详情有数量输入、报价和“F 购买”；货架显示商品库存、价钱和刷新倒计时。未实际提交买卖。
3. 关闭商店后，仅为取景把当前角色坐标移到芙蕾茜娅坐标，按 F 打开角色菜单画面（本地截图，未发布）：商店、对话、送礼物、角色装备四个入口可见。未进入对话或个人商店，也未证明后两项业务完成。
