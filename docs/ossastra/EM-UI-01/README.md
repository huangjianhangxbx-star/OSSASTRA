# EM-UI-01 横版七页菜单

## 打开

在团结打开 `Assets/OSSASTRA/SideView/SC_SideViewAdventure.unity` 并进入 Play。Esc 或手柄 Select 打开菜单，Q／E 或 LB／RB 切换记录、技能、装备、遗物、收集、信息、地图。Esc 或手柄 B 返回上层。Tab／Start 在玩法中仍打开原背包。菜单左下角打开项目原有声音设置。

- 方向键、十字键、左摇杆在当前页面移动，Enter／A 确认，鼠标可点击和滚动。
- 装备和信息可用 1／3 或 LT／RT 切换子页。长列表支持滚动。
- 地图支持区域切换、平移、缩放、回到示例位置、休息点列表和临时标记。标记随菜单会话清空。七页使用样例数据，装备、技能与地图进度的游戏逻辑仍由各自系统负责。
- 菜单捕获新玩法请求期间世界继续运行。关闭前消费已按住的共享键边沿，退出后新输入恢复。

## 从 Unity 编辑

`GameMenu.prefab` 保存 Canvas、菜单根、七个页面容器及输入适配器。页面的控件是进入菜单时创建的原生 uGUI 层级，可在 Play 模式逐项检查。要持久修改布局，编辑 `GameMenuPages.cs` 和 `GameMenuMap.cs`。样例文本集中在 `GameMenuDemoData.cs`，主题资源统一在 `ReferenceTheme.asset`。每一页的重建坐标与原始参考量测在本地研究包。

- 替换公共背景时，在主题里更换 `background.base`、`background.lines` 和 `background.fog` 对应 Sprite。
- 替换槽框，在主题里更换 `slot.skill`、`slot.equipment`、`slot.relic`、`focus.frame` 或 `focus.bracket`。顶栏导入为有边距的 Sprite，画面横向缩放时保留端帽。
- 修改样例文字或条目，在 `GameMenuDemoData.cs` 对应条目调整。图标键使用 `icon.` 加条目 ID。技能页可选绑定本地 `AxePreview`，准备视频时保留静帧，该项目支持一条演示视频。
- 源码发布只包含工程代码和本说明。局部场景与原作素材留在本机。若从新检出版本装配，准备好同名正式横版场，使用 `OSSASTRA → 横版 → 七页菜单 → 装配当前正式场`。作者工具会按 `Assets/OSSASTRA/SideView/GameMenu/LocalReference` 中的文件创建主题。如使用自有素材，文件名以下划线分隔主题键的各段，并使用自己有权限的字体和视频。
