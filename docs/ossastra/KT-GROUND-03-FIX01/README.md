# 地表闪烁修复（KT-GROUND-03-FIX01）

已定位并修复当前高台样板的共面地表层争抢深度问题。原微量硬件深度偏移无法稳定保证上层覆盖下层，相机变化时会出现条带和闪烁。

修复仅更改独立薄顶面Shader：相同平台、相同像素采用相同的平面深度计算，以既有图层绘制顺序合成。保留正常深度测试、透明裁切、贴图和材质引用；不抬高顶点、移动碰撞体或改作者Tilemap。现有材质直接生效。

- [原因、候选比较与最终方案](fix-plan.md)
- [实际测试、现场保护和未测范围](validation.md)

生产多层验证覆盖两平台各28组机位、实际D24/D32深度格式，共2,207,934个可判定样本，错误和未知均为0。独立opaque遮挡对照包含透视/正交、MSAA1/4，184组机位的内部及严格全图差异均为0。真实Play镜头45°→315°及角色/侧壁画面另有实际截图核对；这些结果不等于所有平台、长时间或任意透明边缘都已认证。

场景未替用户保存或重开。退出Play后派生缓存自动更新留下dirty状态，作者hash与Lab磁盘hash保持。诊断期间C盘曾耗尽，使诊断编译IO112失败；已恢复原run并用最小Native核对指纹，没有清理用户文件。最后只读回执有约106MiB可用，空间仍很紧张，需另行处理。
