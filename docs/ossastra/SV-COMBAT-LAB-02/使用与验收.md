# 横版攻击调试台 · 使用与验收

打开 Unity 菜单 **OSSASTRA → 战斗 → 横版攻击调试台 → 动作与音画校准**。在含正式角色的编辑场景即可浏览骨架。在「实战验证」进入独立攻击场可对照实际释放和命中。

1. 选角色和行为。已有绑定会定位实际动画和轨道。选择具体事件可看源时间、同名序号与有效帧。
2. 例如芙蕾第一段普攻 ATK1，30 FPS 时 Hit 在第 12 帧。把标记偏移设为 −1，然后点「应用候选并复位」重打。正式释放应提前到第 11 帧。只想调挥击声或刀光时，分别修改声音补偿、特效补偿。
3. 比较时间轴上的「源事件」「校准标记」「本次实录」。点「恢复正式基线」可回到正式值。满意后点「保存正式校准」，重开窗口核对。另存实验预设可保留其他方案。
4. 重新导出骨架后，如标记移位或同名事件数变化，先核对对应事件，再决定保留原有效帧或采用新时间。未完成核对的已迁移行为会报告失配。

## 本轮验证结果

| 验证 | 结果 |
| --- | --- |
| 正式资产保存与重载 | 猎人 16 条绑定，芙蕾 19 条。重新读取都能解析。 |
| A 角色释放偏移 | 独立场 a1 的 −1、0、+1 帧分别落在 0、0.0333、0.0667 秒，每次正式释放一次。 |
| 冲刺取消 | 提前请求被拒且保留原动作。开放窗口后受理。释放前成功取消，后续释放为 0。 |
| 命中、空挥与停顿 | 同次攻击未重复扣血。开关启用且命中时观察到攻击者局部停顿并恢复。关闭及空挥时均未出现停顿。 |
| B 角色走跑和攻击 | ATK1 一次释放。虚拟手柄轻推 Walk 记录 3 次落脚、3 次音频提交，普通 Move 为 7 次和 7 次。停止后为 0 次新增。 |
| 重导入核对 | 用真实 a3 片段的测试副本移动 Hit 一帧，旧绑定失配。明确改绑且保留有效帧后误差小于 0.000001 秒。插入同名事件也要求核对。 |
| 多 Hit 与循环 | 多 Hit 消费按出现顺序用数据样例验证。实际 Spine 轨道测试覆盖回调去重、偏移和跨循环。 |
| 旧流程回归 | 独立 Play 场检验换主手、换人、技能槽、释放后转身、空间命中和复位，报告为 PASS。 |

本地证据在 Reports/SideViewAttackLab 下的「边界验收.txt」和「动作与音画校准.png」。可通过 Unity 菜单「OSSASTRA → 战斗 → 验证横版攻击调试台」重新生成实战报告。音效数量是正式音频系统的提交记录，主观音量与打击感由作者试听调节。
