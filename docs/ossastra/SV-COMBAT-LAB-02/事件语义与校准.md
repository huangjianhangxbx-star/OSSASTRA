# 横版攻击的事件语义与校准

普攻或技能提出请求时，角色先按实际装备、能力、动作段和动画路由解析身体轨。校准记录的作用域是角色骨架、行为、实际片段、轨道和同名事件的出现序号。已迁移动作的释放、结束许可跟随这次播放的进度。切换装备、被打断或角色复位后，旧播放的事件没有权限推进新动作。

| 源事件 | 绑定后的含义 | 正式消费方 |
| --- | --- | --- |
| Hit | 请求释放一次。多次释放分别编号。实际命中仍由空间查询、阵营和伤害结算决定。 | 角色动作、战斗网关 |
| 动作结束可覆盖 | 允许完成当前动作、按连段规则消费提前输入。 | 动作与连段 |
| 可冲刺打断 | 打开本动作的冲刺取消窗口。成功受理冲刺才取消原动作。 | 冲刺与状态仲裁 |
| FootStep | 已迁移走跑以实际接地、有效位移和当前接触代次为发声条件。 | 横版移动音效适配器 |

本机芙蕾现用最新版游戏导出。骨架声明和实际时间轴采用 `FootStep`、`Hit`、`动作结束可覆盖`、`可冲刺打断`。猎人的早期导出依然使用 `Break`、`End`、`Footstep`，由已有绑定兼容。

芙蕾 ATK1 的冲刺许可、Hit 和结束许可分别位于第 1、10、16 帧。Move 的两次落脚在第 3、11 帧，Walk 在第 7、25 帧。五面猎人的 a1 至 a4 各有独立时间轴，其中 a2 在第 0 帧释放。芙蕾圆锯的四个片段暂无源事件，沿用既有技能时序。

按 30 FPS，源第 10 帧设为 −1、0、+1，目标分别是第 9、10、11 帧。音效与特效可各自再加补偿。设置会在下一次播放起点快照，单次渲染更新可能同时跨过数个制作帧。变速、停顿及重播以实际轨道进度核对。诊断中的消费时间使用未缩放时钟，动画局部时间使用播放轨时钟。

骨架重新导入后应核对同名序号、参数、源时间和相邻事件，再决定重新绑定及是否保留旧有效位置。真实命中的音效、震动、受击和命中停顿继续由战斗结算产生。
