# 横版动作架势与双角色输入

在团结打开 `Assets/OSSASTRA/SideView/SC_SideViewAdventure.unity`，按 Play。开场附近的击打木桩可在「动作架势诊断」中启用攻击。面板可以查看两名角色的各组破绽、恢复锁和反应阶段，也可设置当前角色为零架势或复位。木桩默认停止攻击。

| 操作 | 键鼠 | Xbox 手柄 |
| --- | --- | --- |
| 移动 | A/D；W/S 保留方向 | 左摇杆 |
| 交互 | W | 左摇杆上推后松开再推 |
| 跳跃／闪避 | Space／任一 Shift | A／B |
| 主手／副手 | 鼠标左键／右键 | X／RT |
| 技能 1／2／3 | Q／E／R | Y／LB+Y／LB+B |
| 血瓶／换人 | Y／Z | LB+A／LB+RB |
| 武器模式 | T | LT+RT |
| 快捷使用 1～4 | 1～4 | RB+X/Y/B/A |
| 背包 | Tab | Start |

芙蕾茜娅在空中用 **S+鼠标左键** 或 **左摇杆向下+X** 主动俯冲。命中后的自动腾起属于同一次俯冲。

按 **Tab** 打开背包，选中队伍物资中的「烤麦饼」，再点击快捷栏的 1～4 槽位绑定。关上背包后，可在角色受伤时按对应键使用。正式场复用原 `InventoryView` 和普通物品使用入口，初始队伍物资有四个烤麦饼。快捷键只请求对应槽位。投掷道具的驻留瞄准仍待接入。

## 架势

同语义动作补足一份缺口。不同语义可以叠加。保持防御每秒耗 10 点，启动没有架势费用。架势为零依然可以进行符合条件的动作。此时真正受到攻击才会破防并击飞。自然恢复在动作开放恢复资格后开始，破防反应期间也会回升。

本轮默认值为 100 架势，恢复等待 0.20 秒，基础恢复每秒 40 点。两名角色分别保留自己的缺口。可在场景角色的 `CombatPosture` 调整容量／恢复／防御扣减，在角色定义调恢复倍率，在动作定义指定额外暴露和真实恢复标记。

## 旧资源迁移

| 旧入口 | 正式横版接线 |
| --- | --- |
| 动作准入／接受事务 | 只在正式行动接受后登记暴露。旧体力余额不参与两个新角色。 |
| 行走、主动跳跃和攀越 | 普通移动免架势费用，移动中可自然恢复。主动跳 15。继续抓挂保留对应缺口，翻越补足到 20。 |
| 普攻、闪避、副手、能力 | 普攻目标 20，闪避 25，实际副手攻击 15，主手攻击能力和俯冲默认 30。 |
| 装备、能力来源、道具 | 弹药、数量及耐久继续由原来源预留、释放提交或取消。 |
| 持续防御 | 统一记入架势的防御缺口，归零仍能保持合法防御。 |
| 历史场／敌方 | 显式使用旧模式时保留原体力与旧架势逻辑。 |

正式攻击只绑定实际片段内存在的事件。缺失事件、取消或退场时由动作结束释放对应恢复阻塞。倒地以运动器确认实际支撑为准。

## 同步到已有正式场副本

在两名可控角色的 `CombatPosture` 启用 `Action Posture Enabled`，在 `CharacterRoot` 的 `Posture Basic Recovery Event` 填入 `Break`。猎人的 `CharacterAnimationController` 使用 `_liedownfall`、`_liedown`、`_liedownup` 作为破防三阶段片段。芙蕾茜娅启用 `Use Posture Pose Fallback`，将 `Posture Dodge Fallback Clip` 填为 `Move`。正式 `PlayerInputLayoutInstaller` 使用 `PlayerInputLayout_SideView`，接上原 `InventoryView`、库存会话、交互与共享血瓶服务。原练习敌人和角色由场景已有实例提供。
