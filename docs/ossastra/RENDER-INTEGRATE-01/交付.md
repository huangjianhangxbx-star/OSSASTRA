# 3D环境渲染接入与旧验证场整理

日期：2026-11-03。主场：`Assets/OSSASTRA/GroundWorkshop/Samples/KT-VIS-04/SC_RoomVisibilityLab.unity`。

## 使用

继续打开当前主场运行即可。GameplayCamera上的`WorldLookController`集中配置环境效果，`effects.enabled`切换原图；空气、景深、泛光、调色、暗角均有独立开关。室外引用Amber Light、Outdoor_BestVisual和Green Revision A；进入房间由现有房间权威选择Dungeon Light。室内不强加室外空气或改动原灯光。

主场原本就是XH_URP3D的UniversalRenderer。本轮在其专属Renderer15增加WorldLookRendererFeature，默认Renderer0不改，内建后处理保持关闭。相机仍45°、FOV35、distance25；没有挂会全局替换管线的旧实验Controller，也没有替换当前地图几何、角色或业务根。

## 实现

正向合法世界重建完成后提供当次绘制的许可与真实深度。许可RGB仍服务世界信息，Alpha独立标记环境；环境先写、人物/信息最后排除。效果处理中心与采样邻点都检查许可，黑幕不被空气/Bloom抬亮。视野本身、屋顶遮光和碰撞不变。

显示角色与静态历史白名单分离。世界Mesh与场景Sprite可参与；角色、NPC、敌人、Spine、粒子与登记信息保持清晰。相机再次绘制前后撤销上次输出，防同帧复用旧深度；撤销数据与释放资源分开，正常帧复用缓冲。

代码分为Runtime只读Profile快照与Rendering合法深度合成，不拥有Current、房间成员资格、存档、灯或源材质。原数据类型OutdoorAtmosphereProfile/T7BMath、RegionalLookProfile、HD2DPostProfile的既有源码与meta作为最小可编译依赖原样发布；不修改这些冻结旧文件，也不上传旧预览驱动或其整套程序集。

## 保留边界

本轮把旧档中的色调、距离空气、轻量景深/Bloom与暗角接到正式角色和可视世界。它不等于旧实验逐像素复刻：原生夕照Bokeh、地牢体积光、旧SSAO及RealToon专用材质族没有直接搬入。Green A仅复用其空气/调色数据，不把逐材质色板冒称已经全屏复现。未来真实体素资产与这些专用效果需要通过相同合法世界接口接续；未擅自把旧实验地图堆入当前主场。

场景、配置资产、截图、媒体与真实存档仅保留本机；GitHub定向发布自有源码、契约与文档，不同步Gitee。
