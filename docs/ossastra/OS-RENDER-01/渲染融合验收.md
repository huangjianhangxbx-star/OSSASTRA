# OS-RENDER-01 横版渲染融合

横版比较面板的 D OSLight 接到同一个游戏相机。D 使用 B 的远景、近背景与最终成片，角色采用独立主体校准和 OSLight 方向内边光／外柔光。A、B、C 保留原编号。打开 SC_ExposedContour 或正式 Tut_01，进入 Play，点 D，再点渲染调试。角色和共同成片有各自的显式保存按钮。

## 画面为何相差这么大

在团结 2022.3.62t18、Linear、1600×900 下固定镜头和角色姿势，依次截取 B、关闭 B 的 Bloom、关闭 Bloom 和曲线、C 融合材质、D。选定芙蕾发顶同一块 2600 像素的内部区域。显示亮度中位数分别为 255、246、239、122、229。B 在该小区域的 RGB 全通道都达到 250 的比例为 100%，其余四帧都为 0%。这个样本说明 B 的材料输出已经很亮，而大片三通道截白发生在 Bloom 合成以后。材质阶段的诊断画面仍经过相机基础显示转换，不等同于源贴图。C 的环境底光会乘进整个主体，压暗了中间调。

在 D 的早期试参中，同一发顶采样从无曲线的近中性色变成偏黄。现在角色材质根据实际使用的 RGB 曲线估计浅色区域的偏色，在最终调色之前部分补偿。最终同一发顶样点的显示 RGB 为 B (255,255,255)、C (108,127,119)、D (223,229,244)。这是同一环境下的推荐起点。源图已有的大块平涂仍会保留。

## 渲染链及所有权

1. 比较器验证分层、灯图和双角色轮廓资源。D 借用 B 世界模式并单独发布本相机的 D 标志，使用与 B 相同的 MSAA 恢复逻辑。请求失败显示实际模式与原因。
2. OSLight 在不透明绘制前为 World 和 Character 分别生成光图，向双角色提供两张方向边光图。D 世界画片使用本灯图的世界投影和相对于环境底色的局部变化量。B 的远景经 360p 模糊再合成，近景和远景使用同一灯图投影。采用现有地形几何、透明度与源材质登记。比较器在登记表替换后归还旧材质并绑定新表。
3. 两位角色各自校准环境混合、中间调和高光软肩，再从联合剪影生成方向内边光、外柔光。正常透明槽保持预乘覆盖，特殊混合槽沿原有路径。Es 的既有独立显示在正式两场均回读到开启。未给 Es 分配第三个角色轮廓槽。
4. 暗区、暗角、Bloom 和 RGB 曲线在一个最终合成入口处理。跟随角色的背景光斑在 D 默认关闭。渲染调试的 Bloom 与曲线是共同成片参数。相机结束时清理模式全局值；切换配方和卸载相机时原 Feature 负责回收灯图、临时渲染目标和材质。

## 配置与实测

- 小蓝和芙蕾的起始设置均为中间调 1、环境混合 0.32、高光保护 0.65、内光宽度 2.5／强度 0.8、外光宽度 3.8／强度 0.48。宽度按 1080p 缩放。Bloom、曲线开启，跟随光斑关闭。编辑器显式保存写入 Assets/OSSASTRA/SideView/Resources/OSLightCandidate 中选定的角色或 World 资产；首次无资产使用以上代码默认值。临时修改在同一 Play 会话跨场保留。
- 用实际 D 按钮切换，分别捕获无灯、单 Character 灯四个方向、World、Both、内光关闭、外光关闭的画面。World-only 相对无灯，角色选区没有达到 4/255 的 RGB 通道变化，而平台有 6413 个采样点超过或达到此阈值（每两像素采样）。分别关闭内光、外光在角色区产生了可测变化。实际 Game 帧录下灯绕角色移动并换人；视频按每秒 12 帧编码。
- 临时槽从标题新建，经物理入口 Tut_01:left3、Tut_02:right2 往返。三次落地均是不同 Scene handle，D、十张灯图和 Es 独立 Renderer 均生效。验证结束返回原地图编辑现场，未保存场景。
- 同一设备的功能抽样中，统计名含 Side view 或 ACE 的活动 RT：B 为 8 个约 25.6 MB，C 为 10 个约 28.8 MB，D 为 18 个约 54.4 MB。D→A→D 后回到相同数量和字节。该口径不含共用相机附件和通用角色剪影。单帧 CPU/GPU 读数受编辑器与截图影响，不能作为稳定帧率预算。
- 范围限制：没有对所有地图做美术验收；原作地形数据、地图重铺／撤销及几何裁切由地图任务维护。实际独立运行包、所有攻击姿态遮挡和长时显存压力仍缺专门验收。画面对照、区域定义、帧计数及动态记录保留在本机 work/OS-RENDER-01。
- 额外在 Play 中替换一条实际画片登记，旧 Renderer 回到源材质，新 Renderer 获得 ComparisonCard，随后成功恢复原表。把相机目标设为 1280×720，D 同帧执行 Grade 并持有 10 张灯图，归还后恢复 1600×900。这验证了尺寸切换和重新绑定；第二尺寸的逐像素配准、地编全流程重铺与撤销仍应分别验收。
