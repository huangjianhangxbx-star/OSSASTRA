## 星骸回廊接入建议

保留 `EnemyRoot` 和共享动作、命中结算。借丝之歌的显式前摇、释放、恢复和碰撞回执组织执行，借 ENDER 的数据装配与非战斗／战斗子策略分工。横版敌人需要中立的 XY 战斗空间、两个队员的候选资格、招式承诺时的目标或方向和独立中断规则。主控切换后用同一场景和同一招式核验目标选择、方向承诺、命中资格与自然挥空。历史 XZ 战斗纳入回归。

建议首只用 Bone Thumper 验证接入。五种候选组合为 ENDER Gang `e0161_gang`、Mimic `e0100_mimic`，丝之歌 MossBone Fly、MossBone Crawler、Bone Thumper。建议 Mossbone Mother 作独立 Boss，替代候选包括 Ronin。最终参考策略、名单、地图拓扑、出入口方向与楼层由 G1 决定。

本机 Tut_01 ↔ Tut_02 双场已有跨场世界状态验收。Tut_02 仍是入口切片，三种渲染完整接线、角色及 ES 参考显示和正式构建登记需随选定地图验收。多图保存沿用统一领域快照，休息登记 `RegionId` 和稳定检查点，由角色与世界领域分别持有数据。离房刷新与持久状态分开配置。档案摘要需与活动会话分离，复制存档按目标槽重新封装。Boss 完成后先确认一次聚合写入，再关闭活动会话并返回标题；历史通关档从已保存的安全锚点恢复。
