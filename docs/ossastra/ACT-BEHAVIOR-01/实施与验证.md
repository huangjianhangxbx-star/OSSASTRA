# ACT-BEHAVIOR-01 复杂招式与链匕首

## 在现有手感场试打

1. 打开「OSSASTRA → 战斗 → 横版角色手感调试台」，进入已有的手感场，并将主控切到芙蕾。
2. 打开「招式效果 → 芙蕾链匕首连段」，设平地、可动轻靶。靶距设为 3.1 U，点击「B · 链匕首并复位」。
3. 在 Game 视图按现有普攻键打完前三段。第三段退步时会投出匕首。调整第四次普攻输入时机，观察面板提示的回拉、动画许可和输入状态。轻靶到位后仍在接段窗口内时，新的普攻输入可接飞踢。
4. 点击「A · 来源并复位」切回当前正式配方，B 可继续编辑。需要应用到正式招式时，分别使用第三段、3→4 连接或第四段对应的写回按钮。B 派生于实际生效的来源，候选保存在本机 UserSettings。

## 实际来源与候选

| 段位 | 本机动画 | A 当前正式来源 | B 链匕首 |
| --- | --- | --- | --- |
| 1 | 匕首/ATK1 | 现有快斩和自身位移 | 沿用 A |
| 2 | 匕首/ATK2 | 现有攻击与效果 | 沿用 A |
| 3 | 匕首/ATK3 | 原近战和约 2 U 后撤 | 保留自身位移。真实 Hit 事件释放单目标匕首，成功接触并拉到位后满足逐连接条件 |
| 4 | 匕首/ATK-踢 | 原位移和近战。击退约 1 U，0.15 秒 | 沿用真实飞踢与现有击退。仍需再次实际命中 |

本机芙蕾当前由角色定义的四段普攻提供配方。第三段释放约 0.20 秒，动画接段标记约 0.433 秒。第四段有自己的释放标记。不同角色或装备按有效 ComboSource 读对应配置。

B 初值采用 5 U 射程、16 U/s 飞行速度、15 U/s 回拉速度、0.50 秒回拉期限。目标停靠距离至少 0.86 U，实际距离还考虑双方碰撞主体，水平到位容差 0.12 U，高度差上限 0.65 U。攻击者移动超过 0.75 U 会结束回拉。连段窗口和缓存读取原有连段配置。

## 运行边界

- 普攻沿用原输入、受理、架势和动画事务。可选的专职执行器接收同一个父动作身份。构造期投递在运行对象和回执路由建立后登记，普通攻击还需等待真实释放。首个回执可在投递调用内同步到达。
- 飞行以首个实物接触为终点，命中走共享网关。回拉把目标位移交给共同运动器；到位以实际位移判定。取消按本次执行身份归还运动，目标生命或装备实例变更会关闭旧资格。
- 第三段身体自然结束后，剩余飞行与回拉仍可在当前接段窗口推进。第四段通过原准入时一次性消费交接，第四段的伤害和击退由自己的碰撞判定产生。
- 链条与匕首是程序占位，链端优先接现有角色挂点。投掷和踢击已经使用芙蕾本机 Spine 片段。待制作的是专用牵引姿态、正式匕首与链条素材，以及最终手感校准。

## 验证

| 场景 | 实测结果 |
| --- | --- |
| 角色默认与装备动作组 V01 | 同一个通用计数执行器分别运行。构造期提前接触均为 0，真实释放和正式回执各 1 次。正式伤害分别为 12、15。复位只取消 1 次 |
| 第三段受理与同步命中 V02–V03 | 第三段受理后架势账本登记一个恢复占用，链匕首投递一次，没有额外模板近战。同步重叠通过共享投递器，多碰撞体仅结算一次 |
| 正常连段 V04 | 正式鼠标输入受理四段。轻靶由 X 3.10 拉至约 −0.07，飞踢真实命中一次，推至约 0.93 |
| 条件关闭 V05–V06 | 回拉完成无输入、早按过期、落空、墙阻、格挡、免推和命中后死亡均未接第四段。落空后新按键从第一段开始。起点不合法实体阻挡后方合法目标 |
| 运动与取消 V07–V08 | 共同运动器验证到位、实体墙阻挡、免推、独占、幂等取消及普通推移保留。试打中途取消回拉后只移动了约 0.07 U。回拉中换人关闭旧连接 |
| 窗口与交接 V09–V10 | 合同测试覆盖两种先后顺序、截止等号、晚到回执、失败后旧输入清除。实机回拉临近到位时只按一次，既有输入缓存成功接第四段 |
| 飞踢重新判定 V11 | 四段受理后将靶移到飞踢范围之外，第四击对该靶的实中为 0，无回拉残留 |
| 候选与隔离 V12 | 候选深复制效果与执行器，保留第四段效果和其他连接。本机序列化后冷读通过。靶在到位后重置生命，旧资格失效，新按键重新进入第一段 |
| 暂停和回归 V13–V14 | 全局暂停期间来源模拟钟和靶位移冻结，恢复后完成第四击。双方都进入局部命中停顿。A 保留普通四段，既有圆锯通过三段播放、输入微移、多次真实接触、推移和装备还原回归 |

定向运行使用 Tuanjie 2022.3.62t18 的原有手感场，另运行连段、技能、主手配方和体力预约测试，共 82 项通过。B 是试打候选，正式写回待作者选择。破防与回拉恰好同帧、第四段资源准入拒绝的组合未单独做实机夹具。
