# VEGETATION-01A：主研究场半幅接入

用户于2026-11-10认可v1.2小样，并明确授权放入当前主研究场、覆盖原地台约一半。本轮沿用同一任务，不重建场景。

- 主场：Assets/OSSASTRA/GroundWorkshop/Samples/KT-VIS-04/SC_RoomVisibilityLab.unity。
- 层级根：GrassMain_原生地台半幅_二维草浪。取消GrassLayer组件勾选可临时隐藏草；相机作者俯角45度、原地形与碰撞保持。
- 从224块Native地形中选朝上的Grass槽三角，按XZ投影面积精确二分，正X半幅分界x=-0.182692319；原草顶3067.75平方米，选择1533.875平方米。半幅是排除前范围，未把建筑、水面等不可种区也强行填满。
- 道路、建筑占地加0.4米、实际高处覆盖、101个当前实体Box及样板底板排除后38106簇、184合并块。原B的36簇/平方米、形体/配色/风参数保留，独立Main Profile只提高生成容量；六项自有资产位于Assets/OSSASTRA/WorldRendering/Vegetation/MainGrass。
- 单一明确草顶survey只用于生成，Collider生成完即禁用。它不是新物理地面；运行无逐草射线、GameObject或Update。色图512平方只烘焙一次，源基础色/UV/顶点色由明确Voxel材质折算；没有常驻顶视相机。
- 原RoomPresentationBinding逐块登记和精确销毁，ForcePartial=true；不把DontSave显示块引用存入作者sharedSurfaces。草本身Shader新增RoomSight/RoomTruth，保留0至3原Pass；最终颜色、真值、标签共用原风/LOD/Alpha，未知家族仍拒绝，不绕黑幕。
- 该动态叶路线不使用静态历史退场权限：失去视野时草立即隔离，不延续过期室外信息。绑定为地表环境角色，并仅对精确Grass源恢复WorldLook环境归属。

已验：Room适配实际44检查通过，Registry禁用/重启归还通过；真实私有GPU20检查/14采样通过，风动轮廓/Truth/Label一致、禁视半区0像素；源Profile不改。主场保存并冷重开，38106/184、注册184、原37根、45度、跟随开启、草物理Collider0均读回通过。

主场真实组合成本高于独立Lab。本轮做固定45度off/on/off复测，初版GPU中位11.37/34.73/11.40ms、整帧26.15/37.57/25.60ms；先移Alpha裁剪并未降低实测GPU成本，不能把理论优化当成果。继续针对手工DrawRenderer未使用URP剔除结果的问题，仅将精确草材质纳入原有保守视锥检查，网格与自定义Renderer bounds取并集，并保留风动扩张边界；3项RED→0项失败，普通装饰/混槽/缺网格/无可信视锥保守保持。最终数据见本轮回执，不能用旧Lab的0.118ms替代主场数据。

本机证据：artifacts/VEGETATION-01A/main-integration/及MainIntegration/（GPU/视锥合同输出）。独立草Lab仍保留。未承诺主场稳定60、Player组合预算或所有美术风格定稿；本轮目标是半幅真实接入。
