# 二维草表现层 Implementation Plan

> 本任务由Root逐项实施，几何分布子任务只写隔离候选；唯一Unity/Git writer在共享登记中声明。按用户已批准v1.0及优先v1.1连续执行。

**Goal:** 一套现有透明草图在独立场呈现成片、贴地、根固定且阵风连续的动态草层；不自动主场回接。

**Architecture:** 显式Collider表面编辑时采样，保存surface索引与局部根/法线；确定性分布按空间合并为小网格块，两张交叉的纵向分段贴图面承载同一草图。现有同相机环境快照提供时间/风，材质内公共HLSL供颜色、深度、阴影使用；静态变体绕开风运算。风外观配置和分布独立。

**Tech Stack:** Tuanjie2022.3.62t16 / URP14.2.0-t1 / C# / HLSL；Native资产创建，B级定向验证。

**Spec:** 外部研究/植被/VEGETATION-01A/approved-plan中的v1.0与v1.1原件，SHA见任务记录。

## v1.2 视频路线增量（优先于下方旧阶段清单）

保留4099簇候选A、原图、根尖与分块；B在同一个Shader增加Tutorial艺术色与Environment适配分支。Depth为观察距离配色，HeightBlend为逐簇UV1.w；TerrainColor为每个surface单独的一次性线性基础色图（alpha有效区），不建每帧取色相机。Tutorial手工主阴影混色；Environment将未受光设计色交既有EnvironmentShade一次，避免重复阴影，不复制环境权威。

R0现场已保存到v12-r0.json及A截图，A/B独立作者副本已建。R1在已有地表筛选4.6×5米小片，固定同一草图/密度/高度与分布，加三块地表配色证明取色。R2细噪声与世界纹理粗风共用既有时间，双滚动交叉混合保证16秒端点连续；粗风varying参与颜色，不另加片元风采样。R3正午/暮色/深夜与实际局部灯；R4扩回已有双表面并测S0–S3及较高密度；R5保存重开、归还Main并交候选。正常45°机位是主要验收，30°仅教程诊断。原视频本地有限精确搜索未找到，关键帧已核，不能声称每个常量原样复刻。

三色真实GPU基础色烘焙合同已通过（偏移/非正方/+Z/上层先绘深度/无源alpha/资源归还）；这不代替小样视觉或性能通过。

## 约束与范围

- 唯一选GrassTuft.png，使用UV裁切，不覆盖图片/Importer。不增加实体逐叶资产或第二草型。
- 原Main/CHAR/Profile/共享Room与环境后端/管线/碰撞保持；LOOKDEV仍独立file-only。
- 当前Room后端精确Shader白名单不支持新草Shader，Full也先检查家族。独立普通URP候选可验证；门户/黑幕集成标不支持，禁止主场回接或用Graphics提交逃过许可。共享适配另行协调。
- 草簇不是GameObject；仅合并块各有MeshRenderer。无逐草Update、逐帧射线或顶点重写。
- Native加法场保留原dirty Main在内存，记录并临时停用原根，草场结束精确恢复；不隐式Save原Main。
