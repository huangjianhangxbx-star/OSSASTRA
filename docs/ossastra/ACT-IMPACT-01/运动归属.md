# 招式运动的归属与优先级

每个横版本体独立持有 ActionImpactMotor。首次收到合法运动请求时，组件挂在本体已有运动器所在对象上。默认沿用 CombatStatusEffects 原有 impactWeight 受推倍率。可预先挂载、勾选 Override Resistance 并配置 Push Resistance，0、0.6、1 分别适合轻靶、重靶和免疫靶的 SAMPLE。禁用运动器的固定靶返回拒绝原因。组件只接受、合成与记录请求，物理提交发生在原运动器内。

| 输入 | 仲裁与时钟 | 写入与收尾 |
|---|---|---|
| 普攻或技能自己的曲线位移、命中反冲 | 主动与反冲分别占用通道并合成，同通道比较距离除以总时长；较强者胜出，等强刷新。曲线每步只取进度差。 | 玩家 CharacterMovement.MoveOnce 消费一次。动作结束按动作 ID 归还该动作的位移。 |
| 目标普通推移 | 在接收本体上独立累计，乘以 1 减抗性，与自身位移分别计算。 | 玩家、地图敌人、活动木靶分别经 CharacterMovement、SideViewEnemyBrain.Step、EnemyMovement.Tick 推动胶囊。攻击者结束不清目标推移。 |
| 输入窗口 | 原 Move 权限和角色准入仍由状态机检查，仅开放本次动作的 MoveReady 窗口。多个窗口和原能力取最低速度倍率，方向取交集。 | 实际输入为零时输入分量立即清零。结束/取消按动作 ID 清理，命名窗口也支持单项关闭。 |
| 全身微移 | 行为层继续提供真实 IsMoving 和 Velocity。表现层通过 PresentsLocomotion、冻结的动作朝向和已有攻击轨保持全身动画。 | 原 SideStepCompleted 记录实际步。全身微移及受迫运动关闭该步脚步音资格。保留走 A 的配置可使用原行走轨。 |
| Launch | 初速度只写入一次。玩家沿地图跳跃参数积分，敌人沿自身胶囊提交和横版重力积分。 | 真实碰顶取消上升，落地归还水平冲量。已起跳后的重力和落地继续。 |
| 破防、专属俯冲/反弹、换人退场、攀越、闪避、既有强控 | 这些既有运动先决，发生冲突时丢弃待执行的普通运动。暂停/局部卡肉期间本体不推进运动步。 | 在实际游戏步使用相同原碰撞入口；不会因运动请求制造承伤、架势破防或动作取消。 |

```text
动作 Accepted / Released / 网关已结算接触
    → ActionImpactRun（冻结的动作身份、朝向和条目）
    → 目标或自身 ActionImpactMotor（输入窗口、推移、发射）
    → 玩家 TickSideView / 地图敌人 Step / 可动靶 Tick
    → CharacterController.Move
    → 实际坐标、碰撞与原调试台轨迹
```

变量 InputHorizontalSpeed 是自愿输入的请求速度；EffectHorizontalSpeed 是该物理步词条请求的水平分量；ActualHorizontalSpeed 从实际根前后位置计算，受碰撞、地形扫掠和平台影响。LastRequestedStep、LastActualStep 提供活跃受击运动最近一次提交的 XY。请求距离不承诺穿过阻挡，阻挡损失不累积到下一步。
