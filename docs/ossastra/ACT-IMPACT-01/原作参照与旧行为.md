# 招式运动的参照与改动前基线

## 可复查的原作数据

死亡细胞 Steam build 23762174。只读本机 res.pak 中 data.cdb 的 weapon 表，检查 141 个定义中的五种；未导出原作内容。以下数字为设计表原值，实际两实体位移、抗性与卡肉先后仍为 UNKNOWN。bump 未校准为 Unity 世界距离。

| 武器 | 分段证据 | 对本工程的用处 |
| --- | --- | --- |
| StartSword | hitFrame 5、7、9；lockCtrlAfter 0、0、0.25；区域宽 2.7、2.7、3.5 | 末击的移动窗口可独立设定 |
| BroadSword | hitFrame 8、12、16；lockCtrlAfter 0.2、0.25、0.4 | 蓄势与收招需要真实段身份 |
| BumpBoots | 前两段 bump 1.25，末段 2；duration 均 0.5 | 配置同招不同段的推移 |
| MultiKickBoots | 第二段 bump 0.3，第三段 1；第三段 duration 0.6 | 多段不宜共享一次强推 |
| DashSword | 第一段 bump 1.2，后两段 0.2；第一段区域宽 7.5 | 攻击范围与反应各自调整 |

丝之歌 Steam build 22479045，版本 1.0.30000。复用本机研究 SV-ACTION-01-FIX01 的 HeroController 摘录，及 SV-DIVE-01《原作机制与证据》的目标回执与录像分析。普通与长反冲选择不同水平速度；装备可改变步数，写入刚体水平速度时保留当前垂直速度。长反冲分支还会重置攻击。Hunter 下刺在合格目标响应后排入反弹，落空触地走另一路径。源码与资源支持命中分支的存在；最优连击距离和不同重量敌人的实战轨迹仍待测。

## 现状矩阵

| 权威入口 | 既有消费者及保留点 |
| --- | --- |
| MainActionProfileSO 的 stage、dashAt、dashDistance、dashDuration | CharacterMainAction 随正式段位冻结，沿 CharacterMovement 运动覆盖。新样板需检查与旧前冲重叠。 |
| ActionDefinitionSO，AbilityDefinitionSO 与能力执行器 | 基础伤害、技能费用、时序与装备选择继续使用既有定义。圆锯原走 A、俯冲的首次命中弹起均各有所有者。 |
| Spine 校准 Hit / End、角色动作事务 | Hit 请求释放，真实伤害和有效接触由战斗网关决定。过期播放不能取得下一动作的控制权。 |
| CharacterMovement / EnemyMovement / SideViewEnemyBrain | 角色碰撞器、普通敌人运动器、横版 AI 各自拥有实际位移。破防和俯冲优先；普通轻推不写 HP 或架势。 |
| 旧 CombatStatusEffects 与 CombatPosture | 原有强制运动和硬直仍是合法强控入口。推移抗性不表示伤害免疫。 |
| SideViewFeedbackRuntime | 用既有接触和双方卡肉，音画继续由现有反馈链提交。 |

旧手感台回执在本地基线记录了普攻 A3→A4、E 技能盾冲、HP 10000→9980 及手柄转身后冻结释放方向；其后部分用例失去角色输入权，此次基线不能视为全绿。既有已存实验记录中，芙蕾俯冲首次命中 18 点并弹起一次，圆锯三段与轨道融合、架势归零后实际承伤触发破防均有专项验收。历史记录与本轮复测分开统计。
