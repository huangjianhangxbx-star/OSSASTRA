# 用现有调试台编写招式效果

打开 **OSSASTRA → 战斗 → 横版角色手感调试台**，进入独立测试场，选择「招式效果」页。先选角色、主手动作组、要试的具体段位或技能。副手装备有正式能力绑定时，短按和长按定义也会列出。面板显示所选 SO 的工程路径。

1. 选可动轻靶和平地，载入「轻型普攻」候选，展开「招式效果」。通过添加菜单组合词条，逐条启停、拖动参数、复制、上移或下移。通道留空会匹配所有投递，释放序号从 0 开始，-1 匹配所有释放。
2. 点「B · 应用候选并复位」，回到 Game 按正式键位出招。选定角色在所选招式下次接受时使用这一版。继续修改面板后，再次应用 B 可切换到新候选。点「A · 来源并复位」复测相同输入，待试副本保留下来。原招式已有前冲和俯冲运动仍归原技能管理。
3. 切换重靶、免推靶、格挡、空挥、双目标，或切到台沿、墙边和低顶。页内可读最近真实运动步的 XY、输入与效果速度、目标抗性和请求偏差。选「试玩与记录」查看完整试验时间线，「招式效果」轨道对应实际激活、拒绝和结束事实。
4. 确认后点「写回所选招式」，在显示路径和共享影响的对话框确认。只写效果字段。希望保留原 SO 时选「另存独立样板」，并按需在装备中引用新 SO。关闭窗口或结束 Play 会释放临时覆盖和未保存候选。

## 初始试验配方

| 样板 | 参考来源 | 用途 |
|---|---|---|
| 轻型普攻、末击、后撤、自身后跳 | Rozeul_Basic1、4、2、3 | 输入微移、命中后退、反向位移、真实初速 |
| 踢击、挑飞 | hunter-break、hunter-sweep | 复用现有动画验证目标推移和腾空 |
| 圆锯持续 | SawSustain.asset 内的起手、循环、收招和持续执行器 | 保留走 A，在合法接触造成轻推 |

全部数值均为 SAMPLE。圆锯资产只保存三段技术动作、执行器和效果。芙蕾的动画映射在角色上解析，三个动作按历史配方分别使用 4、2 和 12 帧（30 fps）。

在独立测试场的「招式效果」页切到芙蕾（角色槽 `temporary-b`），点击「临时试装圆锯到芙蕾 Q」。回到 Game 按住 Q 看起手和循环，松开 Q 看收招。选择可动轻靶可比较每次真实接触的推移。A/B 复位后仍能继续用 Q 比较。点击「归还圆锯并恢复原 Q」、切人、关闭窗口或结束试玩时，会恢复原主手和 Q 选择。
