# 招式词条与真实回执

普攻使用所选段的 ActionDefinitionSO.effects，技能使用实际接受的 AbilityDefinitionSO.effects。技能复用动作动画时只读取技能自己的列表。历史 SkillDefinition 通过旧主动作接口执行时读其 ActionDefinitionSO。建议先在调试台建立候选。列表每项保有独立 ID，禁用一项或开启总旁路会从下次动作生效。

| 条目 | 常用触发 | 行为 |
|---|---|---|
| 自身主动位移 | Accepted、Released 或 SpineEvent | 按冻结朝向前后位移，或读触发瞬间的输入方向/自定义 XY。旧阶段已有前冲时旧配置优先，并反馈拒绝原因。 |
| 攻击期间输入移动 | Accepted 或阶段事件 | 请求移动倍率、仅前/仅后/双向及全身攻击保持。MoveReady 可提前关闭单个窗口，正式取消/结束归还该动作的全部窗口。 |
| 目标推移 | Contact | 对实际存活的被击本体按抵抗和碰撞执行。可选远离发动者或按冻结朝向。默认同目标同释放一次。 |
| 命中反冲 | Contact | 对出招者反向位移，默认同一释放一次。动作终结后的离手命中仅可对目标生效。 |
| 击飞/后跳 | 自身用动作事件，目标用 Contact | 配置水平与垂直初速度，水平分量随冻结朝向翻转，落地和顶撞由运动所有者裁定。 |

释放事件可指定释放序号、投递通道，接触可选择允许格挡。SpineEvent 匹配当前身体动作身份、阶段身份和实际事件原名。无相应事件时该项此轮不会触发，动作仍按原事件或时间线结束。地空条件按发动者取样。直接普攻没有具名通道，通道留空。频率可按动作、释放、每释放每个目标、发动者模拟钟的最短间隔控制；次数上限为 0 表示不限。同类运动的优先级取决于接收器反馈，调试台的「激活/拒绝」记录动作、投递、条目与目标身份。

```text
正式普攻段 / 技能接受 / 横版敌人可选 EnemyActionImpactBinding
    └─ ActionImpactRun 冻结词条、曲线、身份与朝向
        ├─ 接受、阶段、Spine 事件 → 自身短程运动 / 输入窗口
        └─ 真实释放 → 以 AttackRelease 实例绑定运行快照
             └─ CombatContactGateway → HP、原防御及架势结算
                 └─ ActionEffectLedger 判定接触、目标存活、去重、发起者窗口
                     └─ ActionImpactMotor → 现有玩家或敌方运动器 → 物理提交
```

敌人可以在 EnemyRoot 同一对象上挂 EnemyActionImpactBinding，把所选 ActionDefinitionSO 赋给 effectSource。挂件仅取效果条目，AI、原攻击伤害、目标和释放时序仍由 EnemyRoot 决定。敌人无玩家输入，玩家输入相关词条会被拒绝。开发靶没有合法横版运动主体时，同一回执会给出无可动目标。

## 边界验证

从正式工程根运行 `./docs/ossastra/ACT-IMPACT-01/VerifyEffectLedger.ps1`（PowerShell 7）。脚本读取实际生产台账源码、本机 Unity 编译的 Ossastra.CharacterCore.dll 和真实 AttackRelease，不需启动 Play。覆盖两次释放、两个目标、重复目标、不同发动者、时间间隔/上限、六类命中结果、致死及正式结束后离手目标。物理碰撞、动画和操作手感以游戏内验证为准。

换相词条的“进入片段”可填实际角色配置的主片段名。例如圆锯的收招填 `圆锯-技能1-3`。留空匹配任意正式换相。两个阶段共用同一主片段时，这个条件会匹配两者，最终次数仍由频率和上限决定。

敌方在途投递携带受理时的生命代际。同一敌人在同一条生命中收招后，迟到的真实命中仍可推移存活目标。敌人死亡再复活后，上一条生命的回执只走原有伤害结算，运动词条已失效。复活后重新受理的招式使用新快照。
