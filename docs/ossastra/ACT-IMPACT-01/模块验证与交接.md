# 招式效果的使用与验证

正式工程 OSSASTRA，目标分支 GitHub main，开发参考 e288eff5。本机开发基点 871bcbe1，与目标分支有分叉。发布时已纳入物理实验室先行发布的 fcde5b4a。用户确认了可配置架构和实现范围，具体位移、曲线和抗性仍是试玩样值。

## 从一个招式开始

在团结编辑器打开「OSSASTRA → 战斗 → 横版角色手感调试台」，进入独立训练场，在「招式效果」页选择角色、武器和普攻段或技能。选轻靶，载入「连段末击」，点「B · 应用候选并复位」，打一刀观察双方。切到「A · 来源并复位」可在同一位置重试。对比满意后再选择写入所选 SO 或另存独立样板。正常游戏通过装备或能力目录指向同一种定义。

七份独立样板在 `Assets/OSSASTRA/Configs/ActionImpactSamples`。轻击、末击、后撤、自身后跳复用主角普攻段，踢击和挑飞复用已有技能动画。选择芙蕾，点「临时试装圆锯到芙蕾 Q」，回到 Game 按住 Q，再松开观察收招。「归还圆锯并恢复原 Q」会还原原主手和技能槽。这个入口使用带三段动作子资产的 SawSustain 样板和角色现有骨架，即使本机缺少原私有圆锯装备目录，也能操作。正式装备的永久引用仍由作者选择。

## 技术验收

在独立场沿正式出招、真实命中网关和运动器测量。2026-11-26 的最终专项 31 项通过，原手感台回归 51 项通过。位移单位为 Unity 世界单位，轨迹从本体根读取。

| 试验 | 实测 |
|---|---|
| 后撤空挥，A/B 和左右朝向 | 总旁路 0，开启后分别 −0.600 和 +0.600，无伤害 |
| 末击同时前进与反冲 | 自身前进 0.240，命中后净位移 0.120；目标移动 0.450、损失 12 HP |
| 同一踢击依次对轻、重、免推靶 | 目标分别移动 0.800、0.320 和 0.000，三者各损失 12 HP；经主角技能入口复测轻靶移动 0.800、损失 20 HP |
| 双目标、格挡、致死 | 双靶各损失 12 HP，攻击者只后退 0.120；格挡无伤害无反冲，击杀 1 HP 目标仍只反冲一次 |
| 攻击中的输入微移 | 键盘和虚拟手柄经 Input System 均推动角色约 0.14。手柄验证读取攻击片段 a1，七个有输入的运动步均未取得脚步音资格；仅前向窗口反向输入位移为 0 |
| 击飞、后跳和敌方攻击 | 目标挑飞达约 0.81 高后落回原支撑；主动后跳的真实峰高约 0.16。原敌人攻击实际令玩家损失 20 HP、后退 0.600 |
| 动作实例与离手 | 43 项台账测试通过；另以实际网关和冻结快照投递双靶，两靶各收到 0.600、攻击者收到一次 −0.120。原动作结束后的在途投递仍给目标 0.600，攻击者收到 0 |
| 曲线积分与碰顶 | 用原 EnemyMovement.Tick 推真实胶囊，按 30、60、120 Hz 分别执行，0.750 请求三次实测均为 0.7500。碰顶后峰高 0.540，真实落地；零步长、取消、抗性与强弱冲突同时检查 |
| 编辑器工作流 | 对普攻与技能各走一次添加、修改顺序、复制、禁用、Undo/Redo、写回临时资产、重新导入读回。六份样板的外部 GUID 集合分别与原来源相同。圆锯样板在一个文件中保存技能、执行器和三段动作，外部仅引用三份脚本 |
| 圆锯、下冲与切换 | 芙蕾按住 Q，第二段轨道循环超过 1.2 秒；松键进入第三段并正常终结，收招专属词条触发一次。6 次接触各推 0.020，累计实移 0.120。蓄持消耗架势，收招归还恢复窗口，归还试装后原武器、Q 槽恢复。下冲经真实输入命中并反弹，换人后新角色独占输入并正常出招 |
| 敌方死亡代际 | 敌人死亡并复活后，上条生命留下的在途投递触发的运动为 0。复活后接受的新招式按更新配置得到 2.400 |
| 敌方起手受推 | 敌人在自己已接受的攻击中实际承伤，被推开 0.100，随后原动作以同一身份正常释放 |
| 原走 A 与破防 | 芙蕾持 Q 并向前时实际移动 0.053，Spine 第 0 轨播放 Walk，第 1 轨播放移动版圆锯循环。架势为 0 时玩家仍能发动普攻；敌方真实命中令 HP 从 100 降至 80，破防反应按击飞、倒地、起身走完，根峰高 0.389，同时附带的普通推移与挑飞均未接管运动 |
| 正式玩家的空间、控制与局部卡肉 | 平地请求 1.500 实走 1.500，墙前同请求只走 0.365，高台沿下落 2.250 后着地。三个工况均在物理帧同步后由正式近战空间查询命中同一胶囊，Z 最大偏差 0.00000。移动平台带行 0.200 与自身移动 0.300 合计 0.500。卡肉期间四次仲裁更新没有推进位移，解冻首步 0.050，眩晕后旧位移余量清除 |
| 原手感台 | 「验证横版攻击调试台」51 项全部通过，包含主手 A3→A4、E 盾冲、方向冻结、芙蕾 ATK1、冲刺取消窗口、双靶卡肉、位移震屏、音效、脚步、跳跃、低顶与高台攀越。原始回执在 `Reports/SideViewAttackLab/边界验收.txt` |

从菜单「OSSASTRA → 战斗 → 验证招式效果」可重跑游戏内专项。原始日志输出到 `Reports/SideViewAttackLab/招式效果验收.txt`。命中策略可用 `pwsh -File docs/ossastra/ACT-IMPACT-01/VerifyEffectLedger.ps1` 独立复核。其余两个运动、命中探针在本目录的「验证」子目录，使用团结的 Edit 预览场，不写场景或样板。设备输入通过 Input System 虚拟设备提供。斜坡实操、拔掉实体手柄和系统窗口失焦期间的手感没有单独实测。

## 后续边界

初版支持主动位移、输入移动倍率、目标推移、自身反冲和初速击飞。目标限时减速、强控继续由 CombatStatusEffects 和架势权威处理；未新增对应词条。持续接触推压、牵引、撞墙二次伤害属于后续范围。原作参考里未经测量的参数和轨迹单列于《原作参照与旧行为》。

隔离发布索引以正式远端树为父，仅应用本任务的代码、样板和说明。结合本机已有团结、Spine 及工程依赖，运行时和编辑器程序集均做了候选编译。完全依靠该远端快照编译全部历史 Assets 时，基线 DRPG 模块缺少 WebCryptBattleBackdrop 源文件。项目整体干净克隆可构建性仍待该模块处理。
