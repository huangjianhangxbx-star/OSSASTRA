# KT-GROUND-01：原创地表替换规格

本页规定怎样为当前地表模块制作原创资源，以及哪些接线仍需手动完成。当前整场为64×48米、3072m²；地表使用原生Tilemap作者数据。原创替换可以沿用这套组织方式，不需要照描参考资产的草叶、配色或边缘轮廓。

当前仍是研究用资源和工具基础，尚没有“任意素材拖入就自动完成七层换肤”的正式管线。源事实和适配差异见 [source-findings](source-findings.md)、[source-to-unity](source-to-unity.md)；刷地操作见 [brush-guide](brush-guide.md)。

## 兼容当前场景的资产交付

| 资产 | 当前兼容规格 | 制作要求 |
|---|---|---|
| 七套地表底纹 | 每套1024×1024，正方形、可无缝平铺 | 提供基础覆盖、不同草地覆盖与道路等七层用途；具体颜色和纹样可原创。RGB为地面颜色，不把边缘轮廓画死在底纹内 |
| 一套边缘mask | 15片，每片128×128，居中pivot、PPU99 | 形状写入alpha；白色RGB配透明背景即可。形状、毛边与破碎感可原创，但必须与自有RuleTile输出的语义一致 |
| 共用mask图集 | 当前1024×512，一张图集包含15片，矩形切片，不旋转打包 | 交付明确的切片名称、Rect与pivot信息。用同一图集生成Sprite Multiple，避免15张独立纹理造成额外切换 |
| 自有Tile/RuleTile | 基础覆盖Tile，以及覆盖层所需RuleTile | 明确默认、实心、孤立、边缘、转角等输出用途与旋转。当前15片是本轮兼容规格，不是所有原创方案都必须具有的数量 |
| 自有地表材质 | 继续使用本工程的Unlit地表Shader，按层绑定底纹 | 七层可共用Shader和mask纹理，但不同底纹仍需要对应材质。当前受控材质须放在 `Assets/OSSASTRA/GroundResearch/LocalGenerated/` 内，并使用本轮自有Shader；任意外部材质白名单尚未接入 |
| 来源与用途说明 | 对应GroundLayer的名称、来源、绘制/擦除和预览字段 | 使用自己的资产ID与证据说明，替换素材后不得继续保留“原参考Sprite/纹理已验证”等过时描述 |

建议为每个原创资源族单独保存底纹、图集、Tile/RuleTile、材质和简短命名表。底纹、图集与Tile可使用 `Assets/OSSASTRA/Art/OriginalGround/<资源族>/`；这是建议目录，不表示已生成原创资产。当前材质刷新路径有独立白名单：材质须在 `Assets/OSSASTRA/GroundResearch/LocalGenerated/<资源族>/`，外部目录材质会被明确拒绝。该路径属于研究生成区，正式原创管线应在后续模块梳理中扩展。

如果使用不同尺寸、不同PPU、更多mask、不同邻接或多套边缘族，需要同时调整Sprite导入、规则配置和相应验证。当前Importer不会自动理解这些变化，也不会根据新图案猜出规则语义。

## 尺度与坐标

作者格子使用逻辑XY，Grid采用XZY swizzle映射到世界XZ地面；本场Grid单格为1单位，地表父缩放使世界X/Z格距为4米。Tilemap采用XZ方向。不要把一套新的XY Sprite直接立在地面上，也不要通过单独旋转每格去补偿错误坐标配置。

在128像素、PPU99和当前父缩放下，mask完整矩形的世界跨度约为5.1717米，而逻辑格距是4米。边缘需要保留越格伸出与重叠关系。若想改变这种关系，应作为整体尺度调整处理，不能仅为“对齐四米”随意改PPU。

底纹的世界重复周期当前为16米候选，可以逐层配置。以1024像素基础级计算，相当于约64像素/米，一格4米覆盖约256像素的底纹跨度；这是当前自有采样的标定关系，不是原作Shader公式的结论。不要为每个128像素mask另外裁出一张小底纹。

规则旋转用于边缘形状；当前底纹按世界XZ连续取样，不随每个mask的规则旋转而整体旋转。若原创道路必须有严格方向纹理，例如沿路向连续的木板，需要另定方向/UV方案，当前实现不会自动完成。

## 颜色、alpha与图集边距

底纹按颜色数据使用sRGB；mask按线性alpha数据使用。当前底纹只采RGB，底纹文件本身透明不会自动在地面挖洞。mask必须把轮廓写入alpha：只在不透明图片的RGB上画黑白，不能得到预期的透明边缘。

当前自有Shader为Unlit、alpha裁切，Cutoff通常约0.5。它不是半透明混合，也没有完整Lit、法线、粗糙度或高度响应。材质和Tilemap颜色建议先保持白色核对原色，再做显式调色。Cutoff在材质Inspector中调整；GroundLayer和刷地来源区目前没有单独的Cutoff配置字段。

mask图集使用Clamp、Bilinear、关闭Mip；底纹使用Repeat、Bilinear，并按配置决定Mip。PNG只提供基础级图像，Unity生成的Mip不是原压缩纹理Mip的逐字复制。

原创打包建议相邻切片保留至少4像素安全间隙，并为每片向外扩展约2像素边缘RGBA；图集外围同样留边。扩展区不计入128×128逻辑切片，不要让邻片颜色或alpha混进切片边缘。此数值是本轮无Mip图集的起点建议；若改变过滤、缩小分辨率、启用Mip或重新打包，需要重新检查远景渗色与细边消失，不能把固定padding当成所有条件下的保证。

## GroundLayer中的接线槽

| 字段或关联对象 | 当前职责 | 替换时要同步的内容 |
|---|---|---|
| `displayName` | 作者工具和运行观察面板的层名称 | 改成原创层的用途名称 |
| `tilemap` | 实际保存作者格的Tilemap | 保持属于当前Surface及同一Grid，不接到其他地图层 |
| `paintTile` | 后续绘制写入的TileBase/RuleTile | 绑定自有Tile；已有格子的旧Tile引用不会因此自动迁移 |
| `eraseReplacement` | 擦除时写回的Tile；空表示清除此层 | 基础层写回自有基础Tile，覆盖层通常为空；按层明确选择 |
| `preview` | 边缘/作者资料预览 | 换成自有Sprite；实际点选结果仍以格子的真实Sprite为准 |
| `detailTexture` | 来源、缩略图和资源查看 | 换成自有底纹，同时同步实际材质纹理；单改此字段不足以更换渲染 |
| `worldRepeatPeriod` | 自有世界底纹重复周期 | 通过工具或Inspector调整，并刷新显示；当前初始候选16m |
| `sourceId/sourceContainer/sourceObjectId/evidence` | 来源追溯说明 | 填自己的资源族、资产标识与用途，不冒用参考资源身份 |
| TilemapRenderer的材质 | 真正绑定底纹、裁切与覆盖参数 | 绑定自有材质，在材质中设置底纹、Cutoff及其他自有显示参数 |

基础覆盖层当前有独立的满覆盖设置，确保研究范围内有连续地面；上层用mask形成草/路边。这与世界范围裁剪均属于本工程适配。替换时要保留这一职责，或明确设计新的覆盖策略，不能只换一张有透明洞的基础Sprite便假定地面仍完整。

## 现在可以怎样替换

1. 在Edit模式准备自有底纹与mask图集，设置Sprite Multiple切片、PPU、pivot、颜色空间和采样。先在小范围核对实心、孤立、直边、凸角、凹角及各方向组合。
2. 创建并核对自有Tile/RuleTile与材质；材质必须位于上述LocalGenerated白名单且使用本轮自有Shader。当前mask由Sprite alpha提供，底纹由材质提供；绘制Tile的碰撞类型按本场地面用途保持None，连续地面碰撞仍由场景另行配置。
3. 选择研究场的GroundResearchSurface，在Inspector的layers中绑定自有Tile、擦除替代、预览和来源字段；再在对应TilemapRenderer上绑定上述白名单内的自有材质，核对材质底纹与GroundLayer.detailTexture一致。
4. 明确处理已刷格：已有格存的是实际Tile资产引用。只换paintTile会改变后续落笔，不能自动替换旧格；需要显式重刷或另做受控的Tile引用迁移。不要用“重建显示缓存”冒充作者数据迁移。
5. 打开 **Tools → OSSASTRA → 地表研究 → 刷地与来源**。来源区目前可以实际修改“候选世界周期”，并记录Undo；该区的Tile/纹理/Sprite对象框是查看和定位用途，尚未实现拖入即换材的写回。
6. 使用“重建显示缓存（不改手绘）”更新邻接显示、边界与周期。当前这个入口不会为任意detailTexture自动新建材质，也不会自动把它写入材质底纹槽。核对后保存场景，重开确认引用和布局。

“重置为本轮示范布局”会替换当前作者格，不是资源替换工具；它与刷新显示不同。需要保留手绘时，不要用示范重置代替迁移。

## 尚未形成的正式资源管线

现有“导入已提取白名单”入口服务于本轮研究manifest，受7套底纹、15个Sprite和14条规则等来源检查约束，按已知记录生成本机配置和材质。它不是面向任意原创素材包的通用导入器。重新导入参考白名单，也不等于完成原创资产换肤。

当前没有统一资源族SO、七层批量替换向导、任意图集自动排版/语义识别、旧格引用自动迁移或完整原创资源包校验。GroundLayer提供了可接线的入口，但正式制作仍需上述显式配置；后续可以围绕实际原创资源族补足管线，而不是现在宣称这些能力已全部存在。

## 替换后的最小检查

- 先看实心、孤立、直边、凹凸转角与相邻异种地表；检查alpha、排序和底层覆盖，不只看一块单独Sprite。
- 旋转地图并改变缩放，确认边缘无邻片渗色、尺度不跳、底纹连续；16m仅为起点，可以按原创纹样调整。
- 逐层点选实际格，核对Tile、规则结果Sprite、材质底纹、预览与来源字段均已换成对应原创资产。
- 做一次绘制、擦除、撤销/重做和保存重开，确认已有格与后续落笔都使用预期资源，范围仍为3072m²。
- 对照纯地面与带角色/敌人的画面和资源数量。共用一个mask图集有助于避免额外纹理切换，但不同层材质仍可能分批；不以“同图集”直接承诺固定Draw Call。

美术替换不自动增加地形高度、逐格碰撞、寻路或地表玩法语义。若这些成为实际需求，应另定义数据与接线，而不是从草地颜色、透明度或贴图文件名推断行为。
