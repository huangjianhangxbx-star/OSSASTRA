# KT-GROUND-01 地表刷地操作

本页说明本轮独立研究场的编辑入口。作者数据只有场景中的原生 Tilemap；没有第二份格子表。拖刷、擦除、矩形填充、撤销重做、取消、失焦及保存重开的原生事件回归已实际通过。

## 打开与选材

1. 在 **Edit 模式**打开 `Assets/OSSASTRA/Scenes/Research/SC_FrontierGroundLab.unity`。
2. 在 Hierarchy 选择 `GroundRoot_开拓物语地表研究`，打开菜单 **Tools → OSSASTRA → 地表研究 → 刷地与来源**。
3. 检查窗口的“本轮地表”引用。整图应显示 **64 × 48 米、3072 平方米、16 × 12 作者格**；16 × 16 米的小样尚未扩图。
4. 在窗口点击中文图层，按色纹缩略图选择用途，再点击绘制工具。每次只编辑所选层。

| 中文图层 | 本轮用途 |
| --- | --- |
| 浅黄碎叶草地 | 连续基础底层；擦除恢复该基础 Tile |
| 明亮草地 | 草地覆盖层 |
| 白花草地 | 花草覆盖层 |
| 青蓝草地 | 草地覆盖层 |
| 深蓝草地 | 草地覆盖层 |
| 深青草地 | 草地覆盖层 |
| 浅石道路 | 道路覆盖层 |

这些中文名是本轮选择入口；边缘形状交给原生 RuleTile 根据相邻格刷新。相同白色边缘遮罩不意味着七层是同一种底纹。

## 绘制与撤销

| 按钮或操作 | 用法 |
| --- | --- |
| 拖刷 | 在 **Scene 视窗**按住左键拖动；“画笔边长”设为 1～8 格。原生 Palette 负责拖动补点 |
| 擦除 / 恢复基础 | 在 Scene 左键拖动。覆盖层清除，基础层恢复基础 Tile；不改其他层 |
| 矩形填充 | Scene 左键按下、拖出矩形、松开填入所选层；不等于全图重置 |
| Ctrl+Z / Ctrl+Shift+Z | 撤销 / 重做；正常独占笔画对应一次撤销 |
| Esc | 取消仍在进行的笔画；已经松手提交的笔画用 Ctrl+Z 撤销 |
| 离开 Scene / 失去窗口焦点 | 按约定提交已画部分，再用 Ctrl+Z 撤销；不继续后台刷地 |
| Alt / 中键 / 右键 | 让给 Scene 原有导航，不绘制地面 |

工具会打开 Unity 原生 **Tile Palette**，不需要另建调色板资产。若在 Palette 里另选了别的画笔，回到本窗口重新点“拖刷”等按钮。当前工具仅写显式登记的本轮图层和编辑范围；Play、Prefab 编辑阶段、旧样地或错误目标不能落笔。

**已修复并实跑：** 连续矩形会分别提交；框选 Esc 会取消本框；失焦后释放本工具的鼠标控制，没有新的按下事件不会继续刷地。旧的矩形事务和焦点缺陷已完成定向回归。

**罕见 Undo 冲突的实际策略：** 如果别的 Editor 操作在本笔进行期间创建了新的 Undo 组，本笔安全结束并保留已经绘制的内容，给出明确警告；此时 Esc 不跨历史组回滚，也不把其他操作合并进刷地撤销。正常独占笔画仍按 Esc 取消整笔。外部 Undo 组的保护已用独立哨兵和原生事件实际验证。

## 保存、刷新与重置

- **保存作者数据和场景**：提交当前笔画、恢复本窗口的观察状态，然后保存该研究场景。重开时应读取同一批 Tilemap 作者格；不保存或改写原双角色源场。
- **重建显示缓存（不改手绘）**：刷新 RuleTile 邻接和候选显示参数，保留手绘格子。显示异常时先用此项。
- **重置为本轮示范布局…**：弹窗确认后，替换七层作者格为示范布局。它会覆盖手绘，可用一次 Ctrl+Z 撤销；与刷新显示分开。

“候选世界周期（米）”可在来源区逐层调整，最小 **0.1 米**，初始 **16 米**。这是本轮自有显示方案的纹理重复周期，**不是已经还原的原作 Shader 参数**。数值改动记录 Undo，并更新显示；配合场景保存使用。

保存验证实际经历了同一个研究场景的两次关闭、重新打开；手绘格、规则选出的 Sprite 和“重建显示”后的内容均保留。跨块验证临时使用较小的原生渲染块，确认同一笔画跨块后仍能保存；最终渲染块配置已恢复。

## 查看实际组成

- **点选来源（吸管）**：在 Scene 点击所选层的格子。窗口显示实际 Tilemap、Tile、规则选出的 Sprite、图集区域、PPU 和本机来源字段。
- **Scene显示 / 只看所选组成**：只切换 Editor 观察可见性，不修改作者格或 Game View。隔离层时看见空白，不表示其他层被删除。
- **Scene线框**：使用 Scene 原有线框观察；**恢复查看状态**或关闭本窗口会恢复它持有的观察状态。

底纹、边缘遮罩和来源资料仅保存在本机；公开代码与本操作说明不包含原图集、原始游戏规则表或素材文件。

## 验证边界

以上验证通过公开 SceneView 事件进入原生 Palette，并读取实际 Tilemap、Sprite、Undo 和重新加载后的作者数据。它覆盖操作逻辑，没有代替物理鼠标和 Toolbar 按钮的人工命中检查；完整人工交互仍需在编辑器中确认。回归记录包含重复坐标校准，其检查计数不代表同等数量的独立功能。
