# KT-GROUND-01：源事实与 Unity 适配

本轮保留“原生 Tilemap 作者数据＋规则 Sprite 边缘＋材质底纹”的组织方式，在独立研究场中适配现有角色和地图观察体系。目标是验证可刷改、可追溯、可替换的地表基础，而不是宣称原作画面与程序已完整移植。

源证据和数值的范围见 [原作地表组成研究](source-findings.md)。以下把直接继承的事实、主动选择的适配与仍未知的内容分开。

## 对应表

| 内容 | 原作直接证据 | 本工程处理与界限 |
|---|---|---|
| 作者数据 | 选定 Starter 为原生 Grid＋七层 Tilemap/TilemapRenderer | 继续用原生 Tilemap；刷地直接修改同一份作者数据，不另建一套运行时格子真相 |
| 邻接 | 14 条有序规则＋默认结果；15 个 Sprite；7959 个保存格结果/矩阵回读一致 | 从本机白名单配置原生 RuleTile；原规则数据只留本机，不随公开代码发布 |
| 边缘图集 | 同一1024×512图集，15个128²切片、PPU99、居中pivot，无旋转打包 | 原图集 Sprite Multiple 导入，保持同纹理；不为每种边缘创建独立纹理或逐格独立 Quad |
| 尺度 | 逻辑格距4，Sprite矩形跨度约5.1717 | 保留二者差别，允许边缘伸出；不以放大纹理或角色凑出三倍面积 |
| 草/路外观 | 七张对应底纹，有颜色、叶片、石粒和部分小花 | 解码基准层不重画；底纹/遮罩导入和采样分工由本工程显式配置 |
| 几何细节 | 源Sprite携带自己的渲染数据；原作运行时Tilemap完整网格未捕获 | 当前导入使用 Full Rect Sprite＋原alpha形状；不声称原紧密网格或GPU批次逐项复原 |
| 纹理周期 | 读到源材质缩放参数16，精确算式未知 | 使用自有 world-XZ 底纹采样，周期16m为标定候选，属于 UNITY_ADAPTATION |
| 光照 | 源编译Shader有Lit/Ramp相关绑定 | 自有Unlit适配便于先核对形状与底纹；不等效还原原作光照、阴影和所有材质响应 |
| 底层/范围 | 本轮没有恢复原作对地图边界、空地与所有层覆盖的完整策略 | 满覆盖底层＋世界边界裁剪，保证本工程研究范围内有地面、范围外不伸出；属于 UNITY_ADAPTATION |
| 地图布局 | 源Starter保存有自己的地表布局 | 64×48候选整图是本工程示范布局，不复刻原逐格坐标，不冒充营销截图同图 |
| 作者工具 | 可确认Tilemap/RuleTile数据；原作者笔刷窗口未知 | 本工程自有Scene View工具负责刷、擦、来源检查与Undo；不声称恢复原作编辑器 |

## 数据和代码的分工

[GroundLayer](../../../Assets/OSSASTRA/Scripts/GroundResearch/Runtime/GroundLayer.cs) 关联单层 Tilemap、绘制 Tile、擦除替代、来源字段和底纹预览。[GroundResearchSurface](../../../Assets/OSSASTRA/Scripts/GroundResearch/Runtime/GroundResearchSurface.cs) 声明受控图层与逻辑编辑范围，并通过 Grid 世界角点计算实际 XZ 占地；来源检查、刷子与运行时查看使用同一份图层数据。

规则负责决定局部边缘形状与旋转，底纹负责地面内部的连续细节。自有采样从世界 XZ 取底纹，使邻接规则旋转时不需要把整片草叶/石粒一同旋转。这个职责拆分是本轮适配的实现选择，不能反推源 Shader 必然使用同一公式。

进口与组场由本工程 Editor 代码完成。第三方纹理、图集、规则配置、来源manifest和依赖它们生成的本机材质，仍按本机内容管理；不能因为Importer代码是自有的，就把它的全部输出视为可公开素材。

## 面积、覆盖和裁剪

三倍面积候选为 **64×48＝3072m²**，对照此前32×32样地的1024m²。比例必须以两场真实地面范围和 Grid 变换读回核对，不能只看场景名、格子数量或截图尺寸。本模块的世界面积计算不把Sprite越格伸出的矩形当成额外有效占地。

原边缘矩形比逻辑格大，直接填到最后一行会自然伸出作者边界。本工程选择让自有 Shader 按地表世界边界裁剪，并以满覆盖底层填满研究范围；上层继续通过alpha显示不规则草/路边。这是为本场完整地面和明确范围作出的适配，不是源资源中已证明存在的同一做法。

64×48示范布置、层间高度偏移和本场碰撞边界同样是本工程场景参数。渲染裁剪只控制画面，不能代替碰撞或寻路；实际场景的连续碰撞必须另行核对。现有范围采用水平XZ地面，不能将当前边界处理扩称为任意倾斜地表或任意旋转多边形裁剪。

## 纹理、色彩和批次

七张底纹保留各自像素尺寸，使用重复采样；边缘图集使用Clamp。源素材的基础像素、原Mip数量和采样设置留有本机记录。PNG不携带原压缩纹理的完整Mip链，因此Unity重新生成的Mip属于适配，不能写成逐字恢复原生Mip。

颜色底纹按sRGB、alpha遮罩按线性数据导入是本轮明确配置。源序列化颜色空间枚举被原样保留，但没有把未进一步核实的枚举含义作为等效色彩管线的证明。当前Unlit画面也不能认证原作完整光照下的颜色。

原Atlas切片与独立解码Sprite的RGBA像素已逐一等价核验。使用同一纹理与原生Tilemap Chunk可以避免人为拆成大量纹理/Renderer；这不是“零成本”或固定Draw Call承诺。七层仍有不同底纹和材质，实际批次、CPU/GPU时间和资源数量应在固定相机、分辨率及画质下测量。

## 研究观察与角色边界

[GroundResearchView](../../../Assets/OSSASTRA/Scripts/GroundResearch/Runtime/GroundResearchView.cs) 是独立场的小型折叠诊断面板，读取同一份图层与来源字段。图层隔离只改变受控TilemapRenderer的显隐，遮罩查看通过PropertyBlock临时覆盖；它不实例化材质、不改共享材质或Tilemap作者数据。其关闭/销毁恢复原值的验收应以独立生命周期测试结果为准。

默认观察通过现有敌人攻击许可入口关闭本场攻击，显式开关才允许攻击；这不会把F6变成游戏暂停。面板借用现有角色输入的指针区域，避免点击面板同时攻击，不添加一套硬编码快捷键。

原角色、敌人、输入、战斗和动画逻辑继续从既有链承接；地表模块不接管这些职责。新场的装配、实际试玩、旧场冒烟、编辑保存重开和性能范围由本轮验证报告记录，不从资源导入成功直接推导为全部通过。
