# SV-DIVE-01 横版俯冲候选

## 在正式横版场试玩

打开 `SC_SideViewAdventure`，进入编辑器 Play，已挂载的芙蕾茜娅预览会自动开启。若当前操控猎人，用 **Z** 切到芙蕾茜娅。出生点左侧有原动作练习木桩。按 **J** 起跳，将鼠标指向下方目标，按住 **S** 再按一次鼠标左键。鼠标在角色正下方时直落，放到左下或右下时取实际角度。命中敌人后自动腾起。第二次下击需要新的主手按下。

角色对象的 `SideViewDiveMount` 保存能力引用，初始只登记到芙蕾茜娅。清空引用、禁用组件或 **OSSASTRA → 横版 → 俯冲候选 → 开关芙蕾茜娅预览** 均可撤销该来源。菜单开关只作用于当前 Play。手柄保留可配置的主手和左摇杆组合，当前 J 跳跃仍只有键盘绑定。

新环境可在保存后的正式横版场用 **OSSASTRA → 横版 → 俯冲候选 → 装配芙蕾茜娅预览** 重建本机配置。三个候选数据资产位于 `Assets/OSSASTRA/SideView/Action`。Executor 可调角域、准备时间、下冲速度、加速度、攻击球、腾起的横速保留和收招。当前样本为向下分量 ≥0.15，准备 0.08 秒，初速 12 m/s，加速度 14 m/s²，攻击球高度 0.42 m、半径 0.44 m，首步保留横速 20%，空中交接 0.10 秒，落地收招 0.15 秒。

## 接入与范围

- 正式 InputAction 在普通攻击缓冲前认领同来源下击组合。键鼠通过当前游戏相机投影到角色 XY 平面，手柄使用同设备已配置的模拟向量。成功接受后以连续向量冻结。
- 本体能力复用现有来源、动作事务和 `AbilityRun`。固定步通过现有 `CharacterController` 驱动。攻击沿真实路径扫掠，使用现有接触网关、伤害去重和表现事实。空中下冲持续到首次有效命中或实际落地；撞到侧墙仍继续下落。首次有效命中后停止伤害扫掠并自动腾起一次，腾起从接触时的位置沿用角色完整普通跳跃的上升过程，无需按住 J；实际顶棚照常阻挡。
- 本机新版架势动作接口尚未落地。编辑器候选为无费用预览，进入正式横版场 Play 自动开启。正式动作自费、旧体力条迁移和 Spine 恢复资格事件仍待统一资源链路。动画暂用现有动作映射。
- 原作参考研究保留在研究目录 `研究/SV-DIVE-01`。本机版本静态核对与旧公开视频逐帧观察分开记录。原作 Hunter 采用固定斜向，连续角度是本项目设计。
