# ENV-01 实现与验证交付

日期：2026-11-04。A、B、C、D技术闭环完成；本轮源代码与文档由Root按精确白名单发布。入口见 [操作与架构说明.md](操作与架构说明.md)。

## 当前可体验内容

仍使用唯一主场 `SC_RoomVisibilityLab`，35°、distance25、FOV35。进入运行，展开右上“环境模拟”，点击“去光影样板”即可观察立柱、台阶、真实窗墙、雨棚、三种材质球和风叶；“到房屋门外”回原入口。

太阳方位/高度/强度/色温、阴影、天空与底光、反射、云/风/雾/雨/湿润都可调。晴、多云、阴、薄雾、小雨五档与温和晴朗、湿润多云、冷色干燥三气候可手动比较。自动天气使用独立固定种子，不动游戏随机数。

交付默认正午12时、手动时间、6分钟一昼夜；自动推进和自动天气均关闭。停止环境时钟不暂停世界，没有新增环境循环音。观察区原点 `(24,0,-9)`，17个Renderer、4个登记结构遮挡盒、14个物理Collider；风仅作用于3个自有无碰撞叶组。

## 架构与本轮修正

单一EnvironmentRoot发布不可变Frame。灯光、合法天空、材质、WorldLook和雨分别消费；原房间/窗洞权威、Caster、碰撞、业务与材质身份保持。天气绘制接现有正向世界Pass，不另加第二套管线/模拟器。

- 真实URP主灯投影接入原地表与装饰，不用最终全屏变暗冒充阴影。Lit保留原生BRDF/附加灯/GI，云只减主灯直射。
- Full表面进入环境适配时保留原整件许可；信息与角色语义先于祖先预警组件，装备显式角色2，耐久条仍为信息。
- Trilight不能靠ambientIntensity倍率控制，本轮在三色的线性光强上缩放，避免原生Lit“滑条变了但没效果”。依据 [Unity官方ambientIntensity说明](https://docs.unity.com/en-us/engine/7000.0/script-reference/unityengine/rendersettings/ambientintensity)，并以本机Native合同实测。
- 日照对照清除底光、方向补光与天空反射；底光对照清除日/月直射及方向补光，原室内局部点灯保留。
- 夜间只衰减日间正对比度，修复有效夜光被旧调色压黑；不重复增加夜曝光，不改旧Profile。
- 雨使用当前相机刚完成的合法深度，按真实MSAA绑定解析；粒子和其投影下方表面都须获当前许可，室内/雨棚/远深度/未知区拒绝。
- 湿润室外地面与装饰最多压暗8%；原生表面平滑度最多增加0.05。室内、雨棚下、角色、信息与alpha保持。
- 自动天气最短1秒，单步最多64次切换；无效配置/超预算保留最后有效快照并报告状态，避免编辑参数卡死。
