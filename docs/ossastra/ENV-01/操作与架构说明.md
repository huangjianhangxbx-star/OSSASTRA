# ENV-01：主场环境模拟

当前机位保持35°。使用原 `SC_RoomVisibilityLab`，环境观察区位于世界坐标 `(24,0,-9)`；不新增验证场景文件。

## 直接体验

1. 进入主场运行，展开右上角“环境模拟”。展开时暂收起重叠的旧诊断窗，折叠后归还旧状态。
2. 点击“去光影样板”，观察立柱、阶梯、窗墙、雨棚、三种材质样球及三组风叶。点击“到房屋门外”回到原房屋入口；也可照常走路。
3. 用时刻、日出/正午/日落/深夜和太阳方位/高度对照光影。自动推进只控制环境演示，默认6分钟一昼夜，游戏继续运行。
4. 切换晴、多云、阴、薄雾、小雨；调整过渡时间、云/风/雾/雨/湿润。自动天气默认关闭，开启后按气候权重及固定种子调度。
5. 使用原场、日照、底光、云影与完整效果对照；“复原演示基线”回正午和初始天气，手动覆盖可单独清除。

天空预览可在面板内查看完整方向；不会改变玩法镜头，也没有第二套模拟时钟。保存预设仅通过 Editor 入口生成独立副本，不改旧冻结档。

## 配置位置

| 入口 | 职责 |
| --- | --- |
| EnvironmentSimulationRoot / EnvironmentRoot | 时刻来源、昼夜档、天气/气候、演示速度、受光响应及运行态覆盖 |
| EnvironmentLightingBinding | 原太阳、阅读补光及环境底光的借用/恢复；原室内两点灯保留 |
| EnvironmentSkyBinding | 天空、反射、预览、明确房间/局部灯/遮雨体、雨量显示预算 |
| EnvironmentSimulationPanel | 只调用正式环境接口，借用自己的输入捕获与旧诊断显示，不定义新按键 |
| EnvironmentObservationRoot | 可整体关闭的17个自有 Renderer、4个登记的结构遮挡盒（物理Collider共14个）；原碰撞保持 |
| Assets/OSSASTRA/Environment/Profiles | 自有昼夜档、5天气档与3气候档；温湿度仅输出环境参数 |
| EnvironmentMaterialResponse | 无光照材质的地面/装饰/人物响应、接影及最低亮度；NativeLit保留原生受光 |

风仅驱动同一快照的云/雨和自有无碰撞风叶，不争写旧植物 billboard。天气持续时间至少1秒，单步调度最多64次；无效输入保持上一有效环境并报告状态。

## 权威与显示链

`时间输入 + 昼夜/天气/气候档 → EnvironmentRoot → 不可变 EnvironmentFrame → 灯光 / 天空 / 材质 / WorldLook / 天气`

- 环境根只推进演示，不建立游戏日历、暂停世界、改变AI/经济/作物或启用环境音。
- 原房间和窗洞系统仍是唯一可视权威。原 Full 表面经过受光适配时保留 Full 许可，不能变成新的 Partial 权限。
- 太阳投影来自真实 URP 主灯阴影。揭顶/前墙的颜色隐藏保留原 Caster、实体和业务；室内区域底光是明确近似策略，不冒充实时GI。
- 原生Lit保留BRDF、附加灯和GI，云仅调主灯直射；原无光照家族保留原alpha、PMA、图集和统一平面深度。人物与信息不接受环境后处理。
- 三色底光按线性光强缩放；日照对照排除天空反射，切回完整效果恢复配置的反射强度。室外湿润只温和压暗地面/装饰，原生材质最多增加0.05平滑度，室内、雨棚、角色和信息排除。
- 夜适应只衰减原正对比度，避免日间调色压掉物理夜光；曝光、色温及负对比度不重复处理，旧Profile不改。
- 天空在合法世界清黑后绘制，背景射线须通过明确建筑/结构/窗洞许可。黑色像素、远深度均不是天空许可。
- 天气直接接在现有正向世界Pass之后，复用该相机刚完成的合法深度。无需另挂会被清黑覆盖的早期天空Pass，也不读取旧CameraDepthTexture。
- 雨粒必须获当前许可、避开室内/雨棚，并按下方合法表面再次拒绝室内投影、历史/未知区与远深度。原HUD不参与。

## 反射与效果边界

反射为32像素/面、只含天空渐变与平均云色的近似Cube，不抓全场未知内容；它不是逐方向太阳盘/空间云的精确副本。变化阈值与至少1秒更新间隔限制重建。

室内观察者不叠室外全屏天气雾，窗外暂沿用原室内空气处理。雨仅叠在当前合法表面，不为远天空背景单独授权雨丝。体积云、体积光、真实天文、全球季节及生存系统属于后续扩展。

## 交接与复现

增量装配使用 `EnvironmentMainSceneSetup.Apply`；重复执行复用完整自有配置，拒绝覆盖半成品或错误引用。配置/场景/网格/材质通过 Native Unity API 生成，源代码和合同见 `Candidates/ENV-01`。

实际对照、连续昼夜/天气录像及Native回执保存在项目外 `研究/环境模拟/ENV-01`。完整结果见 [实现与验证交付.md](实现与验证交付.md)。主场已保存重开，原 `kt-vis06-natural-01` 路由已恢复；测试仅使用独立ENV档。
