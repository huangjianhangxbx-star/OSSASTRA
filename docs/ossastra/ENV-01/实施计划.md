# ENV-01 天空光照与昼夜天气模拟器 Implementation Plan

> **For agentic workers:** 在同一任务中按下列可独立验收项连续实施；优先互斥子代理处理纯计算/Shader审查，Root保持唯一Unity/Git writer。每项先跑有意义的失败用例，再实现并记录结果。

**Goal:** 在当前35°唯一主场中形成可调天空、真实光影、昼夜和天气气候的完整观察闭环。

**Architecture:** 一个EnvironmentRoot解析时间、昼夜和天气气候档，发布不可变快照；灯光、天空、材质响应、既有WorldLook及天气显示分别消费。原房间/窗洞系统仍是唯一可视权威，天空和雨雾通过明确许可绘制。

**Tech Stack:** 本机团结2022.3、URP14.2.0-t1、现有Spine、uGUI、新Input System、Funplay Native Editor API；不换管线、不新增收费插件。

**Spec:** [设计方案.md](设计方案.md)。本轮A/B/C/D已完成；实际证据与范围见 [实现与验证交付.md](实现与验证交付.md)。

## Global Constraints

- 当前主场`Assets/OSSASTRA/GroundWorkshop/Samples/KT-VIS-04/SC_RoomVisibilityLab.unity`同场增量，35°、两原角色单敌人、原交互与存档保持。
- 新生产源码只在`Assets/OSSASTRA/Scripts/`；禁止读取/递归扫描`Assets/Script/`与`Assets/Scripts/`。中文职责头、命名、接口与生命周期遵守现有规则。
- 唯一Unity/Git writer；场景/材质/资产只经Unity API。旧Profile/控制器/媒体只读复用，新配置放自有目录，不修改冻结源档。
- 天气不授予或撤销可见权；不关闭屋顶/墙体的实体遮光，不恢复未知动态对象的投影；不读取旧未裁世界深度。
- 角色、装备受光与环境后处理排除分开；PMA/alpha/图集/平面深度及原sharedMaterials身份保持。
- 预览时钟不作为游戏日历；停止其推进不暂停游戏。环境音默认关闭。
- 不以每帧GI/全场反射抓取完成天空更新。反射不能包含未许可内容。

## 本轮结构和接口

新目录`Assets/OSSASTRA/Scripts/EnvironmentSimulation/`，配置资产`Assets/OSSASTRA/Environment/Profiles/`，同场样板根`EnvironmentObservationRoot`。候选与证据只在`Candidates/ENV-01/`及项目外研究目录，不新增临时验证场。

| 文件/模块 | 职责与接口 |
|---|---|
| Core/EnvironmentClock.cs | `WrapHours(double hours)`；`AdvanceHours(double hours,double deltaSeconds,double cycleSeconds)`，结果在[0,24) |
| Core/SunPath.cs | `Sample(double hours,float maximumElevation,float azimuthOffset)`返回SunPose；方位0为世界+Z，90为+X；06/12/18时对应东/南/西，正午为最大高度 |
| Core/SunPose.cs | 只读`ElevationDegrees`、`AzimuthDegrees`与归一化`DirectionToSun`；方向指向太阳，DirectionalLight照射方向取其反向 |
| Runtime/IEnvironmentTimeSource.cs | `bool TryReadHours(out double hours)`；外部时间源无效时冻结最后有效时刻并报告状态，不静默启动另一套时钟 |
| Core/WeatherBlend.cs | `Progress(double elapsed,double duration)`；中断天气转换时从当前结果重新起算，不能跳回旧起点 |
| Runtime/EnvironmentFrame.cs | 时刻、太阳姿态/颜色/强度、环境底光、天空/云、风、雾、降雨、湿润的不可变数值快照及revision |
| Runtime/DayCycleProfileSO.cs | 日内曲线/渐变、太阳路径、夜间阅读底值；不直接写场景 |
| Runtime/WeatherProfileSO.cs | 五种天气目标及过渡参数；只保存配置 |
| Runtime/ClimateProfileSO.cs | 三个气候基线、天气权重、持续时间和固定种子策略；不接生存/作物 |
| Runtime/EnvironmentRoot.cs | `SetTimeHours(double hours)`、`SetClockRunning(bool running)`、`SetManualSun(bool enabled,float azimuthDegrees,float elevationDegrees)`、`TransitionWeather(WeatherProfileSO target,float durationSeconds)`、`ResetPreview()`，`Current`只读 |
| Runtime/EnvironmentLightingBinding.cs | 明确引用太阳、原阅读补光和环境设置；只写自己的借用范围，恢复原状态 |
| Runtime/EnvironmentMaterialResponse.cs | 明确材质角色与受光/接影/夜间可读度参数；不复制人物业务 |
| Rendering/EnvironmentSky.shader、EnvironmentLighting.hlsl、EnvironmentRain.shader | 自有天空、云场、有限受光与程序化雨；语义来自旧T7B，不依赖旧Controller.Apply |
| Rendering/EnvironmentSkyBinding.cs | `AppendSkyCommands(CommandBuffer cmd,Camera camera,RoomMaskFrame visibility,EnvironmentFrame environment)`，在原PositivePass清黑后、合法世界绘制前由其显式调用；不另挂一个会再次被清黑擦掉的早期天空Pass |
| 现有RoomPositivePass显式接缝 | 实施时复用已有相机Pass完成天空/雨，不新增EnvironmentRendererFeature；保留原正向世界与WorldLook |
| Development/Environment/EnvironmentSimulationPanel.cs | 统一可折叠调节面板，调用Root正式接口；不自行推进模拟、不硬读设备键 |
| EnvironmentSimulation/Editor/EnvironmentMainSceneSetup.cs | 对已核实当前主场做增量装配、配置副本、观察区与原状快照；重复执行不得重复创建 |

既有接缝：`WorldLookController/Settings`读取动态环境快照且保留原静态档回退；`RoomMaskFrame/RoomPositivePass`给出天空/天气所需的当前许可与合法深度；地表/装饰/Spine适配Shader加入各自受光逻辑。若执行中必须新增文件，先在任务记录明确职责，不在未知位置藏入全局驱动。

## 里程碑A：真实光影基础与同场样板

目标：即使关闭所有环境后处理，也能在当前地面上看见跟随太阳角度变化的真实阴影。

- [x] Native保存授权主场的外部安全副本，记录场内灯/RenderSettings/材质引用/相机/原dirty与源档SHA；只占用自有主场配置及必要源码接缝。
- [x] 新建独立时刻与太阳纯计算测试；以下断言先失败，再实现Core三个文件。拒绝NaN、Infinity及无效周期，不静默传进Shader。

```csharp
Assert.That(EnvironmentClock.WrapHours(-1), Is.EqualTo(23));
Assert.That(EnvironmentClock.AdvanceHours(23.9, 6, 360), Is.EqualTo(.3).Within(1e-6));
Assert.That(SunPath.Sample(6, 60, 0).ElevationDegrees, Is.EqualTo(0).Within(.001));
Assert.That(SunPath.Sample(12, 60, 0).ElevationDegrees, Is.EqualTo(60).Within(.001));
Assert.That(SunPath.Sample(18, 60, 0).AzimuthDegrees, Is.EqualTo(270).Within(.001));
Assert.That(WeatherBlend.Progress(2.5, 5), Is.EqualTo(.5).Within(1e-6));
Assert.That(WeatherBlend.Progress(1, 0), Is.EqualTo(1));
```

- [x] 明确绑定当前DiagnosticLight为太阳，开启其软影并核对URP支持；原0.65阅读补光进入可调辅助项，不能夜间残留白昼强度。原室内点灯独立保留。
- [x] 创建同场观察区：受光地面、三种高度柱、台阶、墙/真实窗洞、遮棚、哑光/粗糙/金属样球。使用自有材质副本，标明结构Caster资格与角色通行净空，不改变旧掉落、碰撞或敌人。
- [x] 先用实际GPU对照证明现有地面缺少接影，再给ThinTop/WorldTile/Decoration家族增加可配置日照、底光与主影接收。薄地表仍按原统一平面深度计算照明位置；不能简单改变ZWrite或抬高地面躲问题。
- [x] 太阳四方位与12°/45°/75°下，比较柱影方向和长度、阴影边缘抖动；固定35°相机、关闭WorldLook仍成立才通过。

完成报告：样板位置、实际受光家族清单、独立日照前后画面、Caster白名单、主场与源文件保护结果。不能以“灯的旋转数值变了”结束A。

## 里程碑B：天空、昼夜与人物/室内一致性

- [x] 创建DayCycleProfile与EnvironmentRoot，手动/预览/外部时间端口互斥；默认每6分钟一个演示昼夜，时刻0与24连续。每秒一次与每帧推进的终态应一致。
- [x] 从T7B天空语义建立自有Sky材质，太阳盘方向与同一SunPose一致；增加温和夜空/月亮标识及云场。天空球是独立背景角色，不进入普通PositiveSurfaces。
- [x] 先建立天空隔离失败用例：普通Skybox被清掉、全黑像素填天空会污染未知室内。修正后在正向清黑之后、合法世界之前受明确天空许可绘制。
- [x] 天空许可的保守初始算法：室外背景射线不得先穿过登记建筑/实体阻挡；室内只能消费当前房间合法外开口的相机方向域，射线须穿过真实洞口并排除后方建筑/实体。没有天空许可时仍黑，不能从远平面或黑色反推许可。
- [x] 同一快照驱动太阳颜色/强度、天空、环境底光、反射及WorldLook空气参数；只改参数，不触发全局管线替换。反射默认天空源，变化阈值与更新间隔由Profile控制，初值间隔至少1秒；拖动时可降采样，松开后补最终状态。
- [x] 按实际材质家族补人物/装备环境响应：Lit身体保持原受光；Unlit装备采用风格化亮度/色温响应。完整保留PMA、透明边缘、五面切换、原材质身份及后处理保护。
- [x] 室内底光单独配置，明确它是区域化环境响应而非真实GI。太阳经窗洞照入；揭顶/前墙隐藏保留原ShadowsOnly Caster，不能使整屋瞬间暴露日光。
- [x] 记录06/12/18/00时同机位、太阳单项/底光单项/完整效果；夜间局部灯、角色/装备、窗外天空与未知房间黑幕同时正确。

完成报告：完整24小时连续片段、四时刻对照、室内外/窗洞/揭顶差分、材质响应矩阵及天空许可边界。若只有天空预览变化、地表不变，B不通过。

## 里程碑C：天气、气候与过渡

- [x] 创建晴/多云/阴/薄雾/小雨五个天气档和三个气候基线，旧冻结Profile只作来源。推荐自动天气默认关闭，由用户先手动比较；开启后使用固定种子、配置权重和持续时间，避免无法复现。
- [x] 用真实快照测试晴→雨中途切回晴，从当前值继续过渡；权重全0、持续时间无效、输入越界应有明确校验；快照中不得出现非有限值。
- [x] 共享世界云场驱动天空与有限云影，不把云影当最终画面全屏乘暗。云影只调直射贡献，原底光、室内点灯和黑幕规则独立；提供关闭对照，旧失败参数不作为默认。
- [x] 风由同一快照控制云和明确登记的植被表现；不旋转世界根或人物，不用物理风吹动未授权实体。
- [x] 薄雾继续使用合法世界深度与现有空气接口，天气雾不写RoomFogSettings的可见权/退场历史，不把未知黑幕当作空气深度。
- [x] 小雨采用有界的程序化自有绘制，不创建普通场景Renderer，因此不会被InitializeSightRegistration误收进PositiveSurfaces。先做屋顶内/外、雨点前/后遮挡、未知区域测试，再接入正式可视路径；不把未支持的默认粒子Shader直接塞入正向Renderer列表。雨点避开室内和明确遮雨体，不新增逐雨滴物理刚体。
- [x] 湿润只作用于有明确材质响应的地表/实体，受小范围参数限制；手绘图集不统一高光化。粗糙/金属样球用于辨认反射与湿润差别，禁用时恢复原材质。
- [x] 晴/阴/雾/雨与昼/夜交叉对照；雨不进屋、封窗和未知区不漏、HUD/信息不染色；只控制环境演示而不改变AI或玩法日历。

完成报告：五档可调、天气转换片段、共享云场与直射贡献、雨棚/室内遮雨、气候自动序列可复现，以及关闭/重入的资源与原状态恢复。

## 估时与连续执行方式

预计完整基础闭环 **8–14小时**，是当前代码和需求下的工程估算，不是交付倒计时。主要不确定性是自绘地表/Spine受光、合法天空背景和室内遮雨的接合。只摆天空球和转灯可以更快，但不满足本计划的验收。

实施时按A→B→C→D连续推进，每完成一个里程碑报告结果、实际证据和剩余工作；普通实现取舍按推荐案处理，不在每个小步骤打断。若有无法在现有后端安全完成的内容，保留失败证据并明确缩小结论，不用未生效控件或全屏滤镜冒充完成。

默认先交付以上五种天气与三种气候视觉基线；体积光/体积云、全球季节、积雪、真实气象、生存和作物接续属于独立扩展，不能悄悄计入本轮已完成。
