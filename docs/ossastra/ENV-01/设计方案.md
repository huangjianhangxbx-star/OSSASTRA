# ENV-01：天空、光照与昼夜天气模拟器设计

日期：2026-11-04。状态：已按用户“执行吧”完成本轮实现；实际实现调整、验收与边界见 [实现与验证交付.md](实现与验证交付.md)。下文保留设计起点。

## 目标与推荐

在正在认证的唯一主场中，把天空、真实受光、投影、昼夜及天气组织成一套可调的环境系统。保持当前35°、两角色单敌人、建筑/窗洞可视规则与现有业务。既能直接试玩，也能用统一面板比较光照贡献，后续正式场景可复用。

推荐**沿用现有3D URP，新增轻量环境根与受光适配**。只挂天空球和旋转灯虽然快，但当前大量材质不会响应；直接引入完整天文、实时GI、体积云和气象系统则会扩大依赖及验证面。本轮以实际主场能辨认的光影闭环为准。

## 交付范围

1. **天空**：程序天空球/天空背景、日夜色渐变、太阳/月亮标识、可调云量和云速；不依赖新购插件。35°主视角经常没有地平线，天空仍须通过环境底光和反射产生贡献，不能为看天空擅自抬镜头。
2. **真实光照**：太阳方向、强度、颜色、地面和实体投影、室内外底光与局部灯；手绘地表保持底纹，并有可配置的受光强度。
3. **昼夜**：0–24时手动滑动、日出/正午/日落/深夜预设、可调速度的自动演示；停止昼夜推进只影响环境演示，不暂停游戏。
4. **天气**：晴、多云、阴、薄雾、小雨，支持平滑过渡；天空、直射光、底光、雾、风及降雨消费同一个天气状态。云影、湿润均提供独立开关和贡献对照，默认保守，避免旧实验的发白/塑料感。
5. **气候**：温和晴朗、湿润多云、冷色干燥三个可编辑基线，决定天气权重、持续时间、风及昼夜色彩。温度/湿度作为明确标注的环境参数输出，不在本轮暗中接入生存、作物、积雪或伤害业务。
6. **观察样板**：在主场现有空地增设一个有名字、可保留或整体关闭的光影观察区，与原建筑和交互区域避让；不新增战斗目标或无用场景。

## 显示与受光的职责

| 显示对象 | 本轮方案 |
|---|---|
| 现有URP Lit实体 | 继续使用原受光路径，核对Cast/Receive Shadows、主灯与附加灯支持 |
| ThinTop/WorldTile地表 | 新增日照、环境底光、主灯阴影接收；保留原alpha、统一平面深度、视野裁剪与过渡 |
| 图集装饰 | 采用可调的简化受光，逐类明确是否投影；不假装每片草都有真实立体法线 |
| Lit Spine身体 | 保留原Lit路径及关键字，不再额外乘一次太阳光 |
| Unlit Spine/装备 | 独立的环境亮度/色温响应，保留PMA、图集、alpha和原材质身份；可以保持风格化可读性 |
| HUD、信息条、预警 | 不进入环境变暗、雨雾或景深处理 |

“角色不参与环境后处理”与“角色不受昼夜光照”是不同规则。夜间不能出现全地图变暗、装备却无条件自发白的断层；同时保留可调的最低角色可读度。

## 架构与权威

`时间输入 + 昼夜档 + 天气档 + 气候档 → EnvironmentRoot → 不可变EnvironmentFrame → 灯光/天空/材质/WorldLook/天气表现`。

- 时间有手动、环境预览时钟和外部时间接口三种来源。没有正式游戏时间源时，只创建标明用途的预览时钟；今后接正式时钟时切换输入，不建立第二套游戏日历。
- EnvironmentRoot是本场唯一环境状态写入者。数据档与运行状态分离；旧Profile只读，不能原地改写冻结资产。
- 灯光、天空、天气表现是独立接收者。WorldLook继续负责环境后处理，只读新快照；不让两个Controller争写太阳、环境光或同一效果参数。
- 现有主灯作为明确太阳源，补光列入可配置的阅读辅助并受昼夜曲线约束；原室内局部灯不被黑幕或室外天气随意关掉。
- 所有参数Inspector可检查；开发面板通过正式环境接口改运行状态，不硬读新快捷键，也不只改面板文字。
- Edit预览需显式开启，保存为预设副本需显式操作；禁用、换场、脚本重载时按所有者恢复借用状态，不能污染其他场景。

## 必须保留的可视与遮光边界

- 黑幕表示没有可见权，夜色/薄雾表示有可见权但光照或空气不同。天气不能修改房间许可、发现状态、锁定或敌人AI视野。
- 天空作为独立背景提供者，不把巨大天空Mesh塞进普通PositiveSurfaces。清黑之后先绘制受许可的天空，再绘制合法世界；未知室内、封闭窗洞及非法区域仍保留隔离。
- 天空许可必须来自现有房间、窗洞、结构遮挡与明确地图天空区域，不能通过“像素是黑色”或“深度为远平面”猜测。室外与室内开窗看天空分别验收；无法证明合法的背景保持关闭。
- 屋顶/前墙的颜色隐藏不能关闭其实体或Caster。现有ShadowsOnly作用域可复用，但必须同时确认原Shader有Caster、原Renderer允许投影。
- 大多数Partial物体当前禁止投影以防未知内容泄露。观察样板须明确登记结构Caster；不能为了好看一键恢复全部隐藏敌人与未知物件的影子。
- 屋顶Caster能挡太阳直射，**不能自动遮蔽全局SH环境光**。室内需要明确的底光策略和区域响应；禁止把全局天空调亮后宣称室内已物理正确。
- 降雨与雨雾只显示在合法区域并避开屋顶/室内/遮雨体。普通未支持的粒子Shader不得直接加入正向绘制，否则可能导致不支持材质或黑幕泄漏。
- 初版反射使用天空环境或明确静态白名单，不捕获全场未知敌人/房间。环境/反射更新有频率和变化阈值预算，不逐帧重抓Cubemap或调用GI更新。
- 所有屏幕效果只消费现有当次合法深度；不启用会读取旧世界深度的旧后处理Controller。

## 同场观察区

- 三种高度的立柱、阶梯、实体墙/窗洞、带屋檐遮棚：看影子方向、长度、软硬及遮光。
- 同纹理的受光地面、哑光/粗糙/少量金属样球：区分直射光、环境底光、反射，避免只看色相变化。
- 沿用当前房屋和室内暖/冷局部灯：看日光入窗、揭顶后屋内是否仍遮光，以及夜间灯池。
- 原两角色、装备和一敌人继续参与：检查跨明暗区、朝向/相机旋转、遮挡及可读性。
- 可折叠天空预览窗口显示完整天空球与太阳方向；不改变35°玩法镜头，不由预览相机重复推进环境状态。

## 调节面板

| 分组 | 控件与语义 |
|---|---|
| 时间 | 时刻0–24、自动推进、每昼夜演示分钟数、一键日出/正午/日落/深夜 |
| 太阳 | 跟随时刻/手动角度、方位0–360°、高度、强度、色温、阴影强度/质量；手动角度不偷偷改时刻 |
| 天空与底光 | 天空/地平线颜色、云量/密度/速度、环境光强度、反射强度；室内底光单列 |
| 天气与气候 | 预设、目标天气、混合时长、云影开关/强度、风向/风速、雾强度、雨量、湿润；手动/自动天气与固定随机种子 |
| 对照 | 原场、仅日照、仅底光、仅云影、完整效果；一键复原初始环境，检查当前生效参数 |

参数建议是可改的初值，不是用户已批准的锁定数值：白天06:00–18:00；默认每6分钟演示一个昼夜；天气过渡5秒；太阳测试高度12°/45°/75°、四个方位；阴影初值沿当前2048/2级联，先测清晰度与抖动再调整。

## 验收与完成定义

必须在同一主场看到：旋转太阳时影子按几何改变，降低高度时影子变长；现有地表能够接影；正午/日落/夜间光照不同；阴天减弱直射对比；窗洞允许日光、屋顶颜色隐藏后仍遮光；夜间局部灯可辨认；晴雨转换和风云变化可控；人物与装备响应一致、HUD不受影响；未知区域及动态信息不泄漏。

材质身份、帧作用域、禁用恢复、场景重入、原存档和已有dirty保护必须一起收口。记录同一机位的贡献对照与实际测量，不能只凭Inspector数值变化验收。

本轮不扩展为真实天文/气象精度、全球季节、生存作物、积雪结冰、完整实时GI、体积云/体积光、原生Bokeh或新战斗系统。环境音默认关闭；日后接入也通过现有统一音声根配置，避免再次出现无条件循环噪声。

工程资源：T7B的T7BSky/T7BCommon/T7BCloudLayer及OutdoorProfile；T7A3仅作为后续体积光研究来源，不直接挂旧预览控制器。旧BestVisual/Low里云影和湿润为0是历史有意取舍，不自动把旧高值打开。
