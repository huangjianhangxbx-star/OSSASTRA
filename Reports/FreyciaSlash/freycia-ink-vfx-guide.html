芙蕾 2D 组合特效制作教程

从原有八格素材或单张贴图开始，直接拖刀路、调宽度、排各层时间。保存为预制体后，用芙蕾原有的一次动画事件播放整套效果。

打开编辑器拖刀路与宽度排时间保存与试打八格素材参考与旧版对照

1. 打开样例，选出第一层的素材

OSSASTRA›战斗›2D 组合特效
  1. 在 Project 搜索 FreyciaCombo。FreyciaCombo_ATK1 和 FreyciaCombo_ATK2 是两刀的组合版。FreyciaCombo_Thrust 是窄尖突刺。FreyciaCombo_DelayedStamp 的最后一层从 270 ms 开始，整套到 348 ms 结束。
  2. 第一次练习，选 FreyciaCombo_ATK1，按 Ctrl+D 创建自己的预制体。在组合特效窗口点使用当前选择。顶栏显示预制体资源时，改动会写回这个资产。
  3. 在底部时间轴点主墨体。在右侧素材取样选规则图集，设为 4 列 × 2 行。直接点右侧图集上排第一格；移到 50–100 ms 观察形状。如果素材只有一张，把它拖到本层单图／图集，选整张单图。
  4. 用颜色与透明度给本层着色。时间轴点独可以只看这一层，点锁可以防止误拖。左侧显示勾选影响预制体里的播放，独显和锁定只用于当前编辑。
现有四个样例在芙蕾资源下的 SlashVfx。如果目录里还没有生成过，运行 OSSASTRA → 战斗 → 创建芙蕾组合特效样例。已有样例将继续沿用作者保存的内容。

2. 分开摆位置、改刀路、捏宽度

预览工具该拖什么什么时候用
整体从中心拖整体位置，用旋转和缩放手柄改整个效果的摆放。刀路已经满意，整套偏高、偏低或太大。
路径实心点是路径点，控制柄拉出弧度。箭头指向刀光展开的终点。拉起点和终点，调弧线切线，做横劈或上挑。
宽度分别拖起点、中段、终点。沿长度宽度曲线可继续加细节。中段变厚、终点收尖，或者让余迹越走越细。
  1. 选中并解锁主墨体后切到路径。右侧勾选共用路径时，沿用同一公共路径的锐边和暗尾会一起变化。要单独改暗尾的走势，在暗尾该项取消共用，再编辑它的独立路径。
  2. 从空白形状起步，可点右侧直刺、横劈弧、上挑弧。镜像翻转形状，反转交换路径方向。按 Ctrl+Z可撤回一次完整拖动。
  3. 做突刺时先打开突刺样例，再切宽度。把末端捏到约 0.01，起点约 0.25，中段约 0.43。把时间拖到 50 ms 左右检查尖头。
  4. 只需让某一层挪开一点时，用右侧层偏移、层旋转、层缩放。动作整体挂在角色哪里，进原动画事件的挂点和偏移里调整。

3. 排展开、飞片和退场

  1. 拖时间块中段移动层的开始时间。拖两侧边缘调整整层时长，展开、淡出和消退区间会同比缩放。飞片层的边缘调整发射时段，浅色余粒由存活时间决定。时间轴上部拖游标，或用播放、暂停、复位和逐帧按钮定位。参考帧有 30、60、120 fps 选项。
  2. 在暗尾层打开逐段消退，选从路径起点。层从 0 秒开始时，可先将消退设为 0.08–0.25 秒。柔和度控制退场边缘，纹理仍留在原刀路上。
  3. 再开整体淡出，用整体透明度曲线控制整层一起变暗。想让尾端边扫边消，逐段消退的开始要早于展开结束。想先扫完再消退，移动消退条使其晚于展开。
  4. 飞片层的实色段是发射，后面的半透明段是余粒。把开始移到扫掠之后，设定数量、速度、散布和存活区间。选择沿路径取发射点时，方向 0° 沿切线，+90° 朝路径左侧。
  5. 再添加贴片，点图集下排第三格，在时间轴晚些出现。预览切到移动挂点示范，设置在层开始时固定可以看见贴片在出场位置停留。飞片从各自出生时的位置飞出。用重新随机试新分布，再往回拖到同一时刻比较。

4. 保存并用芙蕾试打

  1. 选 Project 中的预制体资产，点窗口里的保存，关窗后重新打开读取。Prefab 模式里用 Ctrl+S，场景实例覆盖随场景保存。Play 中的实例编辑只用于当前试玩。
  2. 打开OSSASTRA → 战斗 → 横版角色手感调试台 → 动画与事件。选芙蕾和普攻对应段，在正在用的映射片段里找到已经带特效的 Hit 响应，将特效预制体指向自己的新组合副本。保留原挂点、偏移、缩放和时机。内部层的结束时间决定组合什么时候退场。
  3. 在同一面板点试放特效，再进游戏实际按攻击。要改这个预制体，可点编辑组合特效直接打开。先空挥看飞片和延迟贴片，再打木桩看命中点。两次朝向都试一次。若想为实际受击改独立爆点，到命中与受击改命中反馈配方。
动画事件只召唤一次组合。增加二段光效时，在同一个组合的时间轴加层即可。

01 / 素材

先选主笔触，再选陪衬

第一遍直接用 FreyciaInkMasks.png。以后换一张图时，先在深底上看轮廓，再缩到芙蕾出招时的游戏尺寸。主笔触要能读出尖、宽、收尾三个部分。内侧断笔沿挥刀方向分开，薄光只给刃口一层微弱的亮度，飞屑留几个方向清楚的颗粒。

上① 墨体有厚肩和破边的主笔触，也给暗色余迹使用。
上② 锐刃沿外缘走的窄亮线。边缘清楚，尾部可以断。
上③ 断笔内圈几缕拖丝，适合留出透明缺口。
上④ 薄光贴着刃线的一点软亮，适合压低亮度。
下① 飞片长轴横向，做成有尖头的碎片，扫过后弹开。
下② 擦痕顺方向拉长的内侧残迹，用于挥击收尾。
下③ 爆点中心集中，几条不等长的锐刺向外伸出。
下④ 破圈中间挖空，外圈断成几段，晚于闪白退掉。

自己画变体时这样下笔

  1. 在图像软件里复制原图，保留 1024 × 512、4 列 × 2 行、每格 256 × 256。按图中顺序填格，单格四周留约 6 px 的全透明边，防止相邻格串色。
  2. 上排画拉直的笔触。横向从左到右对应动作起点到终点，图上的上侧靠弧外刃，下侧靠弧内。把锐刃画在墨体的外缘一侧。曲线的弯度由游戏叠上去。
  3. 下排的飞片与擦痕保持横向，爆点和破圈以格子中心为原点。导出带透明通道的 PNG，用白色 RGB。想缺一块就擦掉对应 Alpha。想要淡笔就降低 Alpha。
换贴图能改变笔锋、裂口和纹理。整条挥击朝哪边弯、扫到哪里，可以在组合编辑器中拖路径点，旧版对照由角度和半径决定。先改其中一处，方便看出差别。
02 / 导入

建立一个可以反复试的预制体

Assets/OSSASTRA/RealGameResource/角色/主角/Freycia/SlashVfx

在 Project 搜索 FreyciaInk_ATK1。已有素材和材质时，直接复制预制体即可试形状和配色，下面第一、二步可跳过。

  1. 导入图集。 将新 PNG 放进上面的目录，选中它，在 Inspector 输入下表，最后点 Apply。透明棋盘或 Alpha 预览里应该能看见形状。
  2. 复制材质。 回到 Project，选 FreyciaInkMaterial，按 Ctrl+D 并改名。在新材质里把贴图拖到 Frame strip。检查 Shader 是 Ossastra/SideView/CombatEffect，Layer tint 保持白，默认帧 UV 保持整张图。
  3. 复制预制体。 选 FreyciaInk_ATK1，按 Ctrl+D 并命名。双击副本，在 Prefab 模式选根节点。检查有 Mesh Filter、Mesh Renderer 和 Freycia Ink Effect。把材质拖到 Mesh Renderer → Materials → Element 0。沿用原排序和 Transform。
  4. 保存副本。 Prefab 模式若关闭了 Auto Save，点 Save，再返回原场景。该组件在 Play 时生成网格。编辑模式里 Mesh Filter 的 Mesh 留空是正常状态。

练习 A · 把第一刀削薄

副本 Width .64 → .48，其余保持原值。先看扫到一半时红色主体是否更窄，观察刃口是否仍清楚。

练习 B · 让第二刀挑得更高

Radius Y .67 → .82。若弧尖位置还要改方向，下一轮再试 Tilt 20 → 27。

练习 C · 把余迹拉长

ATK1 组件 Lifetime .25 → .30，到动画响应把 特效寿命 .27 → .32。这会放长各层包络。若只想让扫头慢一点，可另试 Sweep Seconds .052 → .065。

练习 D · 给第一刀做干笔尾

在墨体格的右半段擦出两三道沿笔触方向的狭长透明缺口。保留一条连续外缘。导入新图后保持角度和照明不变，观察缺口是否在游戏大小下可辨。

调完后打新的一刀再看。颜色和飞屑网格会在新实例启用时读取。要保留参数，请在退出 Play 后修改并保存预制体资产。

需要单独改某一层的起亮、峰值或消退曲线时，入口在 FreyciaInkEffect.cs 的 DrawSweep / DrawContact。当前 Inspector 能改整体寿命、扫掠、形状与颜色。要做折线或 S 形轨迹，另改 SampleArc 的路径或做独立预制体。
04 / 出刀绑定

把预制体挂到真正播放的片段

在 Project 搜索 FreyciaShadow_Animation，单击这个动画映射资产。第一刀照下面开。配置第二刀时，把 Attack 1 / ATK1 / Basic1 换成对应的第二段。

Melee→Plans Melee→Attack 1→Clips→匕首/ATK1→事件响应→FreyciaShadow_Basic1→Hit #1

如果已经在 FreyciaShadow_Basic1 的 Inspector，可以点 打开动画事件配置 · 匕首/ATK1。先确认显示的是这次要编辑的角色与映射。

  1. 在 适用动作 选 FreyciaShadow_Basic1，看见 动作专用响应 后展开 Hit #1 的现有响应。若看到空白的「片段默认」，回到下拉框选动作。
  2. 保留这一行的 用途＝出手释放 以及已有标记、音效和动作时序。只把你的预制体拖到 特效预制体。已有响应可以直接换引用，避免同一事件装两次刀光。
  3. 在 骨骼 / 插槽 选 角色根，按下表填位置和寿命。勾选 跟随挂点 会在生命周期内跟着角色根；希望留下一道固定在出刀位置的余迹时，可复制一个变体试取消跟随。左右朝向由本项目的刀光播放链路镜像。
  4. 点 保存此动画映射。如果要让画面晚一制作帧，先试 特效补偿（帧）＝+1。30 FPS 时为约 33 ms，当前两刀的源 Hit 都在起始帧，提前量不能越出片段起点。只调画面时保持 标记偏移（帧） 和 音效补偿（帧） 原值。

局部 X 往前移，局部 Y 升高。保持 Z 为 0 作为起点，避免随手把特效移到墙后。第一刀这行也有挥刀音效，改挂点或偏移会一同改变该声音的位置。

05 / 命中绑定

把爆点放在受击位置

  1. 在 Project 搜索 FreyciaInk_Contact。若要做新爆点，先复制它再调，Contact Burst 保持勾选。把 Impact Size .69 → .85 可放大爆点与破圈；Fleck Count、Fleck Travel 单独控制碎屑，基准是 7 / .48。爆点用 Edge，破圈用 Stroke，弧形参数不参与这套播放。
  2. 确认角色定义 FreyciaShadow_Character 的 Side View Feedback 指向 FreyciaInkFeedback。当前已有两行 body.basic 第 1、2 段、Hit，可以直接调它们。
  3. 打开 OSSASTRA → 战斗 → 横版角色手感调试台 → 命中与受击。选芙蕾，招式与阶段 选 默认普攻 · 第 1 段，接触结果 选 实际命中。第二段也照做一次。首次出现空配方时，点 创建此条件的角色配方。
  4. 在 接触特效 勾选 覆盖共用特效，把爆点预制体拖到 特效预制体（空为隐藏）。先保留 延迟 0 ms、缩放 1、寿命 .21 秒、接触点偏移 (0,0,0)、方向 Arriving，跟随受击者关闭。预制体内寿命是 .19 秒。面板自动保存，下一个新动作读取。
想恢复共用命中效果，可以取消 覆盖共用特效。勾着覆盖并清空预制体会主动隐藏该特效。声音和震屏各有单独的覆盖项。

若装备了独立的主手动作组，手感台可能显示该武器自己的招式与阶段。需要为它调效果时，选实际装配的动作组，检查配置来源。格挡、闪避和环境接触也各有自己的结果。

06 / 验收

用四组试打把问题拆开

  1. 朝右空挥一次。 确认一条下劈在身体前方出现，淡完，无命中爆点。
  2. 朝左空挥一次。 确认下劈镜像到左侧，细刃和余迹仍按原顺序退。镜像问题在实际出招时看。
  3. 朝空处连按两次。 第一刀接第二刀。确认第二刀从低处上挑，宽度跟第一刀有差别。
  4. 对木桩重复两段。 观察木桩受击，再看接触位置是否出现短促白金闪光、后续破圈和碎片。手感台里选 当前配置并复位，确保正在试新的配方。

只想快速看一条特效，可以在手感台点 进入独立测试场并试玩，在 动画与事件 下选芙蕾和对应动作，用 当前路由解析 找到片段，展开响应后点 试放特效。这个按钮按当前姿态临时实例化。左右跟随、动画时机和伤害接触，要回到 Game 用正式输入再核对。
