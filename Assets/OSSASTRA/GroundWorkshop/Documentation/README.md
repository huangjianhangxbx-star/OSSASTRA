# 星骸地表工坊 · 公开制作手册

打开 `03-tutorial/地面组合逻辑教程.html`，或 `04-art-guide/素材绘制规范.html`。两份手册离线可读、相互链接，不依赖本机参考图鉴或原作媒体。

内容包括本项目自有说明、独立几何SVG、原创透明PNG练习、原创八邻域技术族的256状态编号表，以及7张已核SHA的纯原创NativeCamera.Render完整帧。该编号表对应独立生成的技术族，不是原作14条有序规则/15片的可逆提取表。真实帧呈现192基础/32覆盖/19连通道路/44装饰及换材前后，不是Editor窗口截图。

可下载 `04-art-guide/assets/OriginalTechnical32.png` 作为32×32底纹导入练习；对应 `OriginalTechnical32_3x3.png` 为96×96的3×3预览。Native验证导入、预览/取消/提交/Undo、作者属性与装饰根保持；这些技术样本不代表正式商业美术。

`03-tutorial/assets/original-story/capture-provenance.json` 只保留该纯原创批次的尺寸、方法、SHA和去掉绝对路径的来源说明。私有参考渲染未进入此目录。

手册保留来源事实与Unity适配/未知的区分。实际插件依赖、最新技术验收与物理输入未测边界由对应版本交接报告说明；这些文档不代签视觉或制作体验验收。

`public-manifest.json` 列明可分发正文与示意的精确文件和SHA-256。`qa/` 目录仅为自有手册的离线布局测试截图，可从正式发布包排除，不属于Unity功能截图。
